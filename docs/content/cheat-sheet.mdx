The whole everyday API of EasyEcs on one page, as tables and short code. Each section links to the guide page that
explains it. Everything is in one namespace: `using EasyEcs;`.

The examples on this page share these declarations:

```csharp
public record struct Position(float X, float Y) : IComponent;
public record struct Velocity(float X, float Y) : IComponent;
public record struct Health(int Value) : IComponent, ITracked;          // tracked: writes are recorded
public record struct Mana(int Value) : IComponent, ITracked;
public record struct Team(int Id) : IComponent, IIndexed<int> { public int Key => Id; }
public record struct Account(int Id) : IComponent, IUniqueIndexed<int> { public int Key => Id; }   // one entity per key
public record struct Zone(int Id) : IComponent, IGroup { public int Group => Id; }
public record struct OwnedBy(EntityId Owner) : IComponent, IIndexed<EntityId> { public EntityId Key => Owner; }
public record struct MemberOf(EntityId Target) : IRelation;                   // many links per entity
public record struct Loot(int Item);                                          // a DynamicBuffer element
public record struct Seat(int Number) : ICleanupComponent;                    // released after destroy
public struct Dead : IComponent;                                              // a tag
public record struct Session(int Connection) : IComponent;                   // runtime state, not saved
public record struct Clock(long Tick) : ISingletonComponent;                  // one per world
public record struct Config(int MaxPlayers) : ISingletonComponent;
```

## Declare data [#declare-data]

| Declare | Means | Guide |
| --- | --- | --- |
| `struct X : IComponent` | Per-entity data, one column per type | [Entities and components](/en/docs/guide/entities-and-components) |
| `struct X : IComponent` with no fields | A tag: a yes-or-no state used in filters | [Entities and components](/en/docs/guide/entities-and-components) |
| `struct X : ISingletonComponent` | One value per world | [Singletons](/en/docs/guide/singletons) |
| `: ITracked` | Rows record the tick of their last write and removal | [Change tracking](/en/docs/guide/change-tracking) |
| `: IIndexed<TKey>` with `Key` | Found by value through `world.Index<T, TKey>()` | [Indexes and relations](/en/docs/guide/indexes-and-relations) |
| `: IUniqueIndexed<TKey>` with `Key` | A key that names one entity: `index.Get(key)`; a write that would give a second entity the key throws | [Indexes and relations](/en/docs/guide/indexes-and-relations) |
| `: IDirectIndexed<TKey>` with `Key`, `static Slots`, `static SlotOf(key)` | A unique key that maps onto bounded slots (grid cells): `Get` / `TryGet` read one array entry | [Direct-mapped keys](/en/docs/guide/indexes-and-relations#direct-index) |
| `: IIndexed<EntityId>` | A link to one entity, found from the target | [Indexes and relations](/en/docs/guide/indexes-and-relations) |
| `: IRelation` with `Target` | Many links per entity, kept in a buffer | [Indexes and relations](/en/docs/guide/indexes-and-relations) |
| `: IGroup` with `Group` | Splits tables by value after `world.GroupBy<T>()` | [Groups](/en/docs/guide/groups) |
| `: ICleanupComponent` | Outlives `Destroy`: the other components go, the entity gets the `Retired` tag and stays until a system removes the last cleanup component | [Cleanup and disable](/en/docs/guide/cleanup-and-disable) |
| `Disabled<T>` | The tag an entity carries while its `T` is disabled: query it to find the paused ones | [Cleanup and disable](/en/docs/guide/cleanup-and-disable) |
| `DynamicBuffer<T>` | A list per entity, every write tracked | [Dynamic buffers](/en/docs/guide/dynamic-buffers) |
| `ChildOf(EntityId Parent)` | The built-in hierarchy link | [Hierarchy](/en/docs/guide/hierarchy) |
| `struct G : ISystemGroup` | A group of systems with its own cadence | [Systems](/en/docs/guide/systems) |
| `: ISystemGroupWith<T>` / `ISystemGroupWithout<T>` on a group (or an interface it implements) | The group's systems visit only entities with / without `T`; a generic interface gives each actor type its own filtered group | [Systems](/en/docs/guide/systems#group-filters) |
| `class S<T> : EcsSystem` | A generic system: each closed type (`S<Position>`) is a system of its own | [Systems](/en/docs/guide/systems#generic-systems) |

Components are structs ([EECS006](/en/docs/guide/analyzer#eecs006)). Keep an entity link as an `EntityId`, not an
`Entity` ([EECS017](/en/docs/guide/analyzer#eecs017)).

## World [#world]

| Call | Does |
| --- | --- |
| `new World(options)` | An isolated world; `Dispose()` runs every `OnDestroy` |
| `world.Update()` | Runs the default group's systems once |
| `world.Update<TGroup>()` | Runs one system group |
| `world.AddSystem<T>()` / `AddSystem(instance)` | Adds a system (runs `OnCreate`) |
| `world.RemoveSystem<T>()` / `TryGetSystem<T>(out s)` / `Systems` | Removes, finds, lists systems |
| `world.EntityCount` / `Entities` | Live entities and an allocation-free walk over them |
| `world.ChangeTick` | The current change tick |
| `world.DefaultUpdateCount` | Completed `Update()` calls of the default group |
| `world.UpdateCount<TGroup>()` | `Update<TGroup>()` calls so far, the running one included: what the group's `UpdateInterval`s count |
| `world.Reserve<T1, …, Tn>(n)` / `Reserve(prefab, n)` / `EnsureEntityCapacity(n)` | Pre-size before a known peak or a wave |
| `world.TryGetEntity(id, out e)` / `GetEntity(id)` / `IsAlive(id)` | From an `EntityId` back to a checked handle |
| `world.DescribeTables()` | Tables, columns, rows and bytes, for tools |
| `world.DescribeSchedule()` | Every group's stages, each system's reads and writes, why it waits, the pairs only registration orders; `ToString()` / `ToMermaid()` |
| `world.TrimExcess()` | Drops empty tables and shrinks the others after a peak, at a quiet moment |
| `world.DestroyedSince(since, into, out count)` / `DestroyLogOldestTick` | Entities destroyed since a tick, with `WorldOptions.DestroyLogCapacity`; `false`: the reader is older than the log |

```csharp
Console.WriteLine(world.DescribeSchedule());        // stages, waits, registration-only pairs
world.TrimExcess();                                 // after a wave despawned: memory back, nothing breaks
```

## Entities [#entities]

```csharp
using var world = new World();
Entity unit = world.CreateEntity(new Position(0, 0), new Velocity(1, 0), new Health(100));
```

The generic calls, what the [generated members](#generated-members) call; code that names a component uses the
members (`unit.Velocity`, `SetHealth(50)`, `RemoveDead()`), as in the example under the table.

| Call | Does | Structural |
| --- | --- | --- |
| `world.CreateEntity(a, b, …)` | Creates with up to 9 components, straight into the final table | yes |
| `entity.Set(a, b, …)` | Adds or overwrites up to 9 components in one move; returns the entity | yes |
| `entity.SetIfChanged(value)` | `Set` unless the entity already has this value; `true` when it set it (an equal value is not stamped or re-indexed) | when added |
| `entity.Remove<A, B>()` | Removes components it has; returns the entity | yes |
| `entity.GetOrAdd<T>()` | `ref T`, added with the default value if missing | when added |
| `entity.Get<T>()` | `ref T` for writing (a write for change tracking) | no |
| `entity.Read<T>()` | `ref readonly T` (never a write) | no |
| `entity.TryGet<T>(out T copy)` | A copy, if present | no |
| `entity.TryGetRef<T>(out bool found)` | `ref T` or a null ref | no |
| `entity.Has<T>()` / `Has<A, B>()` | Presence of one or all | no |
| `entity.Disable<T>()` / `Enable<T>()` / `IsDisabled<T>()` | Hides a component, keeping its value | yes |
| `entity.Clone()` | A copy of the entity in its world; throws for a retired entity (kept for its cleanup components) | yes |
| `entity.Run<T1..T9, TJob>(ref job)` / `Run(ref job, filter)` | Runs an `IForEachEntity` job on this entity with the refs a pass gives; `false` when it is not alive, lacks a component or fails the filter | when the job makes one |
| `entity.Destroy()` | Destroys it; its id is recycled with a new version | yes |
| `entity.IsAlive` / `Id` / `World` | Handle state; every access checks the version | no |
| `entity.Describe()` | Its component values, for debuggers and logs | no |
| `EntityId` / `EntityId.Null` / `id.IsNull` / `id.Index` / `id.Version` | The 8-byte id to keep in components; `Null` is the default value | no |

```csharp tab="Components"
unit.Velocity.X = 2;                                // write in place through the ref
float x = unit.Position.X;                          // a read (ref readonly for a tracked component)
unit.Set(new Health(50), new Dead());               // both in one call: shorter, same cost
unit.RemoveDead();                                  // flips a presence bit: the row stays
if (unit.TryGetHealth(out var hp)) { /* hp is a copy */ }
```

```csharp tab="entity.Run"
public struct TakeHit : IForEachEntity<Health>
{
    public int Damage;
    public static int WriteMask => 1;                  // bit 0: Health counts as written

    public void Execute(Entity target, ref Health hp) => hp.Value -= Damage;
}
```

```csharp tab="entity.Run"
var hit = new TakeHit { Damage = 30 };
bool applied = unit.Run<Health, TakeHit>(ref hit);   // a request handled on its entity
```

A `ref` stays valid until the next structural change and never across `await`
([ref and await](/en/docs/guide/refs-and-await)).

## Generated members [#generated-members]

The source generator gives every component, tag and singleton named members (C# 14 extension members). Each one is an
inlined call to the generic API above.

| Declared | Generated |
| --- | --- |
| Component `Position` | `e.Position` (`ref`), `HasPosition`, `TryGetPosition(out p)`, `GetOrAddPosition()`, `SetPosition(x, y)`, `RemovePosition()`, `DisablePosition()`, `EnablePosition()`, `IsPositionDisabled` |
| Tracked or indexed `Health` | `e.Health` is `ref readonly`; write with `SetHealth(…)` or `WriteHealth()` (`ref`, tracked only); `SetHealthIfChanged(…)` writes only a different value |
| Tag `Dead` | `e.IsDead`, `SetDead()`, `RemoveDead()` |
| Indexed `Team` | `world.TeamIndex` (`world.Index<Team, int>()`) |
| Unique `Account` | `world.AccountIndex.Get(id)` / `TryGet(id, out e)` |
| Grouped `Zone` | `filter.InZone(id)` (`InGroup<Zone>(id)`) |
| Buffer element `Loot` | `e.Loot` (`ref readonly DynamicBuffer<Loot>`), `HasLoot`, `WriteLoot()`, `GetOrAddLoot()`, `RemoveLoot()` |
| Relation `MemberOf` | `e.LinkMemberOf(target)`, `UnlinkMemberOf(target)`, `LinksMemberOf(target)`, `world.MemberOfIndex` |
| Singleton `Clock` | `world.Clock` (`ref`), `HasClock`, `GetOrAddClock()`, `SetClock(…)`, `RemoveClock()` |
| On a `Prefab` | `SetPosition(…)`, `RemovePosition()` return the prefab; `prefab.Position` (read-only), `HasPosition`, `IsDead` |
| `world.Query<Position, Velocity>()` items | `item.Position`, `item.Velocity` |

```csharp
unit.SetPosition(3, 4).SetDead();                   // setters return the entity
unit.Position.X += 1;                               // untracked: a ref
unit.SetHealth(80);                                 // tracked: written with Set, stamped
bool rewritten = unit.SetHealthIfChanged(80);       // false: the value is already 80, nothing stamped
bool dead = unit.IsDead;
```

Guide: [Entities and components](/en/docs/guide/entities-and-components).

## Systems and [ForEach] [#systems]

```csharp title="MovementSystem.cs"
public class MovementSystem : EcsSystem
{
    [ForEach, Without<Dead>]                         // once per entity with Position and Velocity, without Dead
    static void Move(ref Position p, in Velocity v) => p = new Position(p.X + v.X, p.Y + v.Y);
}
```

A static per-entity method whose components hold 1 to 4 numbers of one type (`float`, `int`, …) also gets a
`Vector<T>` loop written by the generator, with the same results bit for bit
([vector loops](/en/docs/guide/systems#vector-loops)). This one assigns a whole new `Position`, so it runs row by
row; `p.X += v.X; p.Y += v.Y;` would get the loop, and [EECS055](/en/docs/guide/analyzer#eecs055) says which.

### [ForEach] parameters [#foreach-parameters]

| Parameter | Is | Notes |
| --- | --- | --- |
| `ref T` | A component the method writes | 1 to 9 components; a write for change tracking |
| `in T` | A component the method reads | Not a write ([EECS011](/en/docs/guide/analyzer#eecs011) catches writes through `in`) |
| `Span<T>` / `ReadOnlySpan<T>` | A run of rows of `T` (a batch method) | Cannot mix with per-entity parameters ([EECS009](/en/docs/guide/analyzer#eecs009)) |
| `ref S` / `in S` | A singleton | Resolved once per pass; throws if it was not added |
| `Entity` | The current entity | Use it for structural changes |
| `World` | The world | For creating entities from a static method |
| `EntitySpan` | The entities of a batch method's run | Batch methods only |
| `Maybe<T>` | A component the entity may lack | `HasValue`, `Value` |
| `ReadOnlyMaybe<T>` | The same, read only (indexed components too) | `HasValue`, `Value` (`ref readonly`) |
| `Scratch<T>` | The method's working memory on the running thread, kept between rows | `Value` (`ref T`, `default` at first: `scratch.Value ??= new()`); clear it per row; never store what it holds ([scratch](/en/docs/guide/threading#scratch), [EECS058](/en/docs/guide/analyzer#eecs058)) |
| `Lookup<T>` | Read-only `T` of any entity, as it was before the pass; parallel too | `lookup[id]` (`ReadOnlyMaybe<T>`), `Read(id)`, `Has(id)`; `TryFind`, `Find`, `Count` by key ([lookups](/en/docs/guide/threading#lookups), [EECS059](/en/docs/guide/analyzer#eecs059)) |
| `ref Reduce<T>` | A total over the rows into singleton `T : IReduction<T>` | Always by `ref` (else EECS002); the `Value` field is this chunk's partial result; the combined result replaces `T` ([reductions](/en/docs/guide/threading#reductions), [EECS057](/en/docs/guide/analyzer#eecs057)) |
| `Mut<T>` | A component the method writes on some rows | `Value` reads; `Write()` and a `SetIfChanged(value)` that changed it stamp the row; a write for the scheduler |
| Any other type (outside a system) | A value the caller passes to the entry point | `ref int count`, `in Settings s` |

### Attributes [#attributes]

| Attribute | On | Does |
| --- | --- | --- |
| `[ForEach]` / `[ForEach(Parallel = true)]` | Method | The method is the loop; `Parallel` splits rows across threads ([EECS010](/en/docs/guide/analyzer#eecs010)) |
| `[ForEach(Parallel = true, ChunkRows = n)]` | Method | Threads claim `n` rows at a time (OpenMP's `schedule(dynamic, n)`): for a few hundred heavy rows ([chunk size](/en/docs/guide/threading#chunk-rows), [EECS054](/en/docs/guide/analyzer#eecs054)) |
| `[ForEach(Simd = SimdMode.Require)]` | Method | The method must get its vector loop, else a build error ([EECS056](/en/docs/guide/analyzer#eecs056)); `SimdMode.Off` keeps it scalar without [EECS055](/en/docs/guide/analyzer#eecs055) |
| `[ForEach(Slices = N)]` | Method | Each run visits one slice, about 1 / N of the rows: every row once per N runs (not with `Changed` / `Removed`: [EECS035](/en/docs/guide/analyzer#eecs035)) |
| `[With<T>]` | Method, system group | Requires `T` without passing it |
| `[Without<T>]` | Method, system group | Excludes entities with `T` |
| `[WithAny<A>, WithAny<B>]` | Method, system group | Requires at least one of them |
| `[Changed<T>]` | Method | Rows whose tracked `T` was written since the system last ran |
| `[Removed<T>]` | Method | Entities that lost tracked `T` since the system last ran |
| `[ChangedAny<A, B>]` / `[RemovedAny<A, B>]` | Method | Rows where at least one of 2 to 9 tracked components was written, or lost |
| `[UpdateBefore<S>]` / `[UpdateAfter<S>]` | System | Ordering ([EECS019](/en/docs/guide/analyzer#eecs019) rejects cycles) |
| `[UpdateInGroup<G>]` | System | Runs on `world.Update<G>()` only |

```csharp
public class DecaySystem : EcsSystem
{
    [ForEach(Slices = 4)]                            // a quarter of the rows per run, every row once per 4 runs
    static void Decay(ref Velocity v) => v = new Velocity(v.X * 0.9f, v.Y * 0.9f);
}
```

`[Changed<T>]` and `[Removed<T>]` go on methods only. A system group takes `[With<T>]`, `[Without<T>]` and
`[WithAny<T>]` ([EECS023](/en/docs/guide/analyzer#eecs023) flags them on any other struct), or `ISystemGroupWith<T>` /
`ISystemGroupWithout<T>`, which a generic group interface needs because an attribute cannot name a type parameter:

```csharp
public struct In<TActor> : IComponent;              // the tag of one actor type
public interface IActorGroup<TActor> : ISystemGroupWith<In<TActor>> where TActor : struct;
public struct Shop : IActorGroup<Shop>;             // the systems of [UpdateInGroup<Shop>] see In<Shop> entities only
```

### System members [#system-members]

| Member | Does |
| --- | --- |
| `OnCreate()` / `OnUpdate()` / `OnDestroy()` | Lifecycle; `OnUpdate` runs before the `[ForEach]` methods |
| `World` | The system's world |
| `UpdateInterval` / `UpdatePhase` | Run every N-th update, on phase 0 to N-1 |
| `Enabled` | Skip the system; setting `true` clears `Error` |
| `Error` | The exception that disabled it under `SystemErrorPolicy.Disable` |
| `LastRunTick` | The change tick of its last run |
| `RunCount` | Runs before the current one (a sliced method visits slice `RunCount % N`) |
| `Stats` | `Runs`, `LastTime`, `TotalTime`, `AverageTime`, `LastAllocated` / `TotalAllocated` (bytes), `LastEntities` / `TotalEntities` (matched when its pass starts) with `MeasureSystems` |

Systems keep no state ([EECS007](/en/docs/guide/analyzer#eecs007)) and never reference each other
([EECS008](/en/docs/guide/analyzer#eecs008)). Guide: [Systems](/en/docs/guide/systems).

## Queries and filters [#queries]

```csharp
// A field: build each filter once.
private static readonly QueryFilter Alive = QueryFilter.Create().Without<Dead>();
```

```csharp
foreach (var item in world.Query<Position, Velocity>(Alive))
    item.Position.X += item.Velocity.X;             // items hand out refs; item.Entity is the handle

int movers = world.Count<Position, Velocity>(Alive);
bool anyDead = world.Any<Dead>();
```

| Call | Does |
| --- | --- |
| `world.Query<T1..T9>(filter)` | `foreach` over items: `ref` components and `Entity` |
| `world.Read<T1..T9>(filter)` | The same, `ref readonly`: stamps nothing (a save, a send) |
| `world.Count<T1..T9>(filter)` / `Any<…>(filter)` | Counts, or stops at the first match |
| `world.ForEach<T1..T9, TJob>(ref job, filter)` | A struct job `IForEach<T…>`: `Execute(ref T1 …)` |
| `world.ForEachEntity<…>(ref job, filter)` | `IForEachEntity<T…>`: `Execute(Entity e, ref T1 …)` |
| `world.ForEachBatch<…>(ref job, filter)` | `IForEachBatch<T…>`: runs of rows as spans |
| `world.ForEachParallel` / `ForEachEntityParallel` | A struct job in chunks on several threads (`chunkRows:` sets the chunk size) |
| `Runner.Method(world, …)` | The entry point of a static `[ForEach]` method outside a system |
| `static int WriteMask => mask` on a job | Components the job writes (bit k - 1 for component k), stamped for change tracking; default `-1`, all |
| `: INoStructuralChanges` on a job | The job promises no structural change: no per-entity bookkeeping, structure frozen while it runs |

| `QueryFilter` | Selects |
| --- | --- |
| `.With<T>()` / `.Without<T>()` / `.WithAny<T>()` | Presence, as the attributes |
| `.Changed<T>(since)` / `.Removed<T>(since)` | Written, or lost, at or after tick `since` |
| `.ChangedAny<A, B>(since)` / `.RemovedAny<A, B>(since)` | At least one of them written, or lost, at or after `since` |
| `.Since(tick)` | The same filter with a new tick: one filter, run with each client's tick |
| `.Slice(index, of)` | Slice `index` of the `of` slices of every table, for the `ForEach` calls only |
| `.InGroup<T>(group)` | One group of a grouped component |

Guide: [Queries and filters](/en/docs/guide/queries).

## Change tracking [#change-tracking]

| Is a write | Is not a write |
| --- | --- |
| `ref` parameters, `Span<T>`, `Query` items | `in` parameters, `ReadOnlySpan<T>`, `world.Read<…>` items |
| `Mut<T>.Write()`, a `SetIfChanged(value)` with a new value | `Mut<T>.Value`, a `SetIfChanged(value)` with the same value |
| `Get<T>()`, `TryGetRef<T>` when found, `GetOrAdd<T>()`, `Set(…)`, `WriteX()` | `Read<T>()`, `TryGet<T>(out copy)`, `Has<T>()`, `e.X` of a tracked `X` |
| Creating, instantiating, cloning, `Enable<T>()`, `Restore`, `Load`, `LoadEntitiesInto` | Removing or `Disable<T>()` (that is a removal, for `[Removed<T>]`) |
| `entity.Run`: the components in the job's `WriteMask` | `Load(…, markWritten: false)`, `LoadEntitiesInto(…, markWritten: false)` |

```csharp tab="Changed<T>"
ulong mark = world.ChangeTick;
world.Update();
int changed = world.Count<Health>(QueryFilter.Create().Changed<Health>(mark));
```

```csharp tab="Mut<T>"
public class ClampSystem : EcsSystem
{
    [ForEach]                                        // stamps only the rows it writes
    static void Clamp(Mut<Health> hp)
    {
        if (hp.Value.Value > 100) hp.Write() = new Health(100);
    }
}
```

```csharp tab="Per client"
// One filter, kept in a field, run with each client's acknowledged tick.
private static readonly QueryFilter Dirty = QueryFilter.Create().ChangedAny<Health, Mana>(0);
```

```csharp tab="Per client"
ulong ack = world.ChangeTick;                       // a client's acknowledged tick
world.Update();
int toSend = world.Count<Health>(Dirty.Since(ack));

using var replicated = new World(new WorldOptions { DestroyLogCapacity = 4096 });
ulong seen = replicated.ChangeTick;
replicated.Update();
var gone = new EntityId[4096];
if (!replicated.DestroyedSince(seen, gone, out int goneCount)) { /* older than the log: send everything */ }
```

[whole table of writes](/en/docs/guide/change-tracking#what-counts-as-a-write).

## Indexes, relations, hierarchy, groups [#indexes]

| Call | Does |
| --- | --- |
| `world.Index<T, TKey>()` (`world.TIndex`) | The value index of `T` |
| `index.Find(key)` / `TryFind(key, out e)` / `Count(key)` | Matching entities, one, how many |
| `index.Find(key).Count` / `relations.Find(target).Count` | How many the loop walks, O(1), to size a buffer |
| `index.KeyCount` / `relations.TargetCount` | How many distinct keys / targets are held, O(1) (occupied cells, guilds with a member) |
| `index.Get(key)` / `TryGet(key, out e)` | The one entity of a unique key (`IUniqueIndexed<TKey>`); `Get` throws when none has it |
| `index.Range(min, max)` / `RangeDescending` / `Ascending()` / `Descending()` | Sorted walks, for a comparable key |
| `index.WhenTargetDestroyed(TargetPolicy.Keep / Remove / Destroy)` | What an `EntityId` link does when its target dies |
| `entity.Link(r)` / `Unlink<T>(target)` / `Links<T>(target)` | Many-to-many links |
| `world.Relations<T>()` then `Find(target)` / `Count(target)` | Who links to a target |
| `world.Children(parent)` | Entities whose `ChildOf` names the parent; destroying the parent destroys them (`ChildOf` starts with `TargetPolicy.Destroy`) |
| `world.Descendants(root)` | The whole subtree, depth first, each entity before its children, root excluded; a `ChildOf` cycle throws `InvalidOperationException` |
| `world.Descendants(root).AddTo(ids, includeRoot: true)` | The root and its subtree appended to a `List<EntityId>`: the entities for `MoveEntities` / `SaveEntities` |
| `world.GroupBy<T>()` | Splits tables by an `IGroup` value |

```csharp
var teams = world.TeamIndex;
var moving = new List<Entity>();
foreach (var member in teams.Find(1)) moving.Add(member);  // collect first: never change Team inside Find
foreach (var member in moving) member.SetTeam(2);           // write indexed components with Set
var ship = world.CreateEntity();
world.CreateEntity(new ChildOf(ship));
foreach (var child in world.Children(ship)) { }
foreach (var part in world.Descendants(ship)) { }  // children, grandchildren, ...
var account = world.CreateEntity(new Account(42));
Entity holder = world.AccountIndex.Get(42);        // the same entity; a second Account(42) would throw
```

Indexed and grouped components are written with `Set`, never through a `ref`
([EECS015](/en/docs/guide/analyzer#eecs015)), and not while a `foreach` walks their index
([EECS042](/en/docs/guide/analyzer#eecs042)). Guides: [Indexes and relations](/en/docs/guide/indexes-and-relations),
[Hierarchy](/en/docs/guide/hierarchy), [Groups](/en/docs/guide/groups).

## Prefabs and bulk operations [#prefabs-and-bulk]

| Call | Does |
| --- | --- |
| `new Prefab().SetX(…)…` / `new Prefab(basePrefab)` | A recipe outside every world, or a variant of one |
| `prefab.AddMember()` / `prefab.Id` | Entities instantiated together; `Id` names a member in links |
| `prefab.SetBuffer(items)` | A `DynamicBuffer<T>` each instance gets a copy of |
| `world.Instantiate(prefab)` / `Instantiate(prefab, span)` | One entity, or a wave in one pass |
| `world.Instantiate(prefab, a, b, …)` / `Instantiate(prefab, span, a, b, …)` | The same with up to 9 components of its own, replacing or adding to the prefab's: one row copy |
| `world.CreateEntities(span, a, b, …)` | A wave with the same values |
| `world.DestroyAll<T…>(filter)` | Destroys every match; returns how many |
| `world.CollectIds<T1..Tn>(span, filter)` | Writes the ids of the first matches into `span`, in query order, until it is full; returns how many ([bounded batch](/en/docs/guide/queries#collect-ids)) |
| `world.DestroyEntities(ids)` | Destroys a list of ids in one pass; returns how many |
| `world.SetAll(value, filter)` / `RemoveAll<T>(filter)` | One component set or removed on every match; `SetAll` skips entities tagged `Retired` unless the filter names it |
| `world.DisableAll<T>(filter)` / `EnableAll<T>(filter)` | One component disabled or enabled on every match |

```csharp
var goblin = new Prefab().SetPosition(0, 0).SetHealth(30);
var wave = new Entity[100];
world.Instantiate(goblin, wave);
var scout = world.Instantiate(goblin, new Velocity(2, 0));   // the prefab's values plus its own
world.SetAll(new Velocity(0, 0), QueryFilter.Create().With<Health>());
world.DestroyAll<Dead>();
```

Guides: [Prefabs](/en/docs/guide/prefabs), [Bulk operations](/en/docs/guide/bulk).

## Dynamic buffers [#dynamic-buffers]

Reads go through `e.Loot` (`ref readonly`, with `Count`, `Capacity`, an indexer and `foreach`); writes take the buffer
by `ref` from `e.WriteLoot()` (or `GetOrAddLoot()`), so each one counts for change tracking.

| Call on `ref DynamicBuffer<T>` | Does |
| --- | --- |
| `Add(item)` / `AddRange(items)` / `Insert(index, item)` | Appends, appends a span, inserts |
| `RemoveAt(index)` / `RemoveAtSwapBack(index)` | Removes keeping the order, or by moving the last element in (O(1)) |
| `Clear()` | Empties it, keeping the capacity |
| `EnsureCapacity(n)` / `TrimExcess()` | Grows once before a known count, gives memory back |
| `AsSpan()` | A `Span<T>` over the elements, for writes in place |
| `SetCount(n)` | Sets the count (added elements `default`) and returns the span to write the whole buffer in place |
| `DynamicBuffer<T>.PoolCapacity = n` (static) | The longest list a dead buffer of `T` gives back to its pool, set once at startup ([pool](/en/docs/guide/dynamic-buffers#pool)) |
| `DynamicBuffer<T>.ReservePool(n)` (static) | Fills the pool with `n` empty lists at startup, after `PoolCapacity` |

```csharp
unit.Set(new DynamicBuffer<Loot>());
ref var loot = ref unit.WriteLoot();
loot.EnsureCapacity(8);
loot.Add(new Loot(7));
loot.RemoveAtSwapBack(0);
```

Guide: [Dynamic buffers](/en/docs/guide/dynamic-buffers).

## Snapshots, saves, migration [#persistence]

| Call | Does |
| --- | --- |
| `world.Capture()` / `Capture(into)` | An in-memory copy; `into` reuses a snapshot's arrays |
| `world.Restore(snapshot)` | Back to the copy; handles from then are valid again |
| `world.Save(writer)` / `Load(bytes)` | A whole world as bytes (managed components need `[NinoType]`); `Load` throws `InvalidDataException` when an unmanaged component's layout changed since the save |
| `world.SaveWithout(writer, exclude)` / `LoadKeeping(bytes, keep, markWritten: false)` | A restart: the save leaves out the components and singletons of a set, the load keeps the singletons of a set as the new process set them |
| `world.SaveEntities(writer, ids)` / `LoadEntities(bytes, handles)` | Related entities to another world or process |
| `ComponentSet.Create().With<T>()….WithSingleton<S>()` | Components (and, for whole-world saves, singletons), built once in a `static readonly` field |
| `world.SaveEntitiesWith(writer, ids, set)` | A record: only the components of the set |
| `world.SaveEntitiesWithout(writer, ids, set)` | Everything but the set: the data a load computes again stays out |
| `world.LoadEntitiesInto(bytes, entities, markWritten: false)` | A record onto entities that exist; `markWritten: false` keeps it from counting as changed |
| `world.MoveEntities(target, ids, moved)` | A group to another world of the thread, no encoding; skips retired entities (kept for cleanup), and leaves cleanup components behind |
| `world.RemoveTypes(assembly or context)` | Drops a plugin's types before its context unloads |

```csharp tab="Snapshot and save"
var save = world.Capture();
world.Update();
world.Restore(save);

var bytes = new System.Buffers.ArrayBufferWriter<byte>();
world.Save(bytes);
using var copy = new World();
copy.Load(bytes.WrittenSpan);
```

```csharp tab="Restart"
// A restart: the runtime state and the configuration are not saved; the new process brings its own.
private static readonly ComponentSet Runtime = ComponentSet.Create().WithSingleton<Config>().With<Session>();
private static readonly ComponentSet NewConfig = ComponentSet.Create().WithSingleton<Config>();
```

```csharp tab="Restart"
var restart = new System.Buffers.ArrayBufferWriter<byte>();
world.SaveWithout(restart, Runtime);                       // the old process, at shutdown
using var next = new World();
next.SetConfig(64);                                 // the new version's configuration
next.LoadKeeping(restart.WrittenSpan, NewConfig, markWritten: false);   // Config stays as set
```

Guides: [Snapshots](/en/docs/guide/snapshots), [Saves](/en/docs/guide/saves),
[Migration and unloading](/en/docs/guide/migration-and-unload#records).

## World options [#world-options]

| `WorldOptions` | Default | Does |
| --- | --- | --- |
| `InitialEntityCapacity` | 1024 | Entity records allocated up front |
| `ParallelSystems` | `false` | Runs systems with no order and no conflict at the same time |
| `MaxDegreeOfParallelism` | processor count | Threads one parallel run uses at most |
| `MeasureSystems` | `false` | Records `system.Stats` |
| `SystemErrors` | `SystemErrorPolicy.Throw` | `Disable` switches a failing system off and goes on |
| `DestroyLogCapacity` | 0 (off) | Capacity of the destroy log `DestroyedSince` reads, 16 bytes per record |

```csharp
using var server = new World(new WorldOptions { ParallelSystems = true, SystemErrors = SystemErrorPolicy.Disable });
```

Guide: [Threading](/en/docs/guide/threading).
