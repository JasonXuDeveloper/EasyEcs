A static method that handles each record the passes emitted ([`Emit`](/en/docs/reference/emit)) once: its first parameter is the record, `in T`, and the generator writes the pass that runs it on every record of [`Emitted`](/en/docs/reference/emitted) in the order they were emitted (row order of each pass, passes in the order they ran), then clears them, so none is handled twice. In an [`EcsSystemAttribute`](/en/docs/reference/ecssystemattribute) system it runs in declaration order with the system's [`ForEachAttribute`](/en/docs/reference/foreachattribute) methods; in any other type it gets an entry point, a static member named like the method that takes the world and the method's other values. The other parameters are what a [ForEach] method takes beside its components: singletons (`ref` / `in`), [`Lookup`](/en/docs/reference/lookup), [`Emit`](/en/docs/reference/emit) of another record type, the [`World`](/en/docs/reference/world), and (outside a system) values of any other type. One thread, no allocation; the system writes [`Emitted`](/en/docs/reference/emitted). A pass that throws clears nothing: the records stay, the ones handled included. Records added to [`Emitted`](/en/docs/reference/emitted) while the pass runs are cleared unhandled (an [`Emit`](/en/docs/reference/emit) of the same record is refused: EECS105).

```csharp
[ForEachRecord]
static void Send(in EntityUpdate update, ref Stats stats) => stats.Sent += update.Viewers;   // each update, once
```
