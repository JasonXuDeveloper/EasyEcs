```csharp
public readonly ref struct Mut<T> where T : struct, IComponent
```

A component of the entity a `[ForEach]` method visits that counts as written only when the method writes it: `static void Aim(Mut<Target> target, in Position p) => target.SetIfChanged(new Target(Nearest(p)))`. A `ref` parameter of a tracked component ([`ITrackChanges`](/en/docs/reference/itrackchanges)) stamps every row the method visits, so `[Changed<T>]` readers visit rows whose value never changed; through a [`Mut`](/en/docs/reference/mut) only the rows the method writes ([`Mut.Write`](/en/docs/reference/mut#write), a [`Mut.SetIfChanged`](/en/docs/reference/mut#setifchanged) that changed the value) are stamped, each with the exact per-row stamp of [`Entity.Get`](/en/docs/reference/entity#get). Reading [`Mut.Value`](/en/docs/reference/mut#value) stamps nothing.

The scheduler treats the parameter as a write of `T` (a parallel stage never runs the system beside a reader of it). It works in per-entity methods, also `[ForEach(Parallel = true)]` ones and ones that change structure (a write after the entity moved stamps its new row); batch methods take spans and stamp their runs. For a component that does not track changes it is a plain `ref`. Valid for the call it is passed to (a ref struct). An indexed or grouped component is not written through a ref (EECS015).

## Methods

### `SetIfChanged` [#setifchanged]

```csharp
public bool SetIfChanged(in T value);
```

Store `value` and stamp the row only when it differs from the component's value: true when it did. Equality is `IEquatable` when `T` implements it (record structs do), else the bytes of an unmanaged `T`; a managed `T` without `IEquatable` throws (`NotSupportedException`). O(size of T), allocation-free.

**Complexity** ([API table](/en/docs/api)): O(size of `T`), plus a `Write()` when it differs

### `Write` [#write]

```csharp
public ref T Write();
```

The component by `ref`, stamped as written (a tracked component: its row, found by one meta lookup when the method may move the entity). Call it once per write, when the method knows it writes. O(1).

**Complexity** ([API table](/en/docs/api)): O(1): one stamp (plus one entity lookup in a method that changes structure or runs in parallel)
