实体的配方：一组不属于任何 World 的组件值，所以任何查询都看不到它。[`World.Instantiate`](/zh/docs/reference/world#instantiate) 在任意 World 里创建一个实体，带上每个值的副本。建一次（用代码或配置）并保存起来；只要没人在改它，一个预制体可以同时给多个线程上的 World 使用。

预制体可以有成员（[`Prefab.AddMember`](/zh/docs/reference/prefab#addmember)）：一个 Boss 带着它的小怪和坐骑。实例化其中任何一个，都会创建整组；指向某个成员的 [`EntityId`](/zh/docs/reference/entityid) 字段（[`Prefab.Id`](/zh/docs/reference/prefab#id)，比如 `new ChildOf(boss.Id)`）会指向那个成员新建的实体，其余的都变成 [`EntityId.Null`](/zh/docs/reference/entityid#null)：预制体里的 id 只能指成员（World 里某个实体的 id 可能恰好和成员的一样）。[`Entity`](/zh/docs/reference/entity) 字段原样复制：指向 World 里实体的关系，实例化之后再设置。

### `Prefab` [#ctor-2]

```csharp
public Prefab(Prefab basePrefab);
```

复制 `basePrefab`（和它的成员）的每个值，得到一个能单独修改的预制体：比如配置好的 NPC 的一个变体。之后改其中一个，另一个不受影响（是复制，不是继承）。O(组件数)。

## 方法 [#methods]

### `Absent` [#absent]

```csharp
public Prefab Absent<T>() where T : struct, IComponent;
```

给配方一列 `T`，但不带这个组件：实例没有它，但它们的表给它留了位置，所以之后加上它（每个 tick 设置又清除的标签、部分实例会进入的状态）只翻转一个存在位，不把行移到别的表，所有实例都留在一张表里。配方原有的值会丢掉。返回这个预制体。O(1)。

**复杂度**（[API 表](/zh/docs/api)）：O(1)
