```csharp
public struct Retired : IComponent
```

Tag of a retired entity: `Destroy` found [`ICleanupComponent`](/en/docs/reference/icleanupcomponent)s on it, so it took the other components away and kept the entity alive until its last cleanup component is removed (then the entity is freed: destroyed). Select such entities with `With<Retired>` (a cleanup system) and new ones with `Without<Retired>` (an acquiring system).

Saves record it by its former name (`EasyEcs.Destroyed`, the tag's name before 4.7), so saves written before the rename load their retired entities.
