模板在一个格子周围读什么，它决定 [`PaddedTile.Rows`](/zh/docs/reference/paddedtile#rows) 访问哪些行：某一行读到的行里有不为零的格子时，访问这一行。只要读到的全是零、结果就是零的模板（水不会凭空流出，冷处不会升温），就会跳过安静的行，结果不变。
