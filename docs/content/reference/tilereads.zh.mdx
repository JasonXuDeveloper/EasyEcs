模板在一个格子周围读什么，它决定 [`PaddedTile.Rows`](/zh/docs/reference/paddedtile#rows) 访问哪些行：某一行读到的行里有不为零的格子时，访问这一行（一行算上它的 halo 格子，所以沿 x 读的模板只需要这一行）。只要读到的全是零、结果就是零的模板（水不会凭空流出，冷处不会升温），就会跳过安静的行，结果不变。一行能读多远由形状的 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo) 决定。

### `Above` [#above]

```csharp
Above = 4;
```

它上方各层中它上面的行。

### `All` [#all]

```csharp
All = Cross | Diagonals;
```

周围的每一行：3D 27 点模板，也是稳妥的默认值。

### `Below` [#below]

```csharp
Below = 8;
```

它下方各层中它下面的行。

### `Cross` [#cross]

```csharp
Cross = Layer | Above | Below;
```

这一行、它的四邻和上下的行：3D 七点模板。

### `Diagonals` [#diagonals]

```csharp
Diagonals = 16;
```

它上方和下方各层中它北边和南边的行：3D 的棱和角。

### `Layer` [#layer]

```csharp
Layer = Self | NorthSouth;
```

这一行和它的四邻：2D 五点或九点模板。

### `NorthSouth` [#northsouth]

```csharp
NorthSouth = 2;
```

同一层中它北边和南边的行，连同它们的 halo 格子（也就是 2D 的对角）。

### `Self` [#self]

```csharp
Self = 1;
```

这一行自己，连同它前后的格子（西和东）。
