标记一个追踪变更的组件：每一行都记下最后一次写入时 World 的 [`World.ChangeTick`](/zh/docs/reference/world#changetick)，`[Changed<T>]` / `QueryFilter.Changed<T>(since)` 选出系统上次运行以来写过的行。任何 `ref` 访问都算写入：`[ForEach]` 方法和 job 的 `ref` 参数、`Query` 的元素、`Entity.Get` / `Add` / `GetOrAdd` / `Set`，以及创建实体、添加组件。[`Mut`](/zh/docs/reference/mut) 参数只算它写过的行，`SetIfChanged` 只算值不同的写入。每行多 8 字节，每次写入多一次存储；不追踪的组件没有任何开销。
