### `DestroyLogCapacity` [#destroylogcapacity]

```csharp
public int DestroyLogCapacity { get; init; }
```

Capacity of the destroy log (default 0: off): the ids of the last this many destroyed entities (no longer alive: a retired one is logged when it is freed), each with the change tick of its destruction, which [`World.DestroyedSince`](/en/docs/reference/world#destroyedsince) reports to readers that each keep their own tick (one replication mark per client). Preallocated (16 bytes per record); a destroy then writes one record, and with the log off it costs nothing. Size it to the destroys of the longest gap a reader may leave between two reads: an older reader is told to resynchronize ([`World.DestroyLogOldestTick`](/en/docs/reference/world#destroylogoldesttick)).

### `MaxDegreeOfParallelism` [#maxdegreeofparallelism]

```csharp
public int MaxDegreeOfParallelism { get; init; }
```

Threads one parallel run uses at most (default: processor count): systems run by [`WorldOptions.ParallelSystems`](/en/docs/reference/worldoptions#parallelsystems), and the row chunks of parallel `[ForEach]` methods, `ForEachParallel` and `ForEachEntityParallel` (which run in chunks whether [`WorldOptions.ParallelSystems`](/en/docs/reference/worldoptions#parallelsystems) is on or not). The calling thread is one of them; the others are the process's helper threads, not the thread pool's: a fixed set of background threads, as many as the largest value a world asked for minus one, started when a world first runs work in parallel and shared by every world. No thread starts in steady state, and the per-thread memory of the core (a tile's texture, a `Scratch<T>`) is set up on all of them as soon as one thread sets up its own.

### `MeasureSystems` [#measuresystems]

Measure every system run into [`SystemHandle.Stats`](/en/docs/reference/systemhandle#stats): its time and allocated bytes (two timestamp and two allocation-counter reads per run, and per helper chunk of a parallel `[ForEach]`), and the entities its `[ForEach]` methods visited (one count per pass when it starts). Default false.

### `ParallelSystems` [#parallelsystems]

```csharp
public bool ParallelSystems { get; init; }
```

Run systems with no order between them at the same time (on the process's helper threads) when their generated access does not conflict ([`SystemAccess`](/en/docs/reference/systemaccess)). Default false: one owner thread per world is the recommended model.
