### `DestroyLogCapacity` [#destroylogcapacity]

```csharp
public int DestroyLogCapacity { get; init; }
```

Capacity of the destroy log (default 0: off): the ids of the last this many destroyed entities (no longer alive: a retired one is logged when it is freed), each with the change tick of its destruction, which [`World.DestroyedSince`](/en/docs/reference/world#destroyedsince) reports to readers that each keep their own tick (one replication mark per client). Preallocated (16 bytes per record); a destroy then writes one record, and with the log off it costs nothing. Size it to the destroys of the longest gap a reader may leave between two reads: an older reader is told to resynchronize ([`World.DestroyLogOldestTick`](/en/docs/reference/world#destroylogoldesttick)).

Measure every system run into [`EcsSystem.Stats`](/en/docs/reference/ecssystem#stats): its time and allocated bytes (two timestamp and two allocation-counter reads per run, and per helper chunk of a parallel `[ForEach]`), and the entities its `[ForEach]` methods visited (one count per pass when it starts).
