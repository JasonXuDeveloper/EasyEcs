```csharp
public struct DynamicBuffer<T> : IComponent, ITracked
```

每个实体一个 `T` 列表，作为组件存放：背包、路径、这个 tick 的命中记录。写入要通过组件的 `ref`（`[ForEach]` 方法和 job 的 `ref` 参数、[`Entity.Get`](/zh/docs/reference/entity#get)），所以它和 [`ITracked`](/zh/docs/reference/itracked) 组件的任何写入一样会记录下来，`[Changed<DynamicBuffer<T>>]` 能选出列表变过的实体。通过 `in` 或 [`Entity.Read`](/zh/docs/reference/entity#read) 拿到的列表是只读的：修改方法（[`DynamicBufferExtensions`](/zh/docs/reference/dynamicbufferextensions)）接收 `ref this`，所以通过只读引用写入根本编译不过。快照会复制元素（[`World.Capture`](/zh/docs/reference/world#capture)）；搬行时列表跟着走。在容量以内添加元素不分配内存。

#### 备注 [#remarks]

`new DynamicBuffer<T>()` 不持有列表：每个实体的列表在第一次写入时才创建（用 [`DynamicBufferExtensions.EnsureCapacity`](/zh/docs/reference/dynamicbufferextensions#ensurecapacity) 预留空间），所以同一个值可以用来创建很多实体。列表存放在组件引用的一个对象里，复制组件，副本也会引用同一个列表：分析器禁止复制（EECS012），要通过实体访问列表。
