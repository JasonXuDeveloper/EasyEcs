Whether a [`ForEachAttribute`](/en/docs/reference/foreachattribute) method runs as a vector loop ([`ForEachAttribute.Simd`](/en/docs/reference/foreachattribute#simd)). A method qualifies when it is static, runs on one thread, makes no structural change, takes components (by `ref` or `in`), singletons and values, and computes with operations that have an exact vector counterpart.

## Fields

### `Auto` [#auto]

```csharp
Auto = 0;
```

A vector loop when the method qualifies; EECS055 names the reason when one that looks eligible does not.

### `Off` [#off]

```csharp
Off = 2;
```

One row at a time, as written.

### `Require` [#require]

```csharp
Require = 1;
```

A vector loop, or the build fails with the reason (EECS056).
