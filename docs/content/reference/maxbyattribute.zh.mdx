保留键最大的那一行的归约的键（MPI 的 `MAXLOC`，LINQ 的 `MaxBy`）：`Identity` 里键是它的 `MinValue`（`float` 和 `double` 是 −∞），`Combine` 只在 `right` 的键更大时取 `right`，所以相等时保留先到的行（见 [`MinByAttribute`](/zh/docs/reference/minbyattribute)）。
