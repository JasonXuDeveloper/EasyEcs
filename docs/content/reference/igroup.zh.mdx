标记一个按值拆分表的组件：在调用过 [`World.GroupBy`](/zh/docs/reference/world#groupby) 的 World 里，[`IGroup.Group`](/zh/docs/reference/igroup#group) 不同的实体放在不同的表，所以只查询一组（[`QueryFilter.InGroup`](/zh/docs/reference/queryfilter#ingroup)）时只遍历这一组的行，这些行在内存里是连续的（一个区域、一张地图、一场对局、一支队伍）。用 `Set` 写入新值会把实体搬到新组的表，所以分组组件和被索引的组件一样，不能通过 `ref` 写入（EECS015）。
