```csharp
public readonly struct ComponentSet
```

一组组件类型，建一次就一直留着（放在 `static readonly` 字段里）：存档要写的组件（[`World.SaveEntities`](/zh/docs/reference/world#saveentities-2)），也就是只记录需要持久化的数据、不带周围运行时状态的那份记录。`ComponentSet.Create().With<Bank>().With<Deposits>()`；注册时才知道类型的框架按 `Type` 添加。每次调用都返回一个新集合。

### `With` [#with]

```csharp
public ComponentSet With(Type type);
```

这个集合加上组件类型 `type`（实现 [`IComponent`](/zh/docs/reference/icomponent) 的结构体）。冷路径：一次查找。

**异常**

- `ArgumentException`：`type` 不是生成器或某个 World 登记过的组件类型。
