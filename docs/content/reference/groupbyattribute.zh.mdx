[[Group]](/zh/docs/reference/groupattribute)，并且每个 World 都按这个成员给组件的表分组（[`World.GroupBy`](/zh/docs/reference/world#groupby)），从它第一张含这个组件的表开始：分组过滤条件（[`QueryFilter.InGroup`](/zh/docs/reference/queryfilter#ingroup)）在每个 World 里都只访问这一组的表，不用记着调用设置方法。`public partial record struct Zone([GroupBy] int Id) : IComponent;` 加在手写的 [`IGroup`](/zh/docs/reference/igroup) 的 `Group` 属性上时，它只让每个 World 都按它分组。
