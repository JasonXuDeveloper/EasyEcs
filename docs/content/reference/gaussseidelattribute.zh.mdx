用在推进瓦片的 `[ForEach]` 方法上（一个 `ref Tile<TCell, TTile>` 参数）：用 Gauss-Seidel 代替 Jacobi。这一步原地写瓦片的格子，所以写过的一行就是后面的行读到的值；方法即一次扫描，在瓦片上反复运行，直到一次扫描什么都没改变（最多 [`GaussSeidelAttribute.MaxSweeps`](/zh/docs/reference/gaussseidelattribute#maxsweeps) 次）。瓦片按颜色逐色推进，颜色由键的奇偶决定（面模板两种颜色，9 点模板四种，27 点八种）：同一颜色的两个瓦片互不相邻，所以一种颜色的瓦片同时并行推进，读前面颜色留下的格子，结果和线程数无关。一次扫描没有改变的瓦片会休眠，直到旁边的瓦片改变了它读的边缘。适合会稳定下来的松弛（`d = Min(neighbor + cost)`：距离场、洪水填充、气味），一次遍历代替每跨过一个格子一次。

```csharp
[ForEach(Parallel = true), GaussSeidel]
static void Spread(ref Tile<Scent, Ground> scent) { scent.ExchangeHalo(); foreach (var row in scent.Rows()) ... scent.Write(row) ... }
```
