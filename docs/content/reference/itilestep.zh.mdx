public interface ITileStep<TCell, TTile, TLane> where TCell : unmanaged where TTile : struct, IComponent, ITileShape

模板的一步，供 [`PaddedTile.Steps`](/zh/docs/reference/paddedtile#steps) 使用（时间分块）：一个 struct，它的静态 [`ITileStep.Step`](/zh/docs/reference/itilestep#step) 根据周围的格子算出 16 字节格子的下一个值。Steps 在这一步还能算的每个纹素上运行它，所以方法体就是单步时的那个。

#### 类型参数 [#type-parameters]

- `TCell`：格子。
- `TTile`：分块的组件和形状。
- `TLane`：这一步计算用的道：float 格子用 `float`，byte 格子用 `byte`。

## 属性 [#properties]

### `Reach` [#reach]

```csharp
static abstract int Reach { get; }
```

这一步读多远，以格子、行和层计（五点、九点、七点或 27 点模板为 1）：Steps 运行 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo) / Reach 步，halo 是 Reach 的整数倍。

### `Reads` [#reads]

```csharp
static virtual TileReads Reads { get; }
```

这一步在格子周围读什么，决定它跳过哪些行（默认 [`TileReads.All`](/zh/docs/reference/tilereads#all)）。

## 方法 [#methods]

### `Step` [#step]

```csharp
static abstract Vector128<TLane> Step(TileCursor<TCell, TTile> cells, int x);
```

游标所在行从第 `x` 个格子起 16 字节格子的下一个值：用 `cells.Load128<TLane>(x + dx, dy, dz)` 读它们和它们的邻居，|dx|、|dy|、|dz| ≤ Reach。
