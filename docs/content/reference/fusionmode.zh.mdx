public enum FusionMode

Whether a [`ForEachAttribute`](/zh/docs/reference/foreachattribute) method shares one walk with its neighbors in its system ([`ForEachAttribute.FusionMode`](/zh/docs/reference/foreachattribute#fusionmode)). [`SystemInfo.Loops`](/zh/docs/reference/systeminfo#loops) names the methods each method shares its walk with.

## 字段 [#fields]

### `Auto` [#auto]

```csharp
Auto = 0;
```

One walk with the methods next to it when that gives the same results; EECS093 names a near miss.

### `Off` [#off]

```csharp
Off = 2;
```

A walk of its own.

### `Require` [#require]

```csharp
Require = 1;
```

One walk with the method declared before it, or the build fails with the reason (EECS094).
