[`ForEachAttribute`](/zh/docs/reference/foreachattribute) 方法是否和系统里相邻的方法共用一次遍历（[`ForEachAttribute.FusionMode`](/zh/docs/reference/foreachattribute#fusionmode)）。[`SystemInfo.Loops`](/zh/docs/reference/systeminfo#loops) 列出每个方法和哪些方法共用遍历。

## 字段 [#fields]

### `Auto` [#auto]

```csharp
Auto = 0;
```

结果相同时和相邻的方法共用一次遍历；差一点就能融合时，EECS093 说明原因。

### `Off` [#off]

```csharp
Off = 2;
```

单独遍历。

### `Require` [#require]

```csharp
Require = 1;
```

和前一个声明的方法共用一次遍历，否则构建失败并给出原因（EECS094）。
