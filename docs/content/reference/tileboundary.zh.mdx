分块没有邻居的地方 halo 里放什么（[`ITileShape.Boundary`](/zh/docs/reference/itileshape#boundary)），即网格的边界条件。周期网格不需要：它的 [`ITile.Beside`](/zh/docs/reference/itile#beside) 回绕，每个分块都有邻居。

## 字段 [#fields]

### `Clamp` [#clamp]

```csharp
Clamp = 1;
```

重复分块自己的边缘格子：−k 处的 halo 格子是格子 0。

### `Fill` [#fill]

```csharp
Fill = 0;
```

[`Tile.Pad`](/zh/docs/reference/tile#pad-2) 的填充值（默认零）：Dirichlet 边界。

### `Mirror` [#mirror]

```csharp
Mirror = 2;
```

分块自己的格子在边缘处镜像：−k 处的 halo 格子是格子 k − 1（零通量的 Neumann 边界）。
