[`ForEachAttribute`](/zh/docs/reference/foreachattribute) 方法是否以向量循环运行（[`ForEachAttribute.SimdMode`](/zh/docs/reference/foreachattribute#simdmode)）。符合条件的方法：是静态方法，不做结构变更（在一个线程上或并行都一样），只接收组件（`ref` 或 `in`）及其 [`Maybe`](/zh/docs/reference/maybe)、单例和值，并且只用有精确向量对应的运算。[`World.DescribeSchedule`](/zh/docs/reference/world#describeschedule) 列出系统每个方法得到的循环（[`SystemInfo.Loops`](/zh/docs/reference/systeminfo#loops)）。

## 字段 [#fields]

### `Auto` [#auto]

```csharp
Auto = 0;
```

方法符合条件时生成向量循环；看起来适合却不符合时，EECS055 说明原因。

### `Off` [#off]

```csharp
Off = 2;
```

按写法一次一行。

### `Require` [#require]

```csharp
Require = 1;
```

生成向量循环，否则编译失败并说明原因（EECS056）。
