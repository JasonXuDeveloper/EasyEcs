[`ForEachAttribute`](/zh/docs/reference/foreachattribute) 方法是否以向量循环运行（[`ForEachAttribute.Simd`](/zh/docs/reference/foreachattribute#simd)）。符合条件的方法：是静态方法，在一个线程上跑，不做结构变更，只接收组件（`ref` 或 `in`）、单例和值，并且只用有精确向量对应的运算。

## 字段 [#fields]

### `Auto` [#auto]

```csharp
Auto = 0;
```

方法符合条件时生成向量循环；看起来适合却不符合时，EECS055 说明原因。

### `Off` [#off]

```csharp
Off = 2;
```

按写法一次一行。

### `Require` [#require]

```csharp
Require = 1;
```

生成向量循环，否则编译失败并说明原因（EECS056）。
