```csharp
public interface IIndexed<TKey> where TKey : IEquatable<TKey>
```

A component whose [`IIndexed.Key`](/en/docs/reference/iindexed#key) the world indexes: `world.Index<T, TKey>().Find(key)` enumerates the entities whose `TKey` equals a value (an item's owner, a player's name, a cell of a grid). An [`EntityId`](/en/docs/reference/entityid) key makes the component a relation: `ChildOf(EntityId Parent)` indexed by its parent finds the children of an entity. The index follows the values written with `Set` and `CreateEntity` as they are written, so an indexed component is never written through a `ref` (`Get`, `ref` parameters, query items): the analyzer reports such writes (EECS015).
