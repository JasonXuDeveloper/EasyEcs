[`ForEachAttribute`](/zh/docs/reference/foreachattribute) 方法的向量循环可以改变哪些浮点结果。

## 字段 [#fields]

### `Exact` [#exact]

```csharp
Exact = 0;
```

每个结果都与方法本身逐位相同：归约里的浮点求和保持一次一行。

### `Fast` [#fast]

```csharp
Fast = 1;
```

归约里的浮点求和可以按另一种顺序（每个向量通道各加各的行）相加，所以舍入结果不同；Sin、Cos、Exp、Log、Log2 和 Hypot 采用 .NET 的向量近似：结果可能与方法本身不同，不同机器之间也可能不同。
