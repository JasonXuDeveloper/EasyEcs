public interface ITileShape

分块的形状，写在让实体成为网格分块的组件上（[`ITile`](/zh/docs/reference/itile)）：实体的格子共 [`ITileShape.Width`](/zh/docs/reference/itileshape#width) × [`ITileShape.Depth`](/zh/docs/reference/itileshape#depth) × [`ITileShape.Height`](/zh/docs/reference/itileshape#height) 个，存在它的 `DynamicBuffer<TCell>` 里：每行 [`ITileShape.Width`](/zh/docs/reference/itileshape#width) 个（x），每层 [`ITileShape.Depth`](/zh/docs/reference/itileshape#depth) 行（z），共 [`ITileShape.Height`](/zh/docs/reference/itileshape#height) 层（y）：格子 (x, y, z) 在 `(y * Depth + z) * Width + x`。都是静态成员，JIT 读一次：分块的代码按它的形状编译，每个尺寸和依赖它的分支都折叠成常量。

没有邻居的地方 halo 里放什么（默认 [`TileBoundary.Fill`](/zh/docs/reference/tileboundary#fill)）。

### `Depth` [#depth]

```csharp
static abstract int Depth { get; }
```

每层的行数（z），1 到 64（一层的活跃行是一个 64 位字）。

### `Faces` [#faces]

```csharp
static virtual TileFaces Faces { get; }
```

有邻居的面（默认 [`TileFaces.Sides`](/zh/docs/reference/tilefaces#sides)）；其他面的 halo 按 [`ITileShape.Boundary`](/zh/docs/reference/itileshape#boundary) 处理。[`TileFaces.Below`](/zh/docs/reference/tilefaces#below) 和 [`TileFaces.Above`](/zh/docs/reference/tilefaces#above) 只对不止一层的分块有效；一维分块（只有一行）声明 `West | East`。

### `Halo` [#halo]

```csharp
static virtual int Halo { get; }
```

halo 的宽度，以格子计（默认 1）：MPI halo 交换的 ghost 格子，CUDA 分块的 apron。模板读到 r 个格子、行或层之外，就需要 r。最多是分块在每条有邻居的轴上的长度（[`TileBoundary.Mirror`](/zh/docs/reference/tileboundary#mirror) 时是每条轴）：halo 不会越过旁边的分块。

### `Height` [#height]

```csharp
static virtual int Height { get; }
```

层数（y），至少 1：1（默认）是 2D 分块，它上下没有层。

### `Neighbourhood` [#neighbourhood]

```csharp
static virtual TileNeighbourhood Neighbourhood { get; }
```

找哪些周围的分块，读进 halo 的棱和角（默认 [`TileNeighbourhood.Faces`](/zh/docs/reference/tileneighbourhood#faces)）。

### `Width` [#width]

```csharp
static abstract int Width { get; }
```

每行的格子数（x），至少 1。
