分块的形状，写在让实体成为网格分块的组件上（[`ITile`](/zh/docs/reference/itile)）：实体的格子共 [`ITileShape.Width`](/zh/docs/reference/itileshape#width) × [`ITileShape.Depth`](/zh/docs/reference/itileshape#depth) × [`ITileShape.Height`](/zh/docs/reference/itileshape#height) 个，存在它的 `DynamicBuffer<TCell>` 里：每行 [`ITileShape.Width`](/zh/docs/reference/itileshape#width) 个（x），每层 [`ITileShape.Depth`](/zh/docs/reference/itileshape#depth) 行（z），共 [`ITileShape.Height`](/zh/docs/reference/itileshape#height) 层（y）：格子 (x, y, z) 在 `(y * Depth + z) * Width + x`。都是静态成员，JIT 读一次：分块的代码按它的形状编译。

## 属性 [#properties]

### `Depth` [#depth]

```csharp
static abstract int Depth { get; }
```

每层的行数（z），1 到 64（一层的活跃行是一个 64 位字）。

### `Faces` [#faces]

```csharp
static virtual TileFaces Faces { get; }
```

有邻居的面（默认 [`TileFaces.Sides`](/zh/docs/reference/tilefaces#sides)）；其他面的那一圈是填充值。[`TileFaces.Below`](/zh/docs/reference/tilefaces#below) 和 [`TileFaces.Above`](/zh/docs/reference/tilefaces#above) 只对不止一层的分块有效。

### `Height` [#height]

```csharp
static virtual int Height { get; }
```

层数（y），至少 1：1（默认）是 2D 分块，它上下没有层。

### `Width` [#width]

```csharp
static abstract int Width { get; }
```

每行的格子数（x），至少 1。
