Marks a component whose value splits tables: in a world that called [`World.GroupBy`](/en/docs/reference/world#groupby), entities with different [`IGroup.Group`](/en/docs/reference/igroup#group)s live in different tables, so a query of one group ([`QueryFilter.InGroup`](/en/docs/reference/queryfilter#ingroup)) walks only its own rows, contiguous in memory (a zone, a map, a match, a team). Writing a new value with `Set` moves the entity to its group's table, so a grouped component is never written through a `ref` (EECS015), like an indexed one.
