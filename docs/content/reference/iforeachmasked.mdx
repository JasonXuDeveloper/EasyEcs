A batch job that also takes a word of 64 rows of which only some pass (a filter that tests presence bits or change ticks): `World.ForEachMasked` hands it the whole word with the passing rows as bits, where [`IForEachBatch`](/en/docs/reference/iforeachbatch) would get each run of passing rows apart. A vector loop computes every lane and keeps the passing ones. `[ForEach]` methods with a vector loop compile to this.

One type per number of components, 1 to 9 (generated from one template); the members below are those of each, shown for `IForEachMasked<T1>`.

## Methods

### `Execute` [#execute]

```csharp
void Execute(EntitySpan entities, ulong rows, Span<T1> c1);
```

Rows of one word: row i (of `entities` and of every span) passes when bit i of `rows` is set; the job leaves the other rows as they are (it may store their values back unchanged). Bit 0 is set, and no bit at or past the spans' length.
