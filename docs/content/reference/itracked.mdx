public interface ITracked

Marks a component whose changes are tracked: every row records the world's [`World.ChangeTick`](/en/docs/reference/world#changetick) of its last write, and `[Changed<T>]` / `QueryFilter.Changed<T>(since)` select the rows written since a system last ran. A write is any `ref` access: `ref` parameters of `[ForEach]` methods and jobs, `Query` items, `Entity.Get` / `Add` / `GetOrAdd` / `Set`, and creating the entity or adding the component. A [`Mut`](/en/docs/reference/mut) parameter counts only the rows it writes, and `SetIfChanged` only a value that differs. Costs 8 bytes per row and one store per write; untracked components pay nothing.
