[[EcsSystem]](/zh/docs/reference/ecssystemattribute) 的一个静态方法，系统每次运行时在它的 [ForEach] 方法之前调用。它接收 [`World`](/zh/docs/reference/world)、[`SystemHandle`](/zh/docs/reference/systemhandle)、两者或都不接收，返回 void；每个系统一个（EECS076）。它可能碰任何数据，所以这个系统永远不和别的系统共用并行阶段（[`SystemAccess.RunAlone`](/zh/docs/reference/systemaccess#runalone)）。
