不进任何存档的组件或单例：重启时会重建的运行时状态（连接、缓存、服务句柄）。每种存档都不写它（[`World.Save`](/zh/docs/reference/world#save)、[`World.SaveWithout`](/zh/docs/reference/world#savewithout)、实体存档，集合里点名了也不写），所以它不需要 Nino 格式化器；读档时保留 World 自己的单例值（和 [`World.LoadKeeping`](/zh/docs/reference/world#loadkeeping) 一样）。快照（[`World.Capture`](/zh/docs/reference/world#capture)）和 World 之间的迁移（[`World.MoveEntities`](/zh/docs/reference/world#moveentities)）照常复制它。
