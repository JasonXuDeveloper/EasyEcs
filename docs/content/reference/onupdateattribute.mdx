The static method of an [[EcsSystem]](/en/docs/reference/ecssystemattribute) called on every run of the system, before its [ForEach] methods. It takes the [`World`](/en/docs/reference/world), the [`SystemHandle`](/en/docs/reference/systemhandle), both or neither, and returns void; one per system (EECS076). It may touch anything, so the system never shares a parallel stage ([`SystemAccess.RunAlone`](/en/docs/reference/systemaccess#runalone)).
