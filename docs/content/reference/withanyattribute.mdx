public sealed class WithAnyAttribute<T> : Attribute where T : struct, IComponent

The [`ForEachAttribute`](/en/docs/reference/foreachattribute) method requires at least one of the components named by its `[WithAny<T>]` attributes (not passed in): `[ForEach, WithAny<Burning>, WithAny<Poisoned>]`. On a system group, every [ForEach] method of the group's systems requires one of the group's.
