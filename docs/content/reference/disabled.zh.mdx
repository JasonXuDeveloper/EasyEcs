public struct Disabled<T> : IComponent where T : struct, IComponent

`T` 处于禁用状态（[`Entity.Disable`](/zh/docs/reference/entity#disable)）的实体带的标签：实体保留 `T` 的值，但在 [`Entity.Enable`](/zh/docs/reference/entity#enable) 还回来之前，查询、`Has` 和 `Get` 都当它不存在。像查询别的标签一样查询它（`[With<Disabled<Cooldown>>]`），就能找到 `T` 暂停中的实体。只能通过 `Disable` 和 `Enable` 改变它。
