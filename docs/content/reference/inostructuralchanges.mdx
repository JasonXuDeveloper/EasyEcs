```csharp
public interface INoStructuralChanges
```

Marks a `ForEach` job that makes no structural change (no create/destroy/add/remove/set on any entity of the world it iterates). ForEach then walks tables with no per-entity bookkeeping. The source generator adds it to `[ForEach]` methods that are static, take no [`World`](/en/docs/reference/world) and use their [`Entity`](/en/docs/reference/entity) parameter (if any) only to read; implement it by hand only when the job honors the contract.
