One cell of a tile with its neighbors, the parameter of a [ForEach] method that computes one cell: the shader form of a stencil. The method reads the cell ([`Cell.Value`](/en/docs/reference/cell#value)) and its neighbors at constant offsets (`w[-1, 0, 0]`, within the shape's [`ITileShape.Halo`](/en/docs/reference/itileshape#halo)) and assigns its `out` parameter, the cell of the entity's `DynamicBuffer` of that type at the same place:

```csharp
[ForEach(Parallel = true)]
static void Blur(Cell<Warmth, Plate> w, out NextWarmth next) =>
    next = new((w[-1, 0, 0].T + w.Value.T + w[1, 0, 0].T) * (1f / 3));
```

The generator writes the pass: the halo exchanged per tile, the rows its offsets read walked (the quiet ones get what the method computes from zeros), and each row as a vector loop over its cells, the neighbors unaligned loads of the padded texture; a cell the vector loop cannot take runs the method as written. Treat it as a tile parameter ([`Tile`](/en/docs/reference/tile)): the rows need the tile component and the cells' buffer, the neighbors come from the grid's index.

#### Type parameters

- `TCell`: The cell.
- `TTile`: The tile's component and shape.
