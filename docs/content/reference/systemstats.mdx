How often and how long a system ran ([`WorldOptions.MeasureSystems`](/en/docs/reference/worldoptions#measuresystems)): its `OnUpdate` method plus its `[ForEach]` methods, per run, with the bytes it allocated and the entities its `[ForEach]` methods visited. Read it between updates; with [`WorldOptions.ParallelSystems`](/en/docs/reference/worldoptions#parallelsystems) each system records its own runs.

### `LastAllocated` [#lastallocated]

```csharp
public long LastAllocated { get; }
```

Bytes the latest run allocated on the managed heap: on the thread that ran the system, plus on the threads that ran chunks of its parallel `[ForEach]` methods (`GC.GetAllocatedBytesForCurrentThread` around each).

### `LastEntities` [#lastentities]

```csharp
public long LastEntities { get; }
```

Entities the latest run's `[ForEach]` methods visited: the entities each method's query matched when its pass started (rows passing its filters and, for `[Changed<T>]` / `[Removed<T>]`, written or removed since the system last ran), summed over the methods; a `[ForEach(Slices = N)]` method counts the rows of the slice it visited. Queries made in its OnUpdate method are not counted.
