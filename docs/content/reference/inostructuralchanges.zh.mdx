```csharp
public interface INoStructuralChanges
```

标记一个不做结构变更的 `ForEach` job：不在它遍历的 World 里创建或销毁实体，也不增删、设置任何组件。ForEach 遍历表时就不用做逐实体的簿记。源生成器会给符合条件的 `[ForEach]` 方法加上它：静态方法，不接收 [`World`](/zh/docs/reference/world)，[`Entity`](/zh/docs/reference/entity) 参数（如果有）只用来读。只有 job 确实遵守这个约定时，才手动实现它。
