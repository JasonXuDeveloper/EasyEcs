The systems of one group in stages ([`ScheduleInfo`](/en/docs/reference/scheduleinfo)).

#### Parameters

- `Name`: The group type's name, or "Default" for the default group.
- `Stages`: The stages in execution order: each one's systems may run at the same time ([`WorldOptions.ParallelSystems`](/en/docs/reference/worldoptions#parallelsystems)).
- `RegistrationOrdered`: Pairs of systems whose access conflicts and that no chain of [`UpdateBeforeAttribute`](/en/docs/reference/updatebeforeattribute) / [`UpdateAfterAttribute`](/en/docs/reference/updateafterattribute) orders: they run in registration order, so registering them the other way round changes what the later one sees.
