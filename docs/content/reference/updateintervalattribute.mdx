public sealed class UpdateIntervalAttribute : Attribute

Run the system on every `interval`-th update of its group only: the updates whose count ([`World.DefaultUpdateCount`](/en/docs/reference/world#defaultupdatecount), [`World.UpdateCount`](/en/docs/reference/world#updatecount)) modulo the interval is [`UpdateIntervalAttribute.Phase`](/en/docs/reference/updateintervalattribute#phase). Systems with the same interval and different phases spread their work over the updates instead of all running on the same one. The generator writes the values into the system's code; the interval is 1 or more and the phase 0 to interval - 1 (EECS083).

```csharp
[EcsSystem, UpdateInterval(4, Phase = 1)]   // updates 1, 5, 9, ...
ref struct Regrowth { ... }
```
