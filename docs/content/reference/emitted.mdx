public struct Emitted<T> : ISingletonComponent where T : struct

The records the passes with an [`Emit`](/en/docs/reference/emit) parameter appended, in row order of each pass and in the order the passes ran: a singleton, added by the first pass that emits. The system that applies the records reads [`Emitted.Items`](/en/docs/reference/emitted#items) (`foreach`, `AsReadOnlySpan`, [`World.ForParallel`](/en/docs/reference/world#forparallel-2)) and clears it. Snapshots and saves copy the records like a buffer component's.

#### Type parameters

- `T`: The record.
