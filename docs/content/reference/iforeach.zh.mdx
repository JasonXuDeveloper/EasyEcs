`World.ForEach` 的结构体回调。它是带 struct 约束的泛型参数，JIT 会去掉虚调用，通常还会内联：没有委托，没有闭包，不分配内存。`[ForEach]` 方法就编译成它。

组件数量从 1 到 9，每个数量一个类型，都由同一个模板生成；下面的成员每个类型都有，以 `IForEach<T1>` 为例。

## 属性 [#properties]

### `Merges` [#merges]

```csharp
static virtual bool Merges { get; }
```

job 在字段里保存部分结果（[`Reduce`](/zh/docs/reference/reduce)；默认 false）：并行遍历保留每个块的 job 副本，按块的顺序把它们合并进调用方的 job（[`IForEach.Merge`](/zh/docs/reference/iforeach#merge)）。

### `OneQuery` [#onequery]

```csharp
static virtual bool OneQuery { get; }
```

这个 job 类型的每次遍历都用同一个过滤条件（tick 和分片除外；默认 false）：World 按 job 类型保存查询的匹配结果，不比较过滤条件就能找到它。生成的 job 会设置它（它们的过滤条件是方法里的常量）。

### `OptionalWrites` [#optionalwrites]

```csharp
static virtual ComponentSet OptionalWrites { get; }
```

job 在自身组件之外写入的被追踪的组件（通过 [`Maybe`](/zh/docs/reference/maybe)；默认没有）：并行遍历打开它们的变更 tick 区段时，与 [`IForEach.WriteMask`](/zh/docs/reference/iforeach#writemask) 的组件一起打开，让切开同一区段的块共用它。生成的并行 job 标出它们通过 [`Maybe`](/zh/docs/reference/maybe) 的写入。

### `SelfStamped` [#selfstamped]

```csharp
static virtual int SelfStamped { get; }
```

[`IForEach.WriteMask`](/zh/docs/reference/iforeach#writemask) 里由 job 自己打 tick、而且只在它写的行上打 tick 的组件（位的含义同 [`IForEach.WriteMask`](/zh/docs/reference/iforeach#writemask)；默认没有）：循环不给这些组件的行打 tick。生成的 job 标出它们的 [`Mut`](/zh/docs/reference/mut) 参数。

### `WriteMask` [#writemask]

```csharp
static virtual int WriteMask { get; }
```

job 通过 ref 写入的组件：第 k 个组件对应第 k - 1 位（默认：全部）。job 改变了当前实体的原型时，ForEach 在 job 返回后，把这些组件从 ref 指向的那一行带到实体的新行。生成的 job 只标出它们的 `ref` 参数。

### `Merge` [#merge]

```csharp
static virtual void Merge<TSelf>(ref TSelf job, in TSelf chunk) where TSelf : struct;
```

把 `chunk` 里的部分结果合并进 `job`（两者都是这个 job 自己的类型；[`IForEach.Merges`](/zh/docs/reference/iforeach#merges)）。带 [`Reduce`](/zh/docs/reference/reduce) 参数的生成 job 实现它。
