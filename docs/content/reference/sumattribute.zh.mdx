归约（[`IReduction`](/zh/docs/reference/ireduction)）中按加法合并的字段：`Identity` 是 0，`Combine` 是 `left + right`。用在 partial struct 的数值类型（整数、`float`、`double`、`decimal`）字段、带 setter 的自动属性或 record 的位置参数上：`public partial struct Census : ISingletonComponent { [Sum] public int Alive; [Max] public float Oldest; }`。生成器为这个 struct 写出 `IReduction<T>`（public static 的 `Identity` 和逐字段的 `Combine`），所以每个实例字段都要标 [`SumAttribute`](/zh/docs/reference/sumattribute)、[`ProductAttribute`](/zh/docs/reference/productattribute)、[`MinAttribute`](/zh/docs/reference/minattribute)、[`MaxAttribute`](/zh/docs/reference/maxattribute)、[`AllAttribute`](/zh/docs/reference/allattribute) 或 [`AnyAttribute`](/zh/docs/reference/anyattribute) 之一。标在 struct 本身上时，它是所有没有自己特性的字段的特性：`[Sum] public partial record struct Stats(long Kills, long Deaths, [Max] long Longest) : ISingletonComponent;`。六个特性都是这样。
