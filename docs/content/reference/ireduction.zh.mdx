```csharp
public interface IReduction<T> where T : struct
```

`T` 的值怎样合并：满足结合律的 [`IReduction.Combine`](/zh/docs/reference/ireduction#combine)，以及它的 [`IReduction.Identity`](/zh/docs/reference/ireduction#identity)，和任何值合并都不改变那个值（求和是 0，求最小值是 `float.MaxValue`）。为自身实现它的单例，就是 [`Reduce`](/zh/docs/reference/reduce) 参数的结果。Combine 不必满足交换律：部分结果按行的顺序合并。逐字段写（结果的每个字段只取两边的同一个字段）时，它也是向量循环可以逐 lane 套用的逐元素形式。

#### 类型参数 [#type-parameters]

- `T`：被合并的值。

### `Identity` [#identity]

```csharp
static abstract T Identity { get; }
```

和任何值合并都不改变那个值的值：每个部分结果的起点。

### `Combine` [#combine]

```csharp
static abstract T Combine(T left, T right);
```

`left` 和 `right` 合并的结果，`left` 的行在前。
