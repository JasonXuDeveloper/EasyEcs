public sealed class WhenTargetDestroyedAttribute : Attribute

What destroying an entity does to the links to it, in every world ([`TargetPolicy`](/en/docs/reference/targetpolicy)): on a relation ([`IRelation`](/en/docs/reference/irelation)) or a component indexed by an [`EntityId`](/en/docs/reference/entityid). A world holds the rule from its first table holding the component (or the creation of its index), so the first destroy follows it; a world's own `WhenTargetDestroyed` call on the index replaces it.

#### Parameters

- `policy`: The policy every world starts with.
