```csharp
public readonly ref struct Maybe<T> where T : struct, IComponent
```

An optional component of the entity a `[ForEach]` method visits: `static void Regen(ref Health h,
Maybe<Buff> buff)` visits every entity with Health, and [`Maybe.HasValue`](/zh/docs/reference/maybe#hasvalue) tells whether this one also has a Buff. One method instead of a With and a Without variant when the optional part is small. A method that changes no structure finds the column once per run of rows and tests a presence bit per row; one that changes structure looks the component up through each entity. Split the method in two with `[With<T>]` / `[Without<T>]` in the hottest loops (no test per row). The type declares the access, as `ref` does: the method writes `T`, so the system is scheduled as its writer and a tracked component is stamped on every row that has it; a method that only reads takes a [`ReadOnlyMaybe`](/zh/docs/reference/readonlymaybe) (EECS025). Valid for the call it is passed to (a ref struct).
