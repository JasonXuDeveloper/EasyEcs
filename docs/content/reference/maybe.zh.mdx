```csharp
public readonly ref struct Maybe<T> where T : struct, IComponent
```

`[ForEach]` 方法所访问实体的一个可选组件：`static void Regen(ref Health h, Maybe<Buff> buff)` 访问所有带 Health 的实体，[`Maybe.HasValue`](/zh/docs/reference/maybe#hasvalue) 告诉你当前这个实体有没有 Buff。可选的部分不大时，一个方法就够了，不用写 With 和 Without 两个版本。不做结构变更的方法，每段行查一次列，每行测一个存在位；做结构变更的方法，则要通过每个实体查找这个组件。在最热的循环里，用 `[With<T>]` / `[Without<T>]` 把方法拆成两个（每行不用测试）。类型就声明了读写，和 `ref` 一样：方法算写 `T`，系统按它的写者调度，被追踪的组件在每个带它的行上都打 tick；只读的方法接收 [`ReadOnlyMaybe`](/zh/docs/reference/readonlymaybe)（EECS025）。只在传入它的那次调用里有效（ref struct）。
