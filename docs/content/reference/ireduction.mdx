```csharp
public interface IReduction<T> where T : struct
```

How values of `T` combine: an associative [`IReduction.Combine`](/en/docs/reference/ireduction#combine) and its [`IReduction.Identity`](/en/docs/reference/ireduction#identity), which changes nothing it is combined with (0 for a sum, `float.MaxValue` for a minimum). A singleton implementing it for itself is the result of a [`Reduce`](/en/docs/reference/reduce) parameter. Combine need not be commutative: partial results are combined in row order. Written field by field (each field of the result from the same field of both sides), it is also the elementwise form a vector loop can apply per lane.

#### Type parameters

- `T`: The combined value.
