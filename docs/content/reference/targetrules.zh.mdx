指向实体的组件（键是 [`EntityId`](/zh/docs/reference/entityid) 的 [`IIndexed`](/zh/docs/reference/iindexed)）的目标策略。

## 方法 [#methods]

### `WhenTargetDestroyed` [#whentargetdestroyed]

```csharp
public static ValueIndex<T, EntityId> WhenTargetDestroyed<T>(this ValueIndex<T, EntityId> index, TargetPolicy policy) where T : struct, IComponent, IIndexed<EntityId>;
```

决定销毁一个实体时，键是这个实体的 `T` 组件怎么处理：宠物死了，主人失去 `Pet`（[`TargetPolicy.Remove`](/zh/docs/reference/targetpolicy#remove)）；召唤者死了，召唤物跟着死（[`TargetPolicy.Destroy`](/zh/docs/reference/targetpolicy#destroy)）。[`ChildOf`](/zh/docs/reference/childof) 一开始就是 [`TargetPolicy.Destroy`](/zh/docs/reference/targetpolicy#destroy)；其他组件默认 [`TargetPolicy.Keep`](/zh/docs/reference/targetpolicy#keep)。每次销毁时都会执行（索引一直保持建好的状态）；每个销毁的实体 O(1)，它的每条链接 O(1)。只能在所有者线程调用。
