The blocks of one ordered table (an order inferred for a pair method, or [[OrderBy]](/en/docs/reference/orderbyattribute)): its rows in key order, cut into blocks of [`RowBlocks.Size`](/en/docs/reference/rowblocks#size) rows, each with an axis-aligned box over the declared point of its rows, widened by the margin. What a search over space reads: a box far from the query skips its rows at once, a near one is read row by row (or a block per vector) from the table's columns ([`RowBlocks.Read`](/en/docs/reference/rowblocks#read)). From [`World.Blocks`](/en/docs/reference/world#blocks) (every table ordered by a component) or [`EntitySpan.Blocks`](/en/docs/reference/entityspan#blocks) (the table of a batch method's run of rows, whose row 0 is [`EntitySpan.FirstRow`](/en/docs/reference/entityspan#firstrow)).

The boxes are drawn by the sort and hold until the next one as long as no row moved farther than the margin: rows [0, [`RowBlocks.SortedRows`](/en/docs/reference/rowblocks#sortedrows)) are in blocks; rows [[`RowBlocks.SortedRows`](/en/docs/reference/rowblocks#sortedrows), [`RowBlocks.Rows`](/en/docs/reference/rowblocks#rows)) joined the table since and are in none (a search reads them one by one, or waits for the next sort). A row that moved into a block's row since the sort widened that block's box. Inside a pass a row destroyed or moved away by the pass is a tombstone: its id's index is negative ([`RowBlocks.Ids`](/en/docs/reference/rowblocks#ids)). A row of a block may lack the component since the sort ([`RowBlocks.Has`](/en/docs/reference/rowblocks#has)). Valid until the next structural change of the world (a ref struct over the table's arrays).

### `Pairs` [#pairs]

```csharp
public int Pairs(RowBlocks other, float reach, Span<BlockPair> destination);
public int Pairs(float reach, Span<BlockPair> destination);
```

The pairs of this table's blocks whose boxes come within `reach` of each other on every axis: the candidates of a search for the rows within `reach` of each other, which a kernel then reads [`RowBlocks.Size`](/en/docs/reference/rowblocks#size) × [`RowBlocks.Size`](/en/docs/reference/rowblocks#size) rows per pair (every other pair of rows is farther apart). Each block is paired with itself (a block whose rows all lack the component with none), and each other pair is written once, smaller block first. Written to `destination` as far as it holds; returns how many there are, so a caller whose buffer was short grows it and calls again. A sweep over the blocks sorted by their low side on axis 0: O(blocks × log blocks + candidates). The sort's buffers come from the shared array pools: allocation-free in steady state, and safe on several threads at once (it changes nothing).

**Parameters**

- `reach`: The distance, on each axis, beyond which two rows never interact: 0 or more.
- `destination`: Where the pairs go.

**Returns** The number of pairs, which may exceed the length of `destination`.

**Exceptions**

- `ArgumentOutOfRangeException`: `reach` is negative, infinite or NaN.
- `InvalidOperationException`: The boxes cover no axis.
