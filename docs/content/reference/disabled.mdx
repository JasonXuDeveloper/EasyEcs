```csharp
public struct Disabled<T> : IComponent where T : struct, IComponent
```

The tag of an entity whose `T` is disabled ([`Entity.Disable`](/en/docs/reference/entity#disable)): the entity keeps the value of `T` but lacks it for queries, `Has` and `Get` until [`Entity.Enable`](/en/docs/reference/entity#enable) gives it back. Query it like any tag (`[With<Disabled<Cooldown>>]`) to find the entities whose `T` is paused. Change it only through `Disable` and `Enable`.
