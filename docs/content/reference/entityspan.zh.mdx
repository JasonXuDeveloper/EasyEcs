```csharp
public readonly ref struct EntitySpan
```

批处理 job 里一段行对应的实体：第 `i` 个元素，就是这段行各个 span 第 `i` 个元素所属的实体。只有按下标访问时才构造句柄，所以批处理只需要其中几行的实体时，只读那几行的 id。只在传入它的那次调用里有效（和 span 一样是 ref struct）。

## 属性 [#properties]

### `Clusters` [#clusters]

```csharp
public RowClusters Clusters { get; }
```

这段行所在的表有序时（推断出的顺序或 [[OrderBy]](/zh/docs/reference/orderbyattribute)）是它的簇，否则没有簇（[`RowClusters.Count`](/zh/docs/reference/rowclusters#count) 为 0）：批处理方法通过包围盒找到自己这些行附近的行。O(1)。

### `FirstRow` [#firstrow]

```csharp
public int FirstRow { get; }
```

这段行的第 0 个元素在表里是哪一行：第 `i` 个元素是 [`EntitySpan.Clusters`](/zh/docs/reference/entityspan#clusters) 的第 `FirstRow + i` 行。O(1)。

### `Ids` [#ids]

```csharp
public ReadOnlySpan<EntityId> Ids { get; }
```

这段行里实体的 id，直接从表里读（不复制）：用来保存或发送。

### `Length` [#length]

```csharp
public int Length { get; }
```

实体数量（等于这段行各个 span 的长度）。
