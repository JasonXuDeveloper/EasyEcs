Nested in [`ValueIndex`](/en/docs/reference/valueindex).

Enumerates entities in key order (`foreach`): every entity of a key, then the next key. O(log keys) to start, O(1) per entity and per key. Destroying entities during the loop is allowed, changing `T` is not.
