Tag of an entity that was destroyed while holding [`ICleanupComponent`](/en/docs/reference/icleanupcomponent)s: its other components are gone, it stays alive until its last cleanup component is removed. Select such entities with `With<Destroyed>` (a cleanup system) and new ones with `Without<Destroyed>` (an acquiring system).
