A set of component types, built once and kept (a `static readonly` field): the components a save writes ([`World.SaveEntities`](/en/docs/reference/world#saveentities-2)), the record of what persists without the runtime state around it. `ComponentSet.Create().With<Bank>().With<Deposits>()`; a framework that learns its types at registration adds them by `Type`. Each call returns a new set.
