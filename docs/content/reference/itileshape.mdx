The shape of a tile, on the component that makes an entity a tile of a grid ([`ITile`](/en/docs/reference/itile)): the entity's cells, [`ITileShape.Width`](/en/docs/reference/itileshape#width) × [`ITileShape.Depth`](/en/docs/reference/itileshape#depth) × [`ITileShape.Height`](/en/docs/reference/itileshape#height) of them, are in its `DynamicBuffer<TCell>` in rows of [`ITileShape.Width`](/en/docs/reference/itileshape#width) (x), [`ITileShape.Depth`](/en/docs/reference/itileshape#depth) rows (z) per layer and [`ITileShape.Height`](/en/docs/reference/itileshape#height) layers (y): cell (x, y, z) at `(y * Depth + z) * Width + x`. Static members, read once by the JIT: a tile's code is compiled for its shape, every size and branch on it folded to a constant.

The faces that have neighbors (default [`TileFaces.Sides`](/en/docs/reference/tilefaces#sides)); the halo of the others follows [`ITileShape.Boundary`](/en/docs/reference/itileshape#boundary). [`TileFaces.Below`](/en/docs/reference/tilefaces#below) and [`TileFaces.Above`](/en/docs/reference/tilefaces#above) count only for a tile of more than one layer; a 1D tile (one row) declares `West | East`.

### `Halo` [#halo]

```csharp
static virtual int Halo { get; }
```

The width of the halo, in cells (default 1): the ghost cells of an MPI halo exchange, the apron of a CUDA tile. A stencil reaching r cells, rows or layers away needs r. At most the tile's extent along every axis with neighbors (and along every axis for [`TileBoundary.Mirror`](/en/docs/reference/tileboundary#mirror)): a halo never reaches past the tile beside.
