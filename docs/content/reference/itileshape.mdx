The shape of a tile, on the component that makes an entity a tile of a grid ([`ITile`](/en/docs/reference/itile)): the entity's cells, [`ITileShape.Width`](/en/docs/reference/itileshape#width) × [`ITileShape.Depth`](/en/docs/reference/itileshape#depth) × [`ITileShape.Height`](/en/docs/reference/itileshape#height) of them, are in its `DynamicBuffer<TCell>` in rows of [`ITileShape.Width`](/en/docs/reference/itileshape#width) (x), [`ITileShape.Depth`](/en/docs/reference/itileshape#depth) rows (z) per layer and [`ITileShape.Height`](/en/docs/reference/itileshape#height) layers (y): cell (x, y, z) at `(y * Depth + z) * Width + x`. Static members, read once by the JIT: a tile's code is compiled for its shape.

```csharp
static abstract int Depth { get; }
```

The rows of a layer (z), 1 to 64 (the active rows of a layer are one 64-bit word).

### `Faces` [#faces]

```csharp
static virtual TileFaces Faces { get; }
```

The faces that have neighbours (default [`TileFaces.Sides`](/en/docs/reference/tilefaces#sides)); the halo of the others is the fill value. [`TileFaces.Below`](/en/docs/reference/tilefaces#below) and [`TileFaces.Above`](/en/docs/reference/tilefaces#above) count only for a tile of more than one layer.

### `Height` [#height]

```csharp
static virtual int Height { get; }
```

The layers (y), 1 or more: 1 (the default) is a 2D tile, which has no layers below or above.

### `Width` [#width]

```csharp
static abstract int Width { get; }
```

The cells of a row (x), 1 or more.
