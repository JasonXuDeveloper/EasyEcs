A `[ForEach]` method's working memory on the thread running it (OpenMP's `threadprivate`): a list of neighbours, the open set of a path search, a buffer to fill. `static void Plan(ref Path path, in Goal goal,
Scratch<Frontier> frontier)`: [`Scratch.Value`](/en/docs/reference/scratch#value) is one `T` per method and thread, created (`default`) the first time the thread runs the method and kept for the thread's lifetime, so what it allocates (`value.Ids ??= new int[256]`) it allocates once per thread, and steady state allocates nothing. Two threads never share one; the chunks of a parallel pass running on one thread run one after another, so a row has it to itself for its call.

It is never reset: a row finds what the last row on its thread left, of this pass or an earlier one, of this world or another. Clear what you use at the start of the row (`list.Clear()`); nothing that belongs to the world may live there between rows. Storing what it holds by reference into a component or a singleton (EECS058) hands one thread's memory to the next row that reuses it. Its memory is the thread's: it is released when the thread ends, not when the world is disposed.

Valid for the call it is passed to (a ref struct).

#### Type parameters

- `T`: The scratch value: a struct holding buffers, or a class such as a `List<int>` (created on first use: `scratch.Value ??= new()`).
