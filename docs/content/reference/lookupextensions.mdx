### `Count` [#count]

```csharp
extension<T, TKey>(Lookup<T> lookup) public int Count(TKey key);
```

The number of entities whose `T` has key `key`. O(1): a hash probe.

### `Find` [#find]

```csharp
extension<T, TKey>(Lookup<T> lookup) public ValueIndex<T, TKey>.Matches Find(TKey key);
```

The entities whose `T` has key `key` (`foreach`). O(1), then O(1) per entity. Nothing writes `T` during the pass, so the list holds still while it is walked.

### `TryFind` [#tryfind]

```csharp
extension<T, TKey>(Lookup<T> lookup) public bool TryFind(TKey key, out EntityId id);
```

An entity whose `T` has key `key`: the one of a unique index ([`IUniqueIndexed`](/en/docs/reference/iuniqueindexed)), any of them otherwise. O(1): a hash probe.
