The key a world indexes the component by ([`IIndexed`](/en/docs/reference/iindexed)): on a field, a property or a record's positional parameter, the key is that member (`public partial struct Owner : IComponent { [Key] public EntityId Of; }`); on the struct itself, the key is the whole value. The generator adds `IIndexed<TKey>` to the partial struct (unless an interface the struct declares brings it) with an explicit `Key` returning the member. One key per component; a key computed from several members is written by hand (`public (int, int) Key => (X, Y);`).
