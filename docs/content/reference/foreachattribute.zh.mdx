对每个匹配组件参数（以及 [`WithAttribute`](/zh/docs/reference/withattribute) / [`WithoutAttribute`](/zh/docs/reference/withoutattribute) / [`WithAnyAttribute`](/zh/docs/reference/withanyattribute) 过滤条件）的实体，执行 [`EcsSystem`](/zh/docs/reference/ecssystem) 的一个方法（或者通过生成的入口点，执行任何其他类型的静态方法）。每次更新执行一次，在 [`EcsSystem.OnUpdate`](/zh/docs/reference/ecssystem#onupdate) 之后，按声明顺序。

参数：1 到 9 个组件（`ref` 表示写，`in` 表示读；按段接收行的批处理方法用 `Span<T>` / `ReadOnlySpan<T>`）、单例（`ref` / `in`），还可以加上 [`Entity`](/zh/docs/reference/entity) 和 [`World`](/zh/docs/reference/world)。静态方法和实例方法都支持。

```csharp
public class MovementSystem : EcsSystem
{
    [ForEach, Without<Frozen>]
    static void Move(ref Position p, in Velocity v) { p.X += v.X; p.Y += v.Y; }
}
```

EasyEcs.Generator 把它编译成结构体 job（[`IForEach`](/zh/docs/reference/iforeach)、[`IForEachEntity`](/zh/docs/reference/iforeachentity) 或 [`IForEachBatch`](/zh/docs/reference/iforeachbatch)）：没有委托，不分配内存，可以内联。

把匹配的行分块，放到多个线程上执行（`World.ForEachParallel`）。方法不能做结构变更，必须逐实体执行，也不能写单例（EECS010）；每行工作量大、行数上万时才划算。默认 false。
