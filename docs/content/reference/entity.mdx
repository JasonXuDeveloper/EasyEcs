Handle to an entity: id + version + world (16 bytes). Every access validates the version, so a handle to a destroyed entity never touches the entity that reused its id: questions ([`Entity.IsAlive`](/en/docs/reference/entity#isalive), [`Entity.Has`](/en/docs/reference/entity#has), [`Entity.TryGet`](/en/docs/reference/entity#tryget), [`Entity.TryGetRef`](/en/docs/reference/entity#trygetref)) answer false, accesses and changes ([`Entity.Get`](/en/docs/reference/entity#get), [`Entity.Read`](/en/docs/reference/entity#read), [`Entity.GetOrAdd`](/en/docs/reference/entity#getoradd), `Set`, `Remove`) throw, and [`Entity.Destroy`](/en/docs/reference/entity#destroy) does nothing. Safe to store and to compare.

#### Remarks

Refs returned by [`Entity.Get`](/en/docs/reference/entity#get)/[`Entity.GetOrAdd`](/en/docs/reference/entity#getoradd) point into the row of the entity's archetype table: use them immediately and never keep them across a structural change of that entity (it moves the row) or an `await`.

### `Disable` [#disable]

Disable component `T`: the entity keeps its value but lacks it (queries, `Has`, `Get`) until [`Entity.Enable`](/en/docs/reference/entity#enable), and gets the tag [`Disabled`](/en/docs/reference/disabled). Counts as a removal for `[Removed<T>]`; an indexed component leaves its index. Returns false when the entity lacks `T` (or has it disabled already); throws if it is not alive. Owner thread only.
