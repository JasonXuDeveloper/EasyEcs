```csharp
public sealed class RelationIndex<T> where T : struct, IRelation
```

一个 World 里关系 `T` 的链接，按目标组织（[`World.Relations`](/zh/docs/reference/world#relations)）：哪些实体链接到某个实体，开始 O(1)，之后每条链接 O(1)。写入链接时，以及来源实体销毁或失去缓冲时，索引都会跟着更新；第一次查找（以及 [`World.Restore`](/zh/docs/reference/world#restore) 之后的第一次）会把所有缓冲索引一遍。指向已销毁目标的链接，仍然能按目标的 id 找到，之后的实体不会再用这个 id。只能在所有者线程使用。内存：每个元素一条 20 字节的链接（回收复用），目标的列表里再占 8 字节。

### `Find` [#find]

```csharp
public RelationIndex<T>.Sources Find(EntityId target);
```

链接到 `target` 的实体，每条链接一次。循环里可以销毁实体，但不能改链接。

**复杂度**（[API 表](/zh/docs/api)）：O(1)，然后每条链接 O(1)

### `WhenTargetDestroyed` [#whentargetdestroyed]

```csharp
public RelationIndex<T> WhenTargetDestroyed(TargetPolicy policy);
```

决定销毁一个实体时，指向它的链接怎么处理：[`TargetPolicy.Remove`](/zh/docs/reference/targetpolicy#remove) 删掉链接（成员离开了 World，队伍就忘掉他），[`TargetPolicy.Destroy`](/zh/docs/reference/targetpolicy#destroy) 销毁链接过来的实体（施法者没了，他施加的 buff 一起结束），[`TargetPolicy.Keep`](/zh/docs/reference/targetpolicy#keep)（默认）保留链接。每次销毁时都会执行（索引一直保持建好的状态）；每个销毁的实体 O(1)，每条链接 O(它的来源实体的链接数)。只能在所有者线程调用。

**复杂度**（[API 表](/zh/docs/api)）：O(1)；之后每个被销毁的实体 O(1)，每条链接 O(L)
