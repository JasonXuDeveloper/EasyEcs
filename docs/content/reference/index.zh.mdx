| 类型 | 说明 |
|---|---|
| [`ChangedAttribute<T>`](/zh/docs/reference/changedattribute) | ForEachAttribute 方法只访问 T 在系统上次运行之后写过的实体（EcsSystem.LastRunTick；第一次运行时是所有拥有它的实体）。 |
| [`DynamicBufferExtensions`](/zh/docs/reference/dynamicbufferextensions) | DynamicBuffer 的写入方法。 |

| [`Prefab`](/zh/docs/reference/prefab) | 实体的配方：一组不属于任何 World 的组件值，所以任何查询都看不到它。 |
| [`RelationIndex<T>`](/zh/docs/reference/relationindex) | 一个 World 里关系 T 的链接，按目标组织（World.Relations）：哪些实体链接到某个实体，开始 O(1)，之后每条链接 O(1)。 |
| [`RemovedAttribute<T>`](/zh/docs/reference/removedattribute) | ForEachAttribute 方法只访问在系统上次运行之后（EcsSystem.LastRunTick）失去 T、而且没有再拿回来的实体：同步时把移除发出去，清理时释放组件代表的资源。 |
| [`TargetRules`](/zh/docs/reference/targetrules) | 指向实体的组件（键是 EntityId 的 IIndexed）的目标策略。 |
| [`UpdateAfterAttribute<TSystem>`](/zh/docs/reference/updateafterattribute) | 让这个系统排在同一分组里的 TSystem（和它的派生系统）之后运行：见 UpdateBeforeAttribute。 |
| [`UpdateBeforeAttribute<TSystem>`](/zh/docs/reference/updatebeforeattribute) | 让这个系统排在同一分组里的 TSystem（和它的派生系统）之前运行，不管它们的注册顺序。 |
| [`UpdateInGroupAttribute<TGroup>`](/zh/docs/reference/updateingroupattribute) | 把系统（和它的派生系统）放进分组 TGroup。 |
| [`ValueIndex<T, TKey>`](/zh/docs/reference/valueindex) | 一个 World 里组件 T 的值索引（World.Index）。 |
| [`WithAnyAttribute<T>`](/zh/docs/reference/withanyattribute) | ForEachAttribute 方法要求实体至少拥有它的 [WithAny&lt;T&gt;] 特性列出的组件之一（不传入方法）：[ForEach, WithAny&lt;Burning&gt;, WithAny&lt;Poisoned&gt;]。 |
| [`WithAttribute<T>`](/zh/docs/reference/withattribute) | ForEachAttribute 方法还要求实体有组件 T（不传入方法）。 |
| [`WithoutAttribute<T>`](/zh/docs/reference/withoutattribute) | ForEachAttribute 方法跳过拥有组件 T 的实体。 |
| [`World`](/zh/docs/reference/world) | 一个 ECS World：装着实体、实体的组件、单例，以及更新它们的系统。 |
| [`WorldOptions`](/zh/docs/reference/worldoptions) | World 的配置。 |
| [`WorldSnapshot`](/zh/docs/reference/worldsnapshot) | World 的实体、组件和单例的一份拷贝：World.Capture 拍下，World.Restore 放回（系统和选项不在里面）。 |

| [`EntityId`](/zh/docs/reference/entityid) | 实体的身份：下标，加上这个下标的版本号（8 字节，非托管）。 |
| [`EntitySpan`](/zh/docs/reference/entityspan) | 批处理 job 里一段行对应的实体：第 i 个元素，就是这段行各个 span 第 i 个元素所属的实体。 |
| [`Maybe<T>`](/zh/docs/reference/maybe) | [ForEach] 方法所访问实体的一个可选组件：static void Regen(ref Health h, Maybe&lt;Buff&gt; buff) 访问所有带 Health 的实体，Maybe.HasValue 告诉你当前这个实体有没有 Buff。 |
| [`QueryEnumerator<T1..T9>`](/zh/docs/reference/queryenumerator) | 零分配的查询枚举器；遍历途中做结构变更也安全（访问规则和 ForEach 相同）。 |
| [`QueryFilter`](/zh/docs/reference/queryfilter) | 查询的附加条件：必须存在但不读取的组件（QueryFilter.With），或者必须不存在的组件（QueryFilter.Without）。 |
| [`QueryItem<T1..T9>`](/zh/docs/reference/queryitem) | 一条查询结果：实体，以及指向它所在行的 ref。 |
| [`RelationIndex<T>.Sources`](/zh/docs/reference/relationindex-sources) | 枚举链接到某个目标的实体（foreach），每条链接一次。 |
| [`SingletonRef<T>`](/zh/docs/reference/singletonref) | 某个 World 的单例 T 的句柄。 |
| [`SystemAccess`](/zh/docs/reference/systemaccess) | 系统读写的数据，添加系统时声明一次。 |
| [`SystemList`](/zh/docs/reference/systemlist) | World 的系统，所有分组按执行顺序排列（默认分组在前）：用 foreach 遍历，或者读 SystemList.Count。 |
| [`SystemList.Enumerator`](/zh/docs/reference/systemlist-enumerator) | 依次遍历各个分组，以及每个分组里的系统。 |
| [`SystemStats`](/zh/docs/reference/systemstats) | 系统运行了多少次、花了多长时间（WorldOptions.MeasureSystems）：每次运行包括 EcsSystem.OnUpdate 和它的 [ForEach] 方法。 |
| [`TableInfo`](/zh/docs/reference/tableinfo) | 一张表：拥有同一组组件列的实体（World.Describe）。 |
| [`ValueIndex<T, TKey>.Matches`](/zh/docs/reference/valueindex-matches) | 枚举一个键对应的实体（foreach）。 |
| [`ValueIndex<T, TKey>.Ordered`](/zh/docs/reference/valueindex-ordered) | 按键的顺序枚举实体（foreach）：先是一个键的所有实体，再到下一个键。 |

## 接口 [#interfaces]

| 类型 | 说明 |
|---|---|
| [`ICleanupComponent`](/zh/docs/reference/icleanupcomponent) | 标记一个比所在实体活得更久的组件：销毁持有它的实体时，实体不会释放，而是去掉其他组件、加上 Destroyed 标签，让系统先释放这个组件代表的资源（一个 socket、一个预约、另一个服务里的一个名额），再移除组件。 |
| [`IComponent`](/zh/docs/reference/icomponent) | 把结构体标记为组件数据。 |
| [`IForEach<T1..T9>`](/zh/docs/reference/iforeach) | World.ForEach 的结构体回调。 |
| [`IForEachBatch<T1..T9>`](/zh/docs/reference/iforeachbatch) | World.ForEachBatch 的结构体回调：一次接收一整段行，每个组件一个 span，job 可以用 SIMD 处理（System.Numerics.Vector、MemoryMarshal.Cast），还能拿到这些行的实体（按下标访问时才构造）。 |
| [`IForEachEntity<T1..T9>`](/zh/docs/reference/iforeachentity) | 和 IForEach 一样，但还接收 Entity 句柄。 |
| [`IGroup`](/zh/docs/reference/igroup) | 标记一个按值拆分表的组件：在调用过 World.GroupBy 的 World 里，IGroup.Group 不同的实体放在不同的表，所以只查询一组（QueryFilter.InGroup）时只遍历这一组的行，这些行在内存里是连续的（一个区域、一张地图、一场对局、一支队伍）。 |
| [`IIndexed, IIndexed<TKey>`](/zh/docs/reference/iindexed) | 所有 IIndexed 共同实现的接口：不用反射，就能知道一个组件类型建了索引（JIT 会把这个类型检测折叠掉）。 |
| [`INoStructuralChanges`](/zh/docs/reference/inostructuralchanges) | 标记一个不做结构变更的 ForEach job：不在它遍历的 World 里创建或销毁实体，也不增删、设置任何组件。 |
| [`IRelation`](/zh/docs/reference/irelation) | DynamicBuffer 的元素，把所在实体链接到 IRelation.Target：一个实体可以有任意多条同一种链接（队伍的成员、商人卖的物品、一个 buff 作用的单位），World.Relations 能找出链接到某个目标的实体。 |
| [`ISingletonComponent`](/zh/docs/reference/isingletoncomponent) | 把结构体标记为 World 单例：每个 World 恰好有一个值（时钟、配置、共享状态）。 |
| [`ISystemGroup`](/zh/docs/reference/isystemgroup) | 系统分组的标记：标了 UpdateInGroupAttribute 的系统在调用 World.Update 时一起运行，和 World.Update 运行的默认分组互不相干。 |
| [`ITrackChanges`](/zh/docs/reference/itrackchanges) | 标记一个追踪变更的组件：每一行都记下最后一次写入时 World 的 World.ChangeTick，[Changed&lt;T&gt;] / QueryFilter.Changed&lt;T&gt;(since) 选出系统上次运行以来写过的行。 |
