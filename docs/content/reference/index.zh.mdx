| [`ICleanupComponent`](/zh/docs/reference/icleanupcomponent) | 标记一个比所在实体活得更久的组件：销毁持有它的实体时，实体不会释放，而是去掉其他组件、加上 Retired 标签，让系统先释放这个组件代表的资源（一个 socket、一个预约、另一个服务里的一个名额），再移除组件。 |
| [`IComponent`](/zh/docs/reference/icomponent) | 把结构体标记为组件数据。 |
| [`IDirectMapped<TKey>`](/zh/docs/reference/idirectmapped) | 键能映射到一个有界槽位范围的唯一组件（网格格子、地块、房间、玩家席位）：它的索引在哈希旁边多存一个 IDirectMapped.Slots 项的数组，一个键的实体放在 IDirectMapped.SlotOf 给出的那一项，所以 Get / TryGet 和写入时的唯一性检查只读一个数组项，不用探测哈希。 |
| [`IDrain<T>`](/zh/docs/reference/idrain) | 生成器为 DrainAttribute 方法写的 job：用遍历解析好的值（单例、查找）对一条记录调用这个方法。 |
| [`IForEach<T1..T9>`](/zh/docs/reference/iforeach) | World.ForEach 的结构体回调。 |
| [`IForEachBatch<T1..T9>`](/zh/docs/reference/iforeachbatch) | World.ForEachBatch 的结构体回调：一次接收一整段行，每个组件一个 span，job 可以用 SIMD 处理（System.Numerics.Vector、MemoryMarshal.Cast），还能拿到这些行的实体（按下标访问时才构造）。 |
| [`IForEachEntity<T1..T9>`](/zh/docs/reference/iforeachentity) | 和 IForEach 一样，但还接收 Entity 句柄。 |
| [`IForEachMasked<T1..T9>`](/zh/docs/reference/iforeachmasked) | 还接收"只有部分行通过"的 64 行一字的批量 job（过滤条件要检查存在位或变更 tick）：World.ForEachMasked 把整个字交给它，通过的行以位的形式给出；IForEachBatch 则会把每段连续通过的行分开交给它。 |
| [`IForRange`](/zh/docs/reference/iforrange) | 一段下标上的 job，由 World.ParallelFor 分块运行（Kokkos 的 RangePolicy，Unity 的 IJobParallelForBatch）：每次调用拿到一个块。 |
| [`IForSpan<T>`](/zh/docs/reference/iforspan) | 一个列表的元素上的 job，由 World.ParallelFor 分块运行：每次调用拿到一个块的元素，可写。 |
| [`IGroup`](/zh/docs/reference/igroup) | 标记一个按值拆分表的组件：在调用过 World.GroupBy 的 World 里，IGroup.Group 不同的实体放在不同的表，所以只查询一组（QueryFilter.InGroup）时只遍历这一组的行，这些行在内存里是连续的（一个区域、一张地图、一场对局、一支队伍）。 |
| [`IIndexed<TKey>`](/zh/docs/reference/iindexed) | World 按 IIndexed.Key 建索引的组件：world.Index&lt;T, TKey&gt;().Find(key) 枚举 TKey 等于某个值的实体（物品的主人、玩家的名字、网格的一个格子）。 |
| [`INoStructuralChanges`](/zh/docs/reference/inostructuralchanges) | 标记一个不做结构变更的 ForEach job：不在它遍历的 World 里创建或销毁实体，也不增删、设置任何组件。 |
| [`IOrderKey<TKey>`](/zh/docs/reference/iorderkey) | 一个组件，含它的表让行按 IOrderKey.OrderKey 排序，每簇（8 行，ARM64 上 4 行）一个包围盒，罩住 IOrderKey.BoxPoint（RowClusters）。 |
| [`IReduction<T>`](/zh/docs/reference/ireduction) | T 的值怎样合并：满足结合律的 IReduction.Combine，以及它的 IReduction.Identity，和任何值合并都不改变那个值（求和是 0，求最小值是 float.MaxValue）。 |
| [`IRelation`](/zh/docs/reference/irelation) | DynamicBuffer 的元素，把所在实体链接到 IRelation.Target：一个实体可以有任意多条同一种链接（队伍的成员、商人卖的物品、一个 buff 作用的单位），World.Relations 能找出链接到某个目标的实体。 |
| [`ISingletonComponent`](/zh/docs/reference/isingletoncomponent) | 把结构体标记为 World 单例：每个 World 恰好有一个值（时钟、配置、共享状态）。 |
| [`ISystemGroup`](/zh/docs/reference/isystemgroup) | 系统分组的标记：标了 UpdateInGroupAttribute 的系统在调用 World.Update 时一起运行，和 World.Update 运行的默认分组互不相干。 |
| [`ISystemGroupWith<T>`](/zh/docs/reference/isystemgroupwith) | 系统分组：其中的 [ForEach] 方法只访问有 T 的实体，效果和在分组上写 WithAttribute 一样。 |
| [`ISystemGroupWithout<T>`](/zh/docs/reference/isystemgroupwithout) | 系统分组：其中的 [ForEach] 方法跳过有 T 的实体，效果和在分组上写 WithoutAttribute 一样（见 ISystemGroupWith）。 |
| [`ITile<TKey>`](/zh/docs/reference/itile) | 让实体成为网格中一个瓦片的组件，按键查找（带索引的组件，IIndexed）：record struct Chunk(ChunkPos Pos) : IComponent, ITile&lt;ChunkPos&gt;，带着形状（ITileShape）和每个邻居的键（ITile.Beside）。 |
| [`ITileShape`](/zh/docs/reference/itileshape) | 瓦片的形状，写在让实体成为网格瓦片的组件上（ITile）：实体的格子共 ITileShape.Width × ITileShape.Depth × ITileShape.Height 个，存在它的 DynamicBuffer&lt;TCell&gt; 里：每行 ITileShape.Width 个（x），每层 ITileShape.Depth 行（z），共 ITileShape.Height 层（y）：格子 (x, y, z) 在 (y \* Depth + z) \* Width + x。 |
| [`ITracked`](/zh/docs/reference/itracked) | 标记一个追踪变更的组件：每一行都记下最后一次写入时 World 的 World.ChangeTick，[Changed&lt;T&gt;] / QueryFilter.Changed&lt;T&gt;(since) 选出系统上次运行以来写过的行。 |
| [`IUniqueIndexed<TKey>`](/zh/docs/reference/iuniqueindexed) | 键只对应一个实体的 IIndexed 组件：玩家的账号 id、会话令牌、网格格子里的占用者。 |
