[`ForEachAttribute`](/zh/docs/reference/foreachattribute) 方法消费它访问的行：遍历结束时，销毁访问过的实体，用于只处理一次的事件和命令实体。销毁的恰好是这次遍历的行，不会是之后才匹配的实体：不做结构变更的方法，在遍历结束后一次销毁访问过的所有行（按方法的过滤条件做一次 `DestroyAll`，行全部要销毁的表一步清空）；可能做结构变更的方法，处理完每一行就销毁那个实体。销毁遵循 [`Entity.Destroy`](/zh/docs/reference/entity#destroy) 的规则：带清理组件的实体退休，销毁日志记录每个 id。遍历抛异常时，没处理完的行一个也不销毁：不做结构变更的方法不销毁任何行，下次运行会再访问它们。不能和 [`ForEachAttribute.Slices`](/zh/docs/reference/foreachattribute#slices) 一起用（EECS085）。

```csharp
[ForEach, Consume]
static void Count(in Damage hit, ref DamageDealt dealt) => dealt.Total += hit.Amount;   // each Damage event, once
```
