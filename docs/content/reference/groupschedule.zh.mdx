一个分组的系统，按阶段排列（[`ScheduleInfo`](/zh/docs/reference/scheduleinfo)）。

#### 参数 [#parameters]

- `Name`：分组类型的名字；默认分组为 "Default"。
- `Stages`：按执行顺序排列的阶段：同一阶段的系统可以同时运行（[`WorldOptions.ParallelSystems`](/zh/docs/reference/worldoptions#parallelsystems)）。
- `RegistrationOrdered`：读写冲突、又没有任何一串 [`UpdateBeforeAttribute`](/zh/docs/reference/updatebeforeattribute) / [`UpdateAfterAttribute`](/zh/docs/reference/updateafterattribute) 规定先后的系统对：它们按注册顺序运行，所以反过来注册会改变后一个系统看到的数据。
