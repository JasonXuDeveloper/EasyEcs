```csharp
public readonly ref struct Emit<T> where T : struct
```

Records a `[ForEach]` pass appends to (Unity's `NativeStream`, a GPU's stream compaction), taken by value: `static void Strike(in Attack attack, in Target target, Emit<Hit> hits) => hits.Add(new Hit(target.Id,
attack.Power));`. Each chunk of a parallel pass (or the whole pass on one thread) appends to its own list, with no lock and no atomic per record; when the pass ends, the lists are appended to the world's [`Emitted`](/en/docs/reference/emitted) singleton (added when missing) in chunk order, which is row order: the records come out in the same order on every run and for any thread count, the order of the same method with `Parallel = false`.

A pass appends, it does not replace: several systems may emit `T` in one update (melee and spells both emit damage), each in its turn, and the system that applies the records clears them (`world.GetSingleton<Emitted<Hit>>().Items.Clear()`), so nothing is applied twice. A method that emits must not also take [`Emitted`](/en/docs/reference/emitted) (EECS070): a parallel pass's records reach it only when the pass ends.

The system writes [`Emitted`](/en/docs/reference/emitted) (once per pass, as a [`Reduce`](/en/docs/reference/reduce) writes its singleton). The chunks' lists come from a pool of their own, kept at the largest size a chunk needed, so steady passes allocate nothing. Valid for the call it is passed to (a ref struct).

#### Type parameters

- `T`: The record: plain data, such as the target and amount of a hit.
