让这个系统排在同一分组里的 `TSystem`（一个 [[EcsSystem]](/zh/docs/reference/ecssystemattribute)，EECS077）之前运行，不管它们的注册顺序。没有指定顺序时，系统按注册顺序运行。不管哪种情况，读写冲突的两个系统，排在前面的总是先跑完；彼此没有顺序约束、也不冲突的系统可能同时运行（[`WorldOptions.ParallelSystems`](/zh/docs/reference/worldoptions#parallelsystems)）。顺序在添加系统时解析一次；有环就在那时抛异常，分析器也会报告它能看出来的环（EECS019）。
