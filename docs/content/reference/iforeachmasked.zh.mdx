还接收"只有部分行通过"的 64 行一字的批量 job（过滤条件要检查存在位或变更 tick）：`World.ForEachMasked` 把整个字交给它，通过的行以位的形式给出；[`IForEachBatch`](/zh/docs/reference/iforeachbatch) 则会把每段连续通过的行分开交给它。向量循环算出每个通道，只保留通过的那些。带向量循环的 `[ForEach]` 方法编译成这个接口。

组件数量从 1 到 9，每个数量一个类型，都由同一个模板生成；下面的成员每个类型都有，以 `IForEachMasked<T1>` 为例。

### `Execute` [#execute]

```csharp
void Execute(EntitySpan entities, ulong rows, Span<T1> c1);
```

一个字里的行：`rows` 的第 i 位为 1 时，第 i 行（`entities` 和每个 span 的第 i 个元素）通过；job 保持其余各行不变（可以把它们的值原样写回）。第 0 位一定为 1，span 长度及之后的位一定为 0。
