One step of a stencil, for [`PaddedTile.Steps`](/en/docs/reference/paddedtile#steps) (temporal blocking): a struct whose static [`ITileStep.Step`](/en/docs/reference/itilestep#step) computes the next value of 16 bytes of cells from the cells around them. Steps runs it over every texel the step can still compute, so the body is the one a single step would have.

#### Type parameters

- `TCell`: The cell.
- `TTile`: The tile's component and shape.
- `TLane`: The lanes the step computes in: `float` for float cells, `byte` for byte ones.

## Properties

### `Reach` [#reach]

```csharp
static abstract int Reach { get; }
```

How far the step reads, in cells, rows and layers (1 for a five-, nine-, seven- or 27-point stencil): Steps runs [`ITileShape.Halo`](/en/docs/reference/itileshape#halo) / Reach steps, the halo a whole number of reaches.

### `Reads` [#reads]

```csharp
static virtual TileReads Reads { get; }
```

What the step reads around a cell, for the rows it skips (default [`TileReads.All`](/en/docs/reference/tilereads#all)).

## Methods

### `Step` [#step]

```csharp
static abstract Vector128<TLane> Step(TileCursor<TCell, TTile> cells, int x);
```

The next value of the 16 bytes of cells from cell `x` of the cursor's row: read them and their neighbours with `cells.Load128<TLane>(x + dx, dy, dz)`, |dx|, |dy|, |dz| ≤ Reach.
