`World.ForEachBatch` 的结构体回调：一次接收一整段行，每个组件一个 span，job 可以用 SIMD 处理（`System.Numerics.Vector`、`MemoryMarshal.Cast`），还能拿到这些行的实体（按下标访问时才构造）。参数是 `Span<T>` / `ReadOnlySpan<T>` 的 `[ForEach]` 方法编译成它。

组件数量从 1 到 9，每个数量一个类型，都由同一个模板生成；下面的成员每个类型都有，以 `IForEachBatch<T1>` 为例。

### `OptionalWrites` [#optionalwrites]


job 在自身组件之外写入的被追踪的组件（通过 [`Maybe`](/zh/docs/reference/maybe)；默认没有）：并行遍历打开它们的变更 tick 区块时，与 [`IForEachBatch.WriteMask`](/zh/docs/reference/iforeachbatch#writemask) 的组件一起打开，让切开同一区块的块共用它。生成的并行 job 标出它们通过 [`Maybe`](/zh/docs/reference/maybe) 的写入。

### `SelfStamped` [#selfstamped]


[`IForEachBatch.WriteMask`](/zh/docs/reference/iforeachbatch#writemask) 里由 job 自己打 tick、而且只在它写的行上打 tick 的组件（位的含义同 [`IForEachBatch.WriteMask`](/zh/docs/reference/iforeachbatch#writemask)；默认没有）：循环不给这些组件的行打 tick。生成的 job 标出它们的 [`Mut`](/zh/docs/reference/mut) 参数。

### `WriteMask` [#writemask]

```csharp
static virtual int WriteMask { get; }
```

job 通过 ref 写入的组件：第 k 个组件对应第 k - 1 位（默认：全部）。job 改变了当前实体的原型时，ForEach 在 job 返回后，把这些组件从 ref 指向的那一行带到实体的新行。生成的 job 只标出它们的 `ref` 参数。
