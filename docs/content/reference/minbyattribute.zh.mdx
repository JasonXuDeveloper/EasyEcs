保留键最小的那一行的归约的键（MPI 的 `MINLOC`，LINQ 的 `MinBy`）：其他字段跟着这一行走。标在 partial struct 的一个数值字段、带 setter 的自动属性或 record 的位置参数上（整数、`float`、`double`、`decimal`）：`public partial record struct Weakest(EntityId Player, [MinBy] int Health) : ISingletonComponent;`。生成器写出这个 struct 的 `IReduction<T>`：`Identity` 里键是它的 `MaxValue`（`float` 和 `double` 是 +∞），其他字段都是默认值；`Combine` 只在 `right` 的键更小时取 `right`（`right.Health < left.Health ? right : left`）。相等时保留左边，也就是先到的行，所以几个线程跑结果都一样；NaN 键永远不会替换别的值。方法按同样的方式保留自己这一块里最小的那行：`if (hp.Value < weakest.Value.Health) weakest.Value = new(player.Id, hp.Value);`。一个 struct 只有一个字段标 [`MinByAttribute`](/zh/docs/reference/minbyattribute) 或 [`MaxByAttribute`](/zh/docs/reference/maxbyattribute)，其他字段不能标别的归约特性。
