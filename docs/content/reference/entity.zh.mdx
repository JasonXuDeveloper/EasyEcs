```csharp
public readonly struct Entity : IEquatable<Entity>
```

实体的句柄：id + 版本号 + World（16 字节）。每次访问都校验版本号，所以指向已销毁实体的句柄永远碰不到复用了这个 id 的新实体：查询类调用（[`Entity.IsAlive`](/zh/docs/reference/entity#isalive)、[`Entity.Has`](/zh/docs/reference/entity#has)、[`Entity.TryGet`](/zh/docs/reference/entity#tryget)、[`Entity.TryGetRef`](/zh/docs/reference/entity#trygetref)）返回 false，访问和修改（[`Entity.Get`](/zh/docs/reference/entity#get)、[`Entity.Read`](/zh/docs/reference/entity#read)、[`Entity.GetOrAdd`](/zh/docs/reference/entity#getoradd)、`Set`、`Remove`）抛异常，[`Entity.Destroy`](/zh/docs/reference/entity#destroy) 什么都不做。可以放心保存和比较。

#### 备注 [#remarks]

[`Entity.Get`](/zh/docs/reference/entity#get) / [`Entity.GetOrAdd`](/zh/docs/reference/entity#getoradd) 返回的 ref 指向实体所在原型表的那一行：拿到就用，不要跨过这个实体的结构变更（它会搬行）或 `await` 保留它。

### `Disable` [#disable]

```csharp
public bool Disable<T>() where T : struct, IComponent;
```

禁用组件 `T`：实体保留它的值，但在 [`Entity.Enable`](/zh/docs/reference/entity#enable) 之前都当作没有它（查询、`Has`、`Get`），同时加上 [`Disabled`](/zh/docs/reference/disabled) 标签。对 `[Removed<T>]` 来说算一次移除；被索引的组件离开索引。实体没有 `T`（或者已经禁用）时返回 false；实体不存活时抛异常。O(1)；一张表里第一次禁用时搬一次行（搬到带这个标签列的表）。不能禁用 [`ICleanupComponent`](/zh/docs/reference/icleanupcomponent)（它要留着等释放）和 [`ChildOf`](/zh/docs/reference/childof)（销毁父实体时要找到子实体）：这两种会抛异常。只能在所有者线程调用。

**复杂度**（[API 表](/zh/docs/api)）：O(1)；一张表第一次禁用时搬一次行

### `SetIfChanged` [#setifchanged]

```csharp
public bool SetIfChanged<T>(in T value) where T : struct, IComponent;
```

把组件 `T` 设为 `value`，除非实体已经是这个值：设了就返回 true（和 `Set` 一样：没有就添加、打 tick、更新索引），值相等就返回 false（什么都不写，不打 tick，不碰索引）。相等的判定和 [`Mut.SetIfChanged`](/zh/docs/reference/mut#setifchanged) 相同。实体不存活时抛异常。相等时 O(1) 加一次比较，否则是 `Set` 的开销。只能在所有者线程调用。

**复杂度**（[API 表](/zh/docs/api)）：O(1) 加一次比较（O(`T` 的大小)）；值不同时同 `Set`

### `TryGet` [#tryget]

```csharp
public bool TryGet<T>(out T value) where T : struct, IComponent;
```

实体拥有组件 `T` 时取得它的副本；没有这个组件或实体不存活时返回 false。不算写入。O(1)。

**复杂度**（[API 表](/zh/docs/api)）：O(1)

### `TryGetRef` [#trygetref]

```csharp
public ref T TryGetRef<T>(out bool found) where T : struct, IComponent;
```

实体拥有组件 `T` 时返回它的 ref，`found` 为 true；否则返回空 ref：用之前先检查 `found`。实体不存活时 `found` 为 false。找到时，对被追踪组件算一次写入。O(1)。

**复杂度**（[API 表](/zh/docs/api)）：O(1)

### `Unlink` [#unlink]

```csharp
public int Unlink<T>(EntityId target) where T : struct, IRelation;
```

删掉实体指向 `target` 的 `T` 链接（目标是它的每一个元素）。返回删掉的数量；只有确实删掉了链接，缓冲区才算写入。O(实体的链接数)。实体不存活时抛异常。

**复杂度**（[API 表](/zh/docs/api)）：O(L)
