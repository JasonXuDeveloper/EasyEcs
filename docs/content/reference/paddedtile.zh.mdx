```csharp
public readonly ref struct PaddedTile<TCell, TTile> where TCell : unmanaged where TTile : struct, IComponent, ITileShape
```

带着 halo 拷入的分块各层（[`Tile.Load`](/zh/docs/reference/tile#load-2)）：模板采样的纹理。用 [`PaddedTile.Rows`](/zh/docs/reference/paddedtile#rows) 遍历要计算的行（活跃的行，用尾零计数找到），用 [`PaddedTile.At`](/zh/docs/reference/paddedtile#at) 在一行周围采样：离它一个格子、一行或一层的样本都在纹理内，偏移不是常量时有检查，是常量时由 JIT 消掉。在线程再次加载这个分块类型之前有效。

#### 类型参数 [#type-parameters]

- `TCell`：格子。
- `TTile`：分块的组件和形状。

### `this[]` [#indexer]

纹理的格子 (x, y, z)：x 从 −1 到 Width，z 从 −1 到 Depth，y 从 From − 1 到 To + 1（2D 分块为 From 到 To）。超出时抛出异常。O(1)。

## 方法 [#methods]

### `At` [#at]

```csharp
public TileCursor<TCell, TTile> At(TileRow<TTile> row);
```

纹理中 `row`（From 到 To 层中的一行，来自这个分块的 [`PaddedTile.Rows`](/zh/docs/reference/paddedtile#rows)，或来自按相同层加载的另一个分块）第一个格子处的位置：它的样本。行在范围外时抛出异常。O(1)。

**复杂度**（[API 表](/zh/docs/api)）：O(1)

### `Rows` [#rows]

```csharp
public TileRows<TTile> Rows(TileReads reads = All);
```

读 `reads` 的模板在 From 到 To 层中必须计算的行，逐层、按顺序（`foreach (var row in padded.Rows(TileReads.Layer))`）：它读的行里有不为零格子的那些。每访问一行、每层 O(1)。加载时没有记录 mask 则抛出异常。

**复杂度**（[API 表](/zh/docs/api)）：每层、每访问一行 O(1)：一次尾零计数
