public readonly ref struct Tile<TCell, TTile> where TCell : unmanaged where TTile : struct, IComponent, ITileShape

The cells of a tile (an entity whose `TTile` makes it one, [`ITile`](/en/docs/reference/itile)) with those of its neighbors: a `[ForEach]` parameter, as a CUDA block's tile and its apron, or an MPI rank's subdomain and its ghost cells. `static void Diffuse(Tile<Heat, Plate> heat, Mut<DynamicBuffer<NextHeat>> next)`: the generated job finds the neighbors by key (one search per neighbor and entity for every tile of the grid), and [`Tile.Pad`](/en/docs/reference/tile#pad-2) copies the layers the stencil shades into a padded tile ([`PaddedTile`](/en/docs/reference/paddedtile)): the entity's cells in the middle, a halo of [`ITileShape.Halo`](/en/docs/reference/itileshape#halo) cells around them from the neighbors' facing cells, and the boundary ([`ITileShape.Boundary`](/en/docs/reference/itileshape#boundary)) where there is no neighbor, so the stencil has no edge cases.

The contract: the system is scheduled as a reader of `DynamicBuffer<TCell>` and of `TTile` (and builds its index before the pass), so every neighbor is read as it was before the pass, and the method may run in parallel; a method that writes either of them may not take the tile (EECS059). Write the step into another component and commit it in another system (double buffering).

Valid for the call it is passed to (a ref struct).

#### Type parameters

- `TCell`: The cell: the element of the entity's `DynamicBuffer<TCell>`.
- `TTile`: The component that places the entity in the grid, with the tile's shape.

### `ChangedEdges` [#changededges]

```csharp
public TileFaces ChangedEdges(ReadOnlySpan<TCell> next, out bool changed);
```

Whether `next` (the tile's step, in the layout of its cells) differs from the tile's cells, and the faces whose edge changed: a cell up to [`ITileShape.Halo`](/en/docs/reference/itileshape#halo) cells from the face, which the neighbor across it reads into its halo. A tile that did not change, beside tiles whose facing edges did not change, computes the same step again: let it sleep, and wake the tiles [`Tile.Facing`](/en/docs/reference/tile#facing) the edges that changed, so a sparse grid costs what its active tiles cost. O(cells), compared row by row as bytes.

**Parameters**

- `next`: The step: at least the tile's cells.
- `changed`: Whether any cell changed.

**Returns** The faces whose edge changed ([`TileFaces.Below`](/en/docs/reference/tilefaces#below) and [`TileFaces.Above`](/en/docs/reference/tilefaces#above) only for a tile of more than one layer).

**Complexity** ([API table](/en/docs/api)): O(cells), row by row as bytes

### `Pad` [#pad-2]

```csharp
public PaddedTile<TCell, TTile> Pad(int from, int to, TCell fill = default, bool mask = true);
```

Layers `from` to `to` padded into this thread's texture: each layer's cells in the middle, a ring of [`ITileShape.Halo`](/en/docs/reference/itileshape#halo) (r) cells around each layer (the facing columns of the west and east neighbors, the facing rows of the north and south ones, the corners from the tiles across the edges when the neighborhood has them), and, for a tile of more than one layer, r layers under `from` and over `to` (the tile's own, or the facing layers of the neighbors below or above). Where there is no neighbor (none in the grid, an empty buffer, or outside the shape's faces and neighborhood) the halo follows [`ITileShape.Boundary`](/en/docs/reference/itileshape#boundary): `fill`, or the tile's own edge clamped or mirrored (along the axis that has no neighbor; a tile across an edge or corner whose axis is clamped is read from the tile beside). With `mask`, it records which rows hold a cell that is not zero (every bit), for [`PaddedTile.Rows`](/en/docs/reference/paddedtile#rows).

O(layers × (Width + 2r) × (Depth + 2r)), no allocation once the thread has its texture (allocated on its first load, for all the layers). The texture belongs to the thread and to this tile type: the next load of `TCell` and `TTile` on the thread replaces it, so a method takes one tile per cell type and grid (EECS073). Throws when the shape is invalid (EECS072), the entity's buffer or a neighbor's that is not empty holds fewer cells than the shape, or the layers are not 0 ≤ from ≤ to &lt; Height.

**Complexity** ([API table](/en/docs/api)):

- `tile.Pad(from, to, fill, mask)`: O(layers × (Width + 2r) × (Depth + 2r)), r = `Halo`; each row one or two vector copies
- `tile.Pad()`: O(layers × (Width + 2r) × (Depth + 2r)), r = `Halo`; each row one or two vector copies
