```csharp
public readonly ref struct Tile<TCell, TTile> where TCell : unmanaged where TTile : struct, IComponent, ITileShape
```

一个瓦片（由 `TTile` 变成瓦片的实体，[`ITile`](/zh/docs/reference/itile)）的格子，连同邻居的格子：一个 `[ForEach]` 参数，就像 CUDA 线程块的瓦片和它的 apron，或 MPI 进程的子区域和它的 ghost 格子。`static void Diffuse(Tile<Heat,
Plate> heat, Mut<DynamicBuffer<NextHeat>> next)`：生成的 job 按键找到邻居（网格的每个瓦片，每个邻居查找一次），[`Tile.Pad`](/zh/docs/reference/tile#pad-2) 把模板要计算的层拷进一个带边的瓦片（[`PaddedTile`](/zh/docs/reference/paddedtile)）：中间是实体自己的格子，外面一圈 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo) 个格子的 halo 来自邻居朝向这边的格子，没有邻居的地方按边界（[`ITileShape.Boundary`](/zh/docs/reference/itileshape#boundary)）处理，所以模板代码没有边界情况。

约定：系统被调度为 `DynamicBuffer<TCell>` 和 `TTile` 的读者（并在遍历之前建好它的索引），所以每个邻居读到的都是遍历之前的值，方法可以并行运行；写其中任何一个的方法不能接收这个瓦片（EECS059）。把这一步的结果写进另一个组件，再由另一个系统提交（双缓冲）。

只在传入它的那次调用内有效（ref struct）。

#### 类型参数 [#type-parameters]

- `TCell`：格子：实体的 `DynamicBuffer<TCell>` 的元素。
- `TTile`：把实体放进网格的组件，带着瓦片的形状。

### `ChangedEdges` [#changededges]

```csharp
public TileFaces ChangedEdges(ReadOnlySpan<TCell> next, out bool changed);
```

`next`（瓦片的这一步，按它的格子布局）是否和瓦片的格子不同，以及哪些面的边缘变了：离这个面 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo) 个格子以内的格子，对面的邻居会把它读进 halo。没有变化、旁边瓦片朝向它的边缘也没变化的瓦片，下一步算出的结果相同：让它休眠，并唤醒 [`Tile.Facing`](/zh/docs/reference/tile#facing) 变化边缘的瓦片，这样稀疏网格的开销只是活跃瓦片的开销。O(格子数)，逐行按字节比较。

**参数**

- `next`：这一步：至少有瓦片那么多格子。
- `changed`：是否有格子变化。

**返回值**：边缘变化的面（[`TileFaces.Below`](/zh/docs/reference/tilefaces#below) 和 [`TileFaces.Above`](/zh/docs/reference/tilefaces#above) 只对不止一层的瓦片）。

**复杂度**（[API 表](/zh/docs/api)）：O(格子数)，逐行按字节比较

### `Pad` [#pad-2]

```csharp
public PaddedTile<TCell, TTile> Pad(int from, int to, TCell border = default, bool mask = true);
```

把第 `from` 到第 `to` 层带边拷进这个线程的纹理：每层的格子在中间，每层外面一圈 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo)（r）个格子（西、东邻居朝向这边的列，北、南邻居朝向这边的行；邻域包含棱时，角来自隔着棱的瓦片）；瓦片不止一层时，`from` 下面和 `to` 上面各多 r 层（瓦片自己的，或下方、上方邻居朝向这边的层）。没有邻居的地方（网格里没有、缓冲为空，或在形状的面和邻域之外），halo 按 [`ITileShape.Boundary`](/zh/docs/reference/itileshape#boundary) 处理：`border`，或瓦片自己的边缘格子钳制或镜像（沿没有邻居的那条轴；隔着棱或角、那条轴被钳制的瓦片，从旁边的瓦片读）。传入 `mask` 时，记录哪些行有不为零的格子（按位），供 [`PaddedTile.Rows`](/zh/docs/reference/paddedtile#rows) 使用。

O(层数 × (Width + 2r) × (Depth + 2r))；线程有了纹理之后零分配（纹理在线程第一次加载时按全部层分配）。纹理属于线程和这个瓦片类型：线程下一次加载 `TCell` 和 `TTile` 时会覆盖它，所以一个方法对每种格子和网格只接收一个瓦片（EECS073）。形状无效（EECS072）、实体的缓冲或某个非空邻居的缓冲比形状的格子少，或层不满足 0 ≤ from ≤ to &lt; Height 时抛出异常。

**复杂度**（[API 表](/zh/docs/api)）：

- `tile.Pad(from, to, fill, mask)`：O(层数 × (Width + 2r) × (Depth + 2r))，r 为 `Halo`；每行一到两次向量拷贝
- `tile.Pad()`：O(层数 × (Width + 2r) × (Depth + 2r))，r 为 `Halo`；每行一到两次向量拷贝
