```csharp
public ref struct Tile<TCell, TTile> where TCell : unmanaged where TTile : struct, ITileShape
```

一个瓦片（由 `TTile` 变成瓦片的实体，[`ITile`](/zh/docs/reference/itile)）的格子，连同邻居的格子：一个 `[ForEach]` 参数，就像 CUDA 线程块的瓦片和它的 apron，或 MPI 进程的子区域和它的幽灵格子。生成的 job 按键找到邻居（网格的每个瓦片，每个邻居查找一次），[`Tile.ExchangeHalo`](/zh/docs/reference/tile#exchangehalo-2) 把模板要计算的层拷进瓦片带边的纹理：中间是实体自己的格子，外面一圈 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo) 个格子的光环来自邻居朝向这边的格子，没有邻居的地方按边界（[`ITileShape.Boundary`](/zh/docs/reference/itileshape#boundary)）处理，所以模板代码没有边界情况。[`Tile.Rows`](/zh/docs/reference/tile#rows) 遍历要计算的行，[`Tile.At`](/zh/docs/reference/tile#at) 在一行周围采样。

按值接收（`Tile<Heat, Plate> heat`）时只读：系统被调度为 `DynamicBuffer<TCell>` 和网格组件的读者（并在遍历之前建好它的索引），所以每个邻居读到的都是遍历之前的值，方法可以并行运行。按 `ref` 接收（`static void Diffuse(ref Tile<Heat, Plate> heat)`）时方法推进瓦片：它用 [`Tile.Write`](/zh/docs/reference/tile#write) 写这一步的行，写进生成的遍历放在格子旁边的第二个缓冲，等每个瓦片都推进完再和格子交换（Jacobi，MPI 的 u / v 交换：跳过的行写成零）；或者原地写，按颜色逐色扫描，直到瓦片稳定（[[GaussSeidel]](/zh/docs/reference/gaussseidelattribute)）。遍历从写过的行找出边缘变化的面，只推进可能变化的瓦片：自上次推进以来，自己的格子或邻居朝向它的边缘变了的那些。

只在传入它的那次调用内有效（ref struct）。

#### 类型参数 [#type-parameters]

- `TCell`：格子：实体的 `DynamicBuffer<TCell>` 的元素。
- `TTile`：瓦片的形状：把实体放进网格的组件，或它的 [`Columns`](/zh/docs/reference/columns)。

### `ChangedEdges` [#changededges]

```csharp
public readonly TileFaces ChangedEdges(ReadOnlySpan<TCell> next, out bool changed);
```

`next`（瓦片的这一步，按它的格子布局）是否和瓦片的格子不同，以及哪些面的边缘变了：离这个面 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo) 个格子以内的格子，对面的邻居会把它读进光环。推进瓦片（`ref Tile`）用不到这些：它的遍历从写过的行找出边缘，并让瓦片休眠。O(格子数)，逐行按字节比较。

**参数**

- `next`：这一步：至少有瓦片那么多格子。
- `changed`：是否有格子变化。

**返回值**：边缘变化的面（[`TileFaces.Below`](/zh/docs/reference/tilefaces#below) 和 [`TileFaces.Above`](/zh/docs/reference/tilefaces#above) 只对不止一层的瓦片）。

**复杂度**（[API 表](/zh/docs/api)）：O(格子数)，逐行按字节比较

### `ExchangeHalo` [#exchangehalo-2]

```csharp
public void ExchangeHalo(int from, int to, TCell border = default, bool mask = true);
```

把第 `from` 到第 `to` 层带着光环拷进这个线程里瓦片的纹理，供 [`Tile.Rows`](/zh/docs/reference/tile#rows)、[`Tile.At`](/zh/docs/reference/tile#at) 和索引器读：每层的格子在中间，每层外面一圈 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo)（r）个格子（西、东邻居朝向这边的列，北、南邻居朝向这边的行；邻域包含棱时，角来自隔着棱的瓦片）；瓦片不止一层时，`from` 下面和 `to` 上面各多 r 层（瓦片自己的，或下方、上方邻居朝向这边的层）。没有邻居的地方（网格里没有、缓冲为空，或在形状的面和邻域之外），光环按 [`ITileShape.Boundary`](/zh/docs/reference/itileshape#boundary) 处理：`border`，或瓦片自己的边缘格子钳制或镜像（沿没有邻居的那条轴；隔着棱或角、那条轴被钳制的瓦片，从旁边的瓦片读）。传入 `mask` 时，记录哪些行有不为零的格子（按位），供 [`Tile.Rows`](/zh/docs/reference/tile#rows) 使用。在 [[GaussSeidel]](/zh/docs/reference/gaussseidelattribute) 推进中，第一次之后的扫描保留自己写过的纹理（这期间其他颜色的邻居不变）：这次调用什么都不拷。

O(层数 × (Width + 2r) × (Depth + 2r))；线程有了纹理之后零分配（纹理在线程第一次交换时按全部层分配）。纹理属于线程和这个瓦片类型：线程下一次交换 `TCell` 和 `TTile` 时会覆盖它，所以一个方法对每种格子和网格只接收一个瓦片（EECS073）。形状无效（EECS072）、实体的缓冲或某个非空邻居的缓冲比形状的格子少，或层不满足 0 ≤ from ≤ to &lt; Height 时抛出异常。

**复杂度**（[API 表](/zh/docs/api)）：

- `tile.ExchangeHalo(from, to, fill, mask)`：O(层数 × (Width + 2r) × (Depth + 2r))，r 为 `Halo`；每行一到两次向量拷贝
- `tile.ExchangeHalo()`：O(层数 × (Width + 2r) × (Depth + 2r))，r 为 `Halo`；每行一到两次向量拷贝

### `Write` [#write]

```csharp
public readonly Span<TCell> Write(TileRow<TTile> row);
```

推进瓦片（`ref Tile` 参数）时，这一步中 `row` 的格子，共 Width 个：第二个缓冲的这一行，等每个瓦片都推进完就成为格子（Jacobi）；在 [[GaussSeidel]](/zh/docs/reference/gaussseidelattribute) 推进中，是纹理自己的这一行（交换过的层中的一行），后面的行和扫描会读它。写满这一行的每个格子：这一步没写的行之后为零。O(1)；按值接收的瓦片抛出异常。
