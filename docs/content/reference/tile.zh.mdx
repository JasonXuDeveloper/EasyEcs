```csharp
public readonly ref struct Tile<TCell, TTile> where TCell : unmanaged where TTile : struct, IComponent, ITileShape
```

一个分块（由 `TTile` 变成分块的实体，[`ITile`](/zh/docs/reference/itile)）的格子，连同邻居的格子：一个 `[ForEach]` 参数，就像 CUDA 线程块的分块和 halo。`static void Diffuse(Tile<Heat,
Plate> heat, Mut<DynamicBuffer<NextHeat>> next)`：生成的 job 按键找到邻居（每个实体找一次，同一网格的所有分块共用），[`Tile.Load`](/zh/docs/reference/tile#load-2) 把模板要计算的层拷进一个带边的分块（[`PaddedTile`](/zh/docs/reference/paddedtile)）：中间是实体自己的格子，外面一圈来自邻居朝向这边的行、列或层，没有邻居的地方是填充值，所以模板代码没有边界情况。

约定：系统被调度为 `DynamicBuffer<TCell>` 和 `TTile` 的读者（并在遍历之前建好它的索引），所以每个邻居读到的都是遍历之前的值，方法可以并行运行；写其中任何一个的方法不能接收这个分块（EECS059）。把这一步的结果写进另一个组件，再由另一个系统提交（双缓冲）。

只在传入它的那次调用内有效（ref struct）。

#### 类型参数 [#type-parameters]

- `TCell`：格子：实体的 `DynamicBuffer<TCell>` 的元素。
- `TTile`：把实体放进网格的组件，带着分块的形状。

### `Load` [#load-2]

```csharp
public PaddedTile<TCell, TTile> Load(int from, int to, TCell fill = default, bool mask = true);
```

把第 `from` 到第 `to` 层带边拷进这个线程的纹理：每层的格子在中间，每层外面一圈一个格子（西、东邻居朝向这边的那一列，北、南邻居朝向这边的那一行，四个角是 `fill`）；分块不止一层时，`from` 下面和 `to` 上面各多一层（分块自己的，或下方、上方邻居朝向这边的那一层，它的外圈是 `fill`）。没有邻居、或邻居的缓冲为空的面是 `fill`。传入 `mask` 时，记录哪些行有不为零的格子（按位），供 [`PaddedTile.Rows`](/zh/docs/reference/paddedtile#rows) 使用。

O(层数 × (Width + 2) × (Depth + 2))；线程有了纹理之后零分配（纹理在线程第一次加载时按全部层分配）。纹理属于线程和这个分块类型：线程下一次加载 `TCell` 和 `TTile` 时会覆盖它，所以一个方法对每种格子和网格只接收一个分块。实体的缓冲、或某个非空邻居的缓冲比形状的格子少，或层不满足 0 ≤ from ≤ to &lt; Height 时抛出异常。

**复杂度**（[API 表](/zh/docs/api)）：

- `tile.Load(from, to, fill, mask)`：O(层数 × (Width + 2) × (Depth + 2))，每行一到两次向量拷贝
- `tile.Load()`：O(层数 × (Width + 2) × (Depth + 2))，每行一到两次向量拷贝
