Ordered walks of a value index whose key is comparable (a score, a deadline, a level): ranges and sorted iteration for leaderboards, timers and matchmaking brackets. The first walk sorts the keys once; the index then keeps them sorted as keys appear and disappear (O(log keys) plus a block move each).
