[`DynamicBuffer`](/zh/docs/reference/dynamicbuffer) 的元素，把所在实体链接到 [`IRelation.Target`](/zh/docs/reference/irelation#target)：一个实体可以有任意多条同一种链接（队伍的成员、商人卖的物品、一个 buff 作用的单位），[`World.Relations`](/zh/docs/reference/world#relations) 能找出链接到某个目标的实体。链接用 [`Entity.Link`](/zh/docs/reference/entity#link) / [`Entity.Unlink`](/zh/docs/reference/entity#unlink)（或者对整个缓冲 `Set`）写入，索引才能跟上；读取用 `Read<DynamicBuffer<T>>()` 或 `in` 参数。和所有被索引的组件一样，分析器会报告通过 `ref` 的写入（EECS015）。
