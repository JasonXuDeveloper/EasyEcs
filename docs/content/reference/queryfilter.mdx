Extra query constraints: components that must be present without being read ([`QueryFilter.With`](/en/docs/reference/queryfilter#with)) or must be absent ([`QueryFilter.Without`](/en/docs/reference/queryfilter#without)). Build once and keep it (e.g. in a static readonly field):

## Methods

### `Changed` [#changed]

```csharp
public QueryFilter Changed<T>(ulong since) where T : struct, IComponent, ITracked;
```

Require `T` and only rows whose `T` was written at or after change tick `since`: a [`World.ChangeTick`](/en/docs/reference/world#changetick) read earlier (`[Changed<T>]` methods select the rows written since their system last ran on their own). A filter has one tick: its `Changed` and `Removed` filters must name the same one.

**Exceptions**

- `ArgumentException`: An earlier `Changed` or `Removed` filter named another tick.

**Complexity** ([API table](/en/docs/api)): O(1); a pass skips tables, 4,096-row blocks and 64-row words written before `since`

Only rows where at least one of `T1, T2` was written at or after change tick `since`: `Changed<T1>(since)` OR ... OR `Changed<T2>(since)` (a row has the component it counts for; the others need not be there). Every `ChangedAny` call of a filter joins one group; the group, the `Changed` and `Removed` filters, a `RemovedAny` group and the other filters combine with AND. A table none of whose columns was written since the tick is skipped whole, and words and blocks of rows no column wrote. A filter has one tick ([`QueryFilter.Since`](/en/docs/reference/queryfilter#since) moves it): keep one per client, run it with each client's tick.

**Exceptions**

- `ArgumentException`: An earlier change filter named another tick.

**Complexity** ([API table](/en/docs/api)): O(n) to build; a pass skips tables none of whose columns of the group was written since `since`, and blocks and words no column wrote

Require `T` with group `group`: only the tables of that group are walked ([`World.GroupBy`](/en/docs/reference/world#groupby); in a world that does not group by `T`, every table holds group 0). One group per filter: naming a second one throws `ArgumentException`.

### `Removed` [#removed]

```csharp
public QueryFilter Removed<T>(ulong since) where T : struct, IComponent, ITracked;
```

Only entities that lost `T` at or after change tick `since` and have not got it back (`[Removed<T>]` methods select the removals since their system last ran on their own). Removing a component keeps the entity's row, so the removal is a row like any other: its presence bit is clear and its change tick says when. Destroyed entities have no row and are not visited. A filter has one tick: its `Changed` and `Removed` filters must name the same one.

**Exceptions**

- `ArgumentException`: An earlier `Changed` or `Removed` filter named another tick.

**Complexity** ([API table](/en/docs/api)): as `Changed`

### `Slice` [#slice]

```csharp
public QueryFilter Slice(int index, int of);
```

Visit only slice `index` of `of` of every matching table's rows: passes with each index from 0 to `of` - 1 in turn visit every row once, each about 1 / `of` of the rows. `[ForEach(Slices = N)]` methods pass the slice of their system's run ([`EcsSystem.RunCount`](/en/docs/reference/ecssystem#runcount) mod N). O(1).

A table is cut at multiples of 64 rows (its presence words), from its row count when the pass starts, so a table of fewer than 64 rows is one piece; table i of the match starts its cut at slice (`index` + i) mod `of`, so many small tables spread over the slices too. Rows that move between passes (a swap-remove fills a hole with the table's last row, a structural change moves an entity to another table, the table grows or shrinks across a cut) may be skipped or visited twice in one cycle of `of` passes; the next cycle sees them again.

Honoured by `ForEach`, `ForEachEntity`, `ForEachBatch` and their `Parallel` forms; the calls that need every matching row (`Query`, `Read`, `Count`, `Any`, `DestroyAll`, `entity.Run`, `SetAll` and the other bulk calls) throw `ArgumentException` for a sliced filter. A slice of 1 is the whole tables.

**Exceptions**

- `ArgumentOutOfRangeException`: `of` is below 1, or `index` is not in [0, `of`).

**Complexity** ([API table](/en/docs/api)): O(1); a pass visits about S / N rows, cut at 64-row words
