```csharp
public interface IOrderKey<TKey> : IComponent where TKey : unmanaged
```

一个组件，含它的表让行按 [`IOrderKey.OrderKey`](/zh/docs/reference/iorderkey#orderkey) 排序，每簇（8 行，ARM64 上 4 行）一个包围盒，罩住 [`IOrderKey.BoxPoint`](/zh/docs/reference/iorderkey#boxpoint)（[`RowClusters`](/zh/docs/reference/rowclusters)）。在键成员上写 [[OrderBy]](/zh/docs/reference/orderbyattribute) 来声明，生成器会显式写出这两个成员，并为每个 World 注册这个顺序：只实现接口不会让任何表排序。

#### 类型参数 [#type-parameters]

- `TKey`：键：整数类型、`char`、`bool`、`float`、`double` 或枚举（基数排序按它的位排序）。空间顺序是组件算出的量化位置的 Morton 码或 Hilbert 码。

## 属性 [#properties]

### `BoxPoint` [#boxpoint]

```csharp
Vector3 BoxPoint { get; }
```

簇的包围盒要罩住的点：最多三个轴（声明里的），其余为 0。

### `OrderKey` [#orderkey]

```csharp
TKey OrderKey { get; }
```

行排序用的键，升序（键相同的行保持原来的顺序）。
