## Methods

### `WhenTargetDestroyed` [#whentargetdestroyed]

```csharp
public static ValueIndex<T, EntityId> WhenTargetDestroyed<T>(this ValueIndex<T, EntityId> index, TargetPolicy policy) where T : struct, IComponent, IIndexed<EntityId>;
```

Decide what destroying an entity does to the `T` components whose key is that entity: an owner whose pet dies loses its `Pet` ([`TargetPolicy.Remove`](/en/docs/reference/targetpolicy#remove)), a summon dies with its summoner ([`TargetPolicy.Destroy`](/en/docs/reference/targetpolicy#destroy)). [`ChildOf`](/en/docs/reference/childof) is [`TargetPolicy.Destroy`](/en/docs/reference/targetpolicy#destroy) from the start; others are [`TargetPolicy.Keep`](/en/docs/reference/targetpolicy#keep). Applied inside every destroy (the index is kept built); O(1) per destroyed entity, O(1) per link it had. Owner thread only.
