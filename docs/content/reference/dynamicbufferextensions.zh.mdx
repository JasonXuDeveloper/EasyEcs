### `TrimExcess` [#trimexcess]

```csharp
public static void TrimExcess<T>(this ref DynamicBuffer<T> buffer);
```

把容量缩到和元素数一样，曾经涨得很大的列表就不会一直占着峰值时的内存（列表的数组会重新分配；空列表不占数组）。O(count)。

**复杂度**（[API 表](/zh/docs/api)）：O(count)
