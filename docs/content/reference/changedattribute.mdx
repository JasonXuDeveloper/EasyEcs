```csharp
public sealed class ChangedAttribute<T> : Attribute where T : struct, IComponent, ITrackChanges
```

The [`ForEachAttribute`](/en/docs/reference/foreachattribute) method visits only entities whose `T` was written since its system last ran ([`EcsSystem.LastRunTick`](/en/docs/reference/ecssystem#lastruntick); on the first run, every entity having it). Requires `T` like [`WithAttribute`](/en/docs/reference/withattribute); `T` tracks changes ([`ITrackChanges`](/en/docs/reference/itrackchanges)). Several attributes require all of the components to have changed.
