The key of a reduction that keeps the row with the highest key (MPI's `MAXLOC`, LINQ's `MaxBy`): `Identity` holds the key's `MinValue` (−∞ for `float` and `double`), `Combine` keeps `right` only when its key is higher, so a tie keeps the earlier rows (see [`MinByAttribute`](/en/docs/reference/minbyattribute)).
