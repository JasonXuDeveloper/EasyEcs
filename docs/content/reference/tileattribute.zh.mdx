按形状声明的网格瓦片（[`ITile`](/zh/docs/reference/itile)）：生成器给这个 partial 组件加上 `ITile<TKey>`，键的类型是标了 [[LookupKey]](/zh/docs/reference/lookupkeyattribute) 或 [[UniqueKey]](/zh/docs/reference/uniquekeyattribute) 的成员的类型；形状的静态成员（[`ITileShape`](/zh/docs/reference/itileshape)）来自这里设的属性，`Beside` 从键推出来：`[Tile(Width = 16, Depth = 16)] public partial record struct HeatPlate([LookupKey] PlatePos Pos) : IComponent;`。`int` 键的 `Beside` 沿 x 走一步（西 −1，东 +1）；带整数成员 `X` 和 `Z`（以及表示层的 `Y`）的键沿这个面的轴走一步，和 [`TileFaces`](/zh/docs/reference/tilefaces) 的定义一致：北 −z，南 +z，西 −x，东 +x，下 −y，上 +y。别的键，或者 `Beside` 会绕回去的网格（环面），自己写 `Beside`，其余的仍由生成器写。自己声明了 `ITile<TKey>` 又没写 `Beside` 的类型，也会得到同样推出来的 `Beside`。
