按它查找实体的键：World 用它给组件建索引（[`IIndexed`](/zh/docs/reference/iindexed)），一个键可以对应多个实体（只对应一个时用 [`UniqueKeyAttribute`](/zh/docs/reference/uniquekeyattribute)）。标在字段、属性或 record 的位置参数上，键就是这个成员（`public partial struct Owner : IComponent { [LookupKey] public EntityId Of; }`）；标在 struct 本身上，键是整个值。生成器给这个 partial struct 加上 `IIndexed<TKey>`（struct 声明的接口已经带上时不加），并显式实现返回这个成员的 `Key`。一个组件只有一个键；由多个成员算出的键仍然手写（`public (int, int) Key => (X, Y);`）。
