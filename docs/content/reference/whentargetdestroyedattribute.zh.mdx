在每个 World 里，销毁一个实体时指向它的链接怎么处理（[`TargetPolicy`](/zh/docs/reference/targetpolicy)）：用在关系（[`IRelation`](/zh/docs/reference/irelation)）或以 [`EntityId`](/zh/docs/reference/entityid) 为键建索引的组件上。World 从第一张含这个组件的表开始（或从创建它的索引开始）就带着这条规则，所以第一次销毁就按它处理；World 自己在索引上调用 `WhenTargetDestroyed` 会替换它。

#### 参数 [#parameters]

- `policy`：每个 World 一开始用的策略。
