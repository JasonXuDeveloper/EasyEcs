On a `[ForEach]` method stepping a tile (a `ref Tile<TCell, TTile>` parameter): Gauss-Seidel instead of Jacobi. The step writes the tile's cells in place, so a row it writes is what the next rows read, and the method, one sweep, runs again on the tile until a sweep changes nothing (at most [`GaussSeidelAttribute.MaxSweeps`](/en/docs/reference/gaussseidelattribute#maxsweeps)). The tiles step color by color, colored by the parity of their keys (two colors for a stencil of the faces, four for a 9-point one, eight for 27 points): no two tiles of one color are neighbors, so the tiles of a color step at once, in parallel, and read the cells the colors before them left, which is the same on any number of threads. A tile whose sweep changed nothing sleeps until a tile beside it changes the edge it reads. For relaxations that settle (`d = Min(neighbor + cost)`: distance fields, flood fills, scents), one pass instead of one per cell crossed.

```csharp
[ForEach(Parallel = true), GaussSeidel]
static void Spread(ref Tile<Scent, Ground> scent) { scent.ExchangeHalo(); foreach (var row in scent.Rows()) ... scent.Write(row) ... }
```
