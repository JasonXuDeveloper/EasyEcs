```csharp
public readonly struct QueryFilter
```

查询的附加条件：必须存在但不读取的组件（[`QueryFilter.With`](/zh/docs/reference/queryfilter#with)），或者必须不存在的组件（[`QueryFilter.Without`](/zh/docs/reference/queryfilter#without)）。建一次并保存起来（比如放进 static readonly 字段）：

```csharp
static readonly QueryFilter Alive = QueryFilter.Create().Without<Dead>();
```

## 方法 [#methods]

### `Changed` [#changed]

```csharp
public QueryFilter Changed<T>(ulong since) where T : struct, IComponent, ITrackChanges;
```

要求有 `T`，并且只选 `T` 在变更 tick `since` 或之后写过的行：`since` 是之前读到的 [`World.ChangeTick`](/zh/docs/reference/world#changetick)（`[Changed<T>]` 方法自己就会选出系统上次运行以来写过的行）。一个过滤条件只有一个 tick：它的 `Changed` 和 `Removed` 必须用同一个。

**异常**

- `ArgumentException`：前面的 `Changed` 或 `Removed` 用了另一个 tick。

**复杂度**（[API 表](/zh/docs/api)）：O(1)；遍历跳过 `since` 之前写过的表、4,096 行的块和 64 行的字

### `Create` [#create]

```csharp
public static QueryFilter Create();
```

不加限制的过滤条件：实体只要拥有查询的组件就匹配。链式调用从它开始（`Create().Without<Dead>()`）。O(1)。

**复杂度**（[API 表](/zh/docs/api)）：O(1)

### `InGroup` [#ingroup]

```csharp
public QueryFilter InGroup<T>(int group) where T : struct, IComponent, IGroup;
```

要求有 `T`，且分组是 `group`：只遍历这一组的表（[`World.GroupBy`](/zh/docs/reference/world#groupby)；World 没有按 `T` 分组时，所有表都属于第 0 组）。一个过滤条件只能指定一个分组。

**复杂度**（[API 表](/zh/docs/api)）：O(1)；遍历只走这个分组的表

### `Removed` [#removed]

```csharp
public QueryFilter Removed<T>(ulong since) where T : struct, IComponent, ITrackChanges;
```

只选在变更 tick `since` 或之后失去 `T`、而且没有再拿回来的实体（`[Removed<T>]` 方法自己就会选出系统上次运行以来的移除）。移除组件后实体的行还在，所以一次移除和别的行一样，也是一行：存在位清零，变更 tick 记着移除的时间。已经销毁的实体没有行，不会访问到。一个过滤条件只有一个 tick：它的 `Changed` 和 `Removed` 必须用同一个。

**异常**

- `ArgumentException`：前面的 `Changed` 或 `Removed` 用了另一个 tick。

**复杂度**（[API 表](/zh/docs/api)）：同 `Changed`

### `Since` [#since]

```csharp
public QueryFilter Since(ulong since);
```

返回同一个过滤条件，只是把它的 [`QueryFilter.Changed`](/zh/docs/reference/queryfilter#changed) 和 [`QueryFilter.Removed`](/zh/docs/reference/queryfilter#removed) 挪到 tick `since`，不用重建：适合存在字段里、每次更新后再用一次的过滤条件。

**复杂度**（[API 表](/zh/docs/api)）：O(1)

### `With` [#with]

```csharp
public QueryFilter With<T>() where T : struct, IComponent;
```

要求 `T` 存在（不传给查询回调）。

### `WithAny` [#withany]

```csharp
public QueryFilter WithAny<T>() where T : struct, IComponent;
```

要求至少拥有各个 `WithAny` 调用列出的组件之一：`WithAny<Burning>().WithAny<Poisoned>()` 匹配带 Burning、带 Poisoned 或两个都带的实体。

### `Without` [#without]

```csharp
public QueryFilter Without<T>() where T : struct, IComponent;
```

要求 `T` 不存在。
