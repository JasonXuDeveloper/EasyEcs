Stream compaction for batch methods, a GPU's ballot and compaction on a CPU: a vector compare decides a lane mask (`Vector256.LessThan(hp, limit).ExtractMostSignificantBits()`: CUDA's `__ballot_sync`; its `__popc` is `PopCount`), and [`Lanes.Compact`](/en/docs/reference/lanes#compact) writes the selected elements side by side: the ids of the rows a batch method picked (`entities.Ids`), their values, their indexes. With AVX-512 a lane of 4 or 8 bytes moves 16 or 8 at a time (`VPCOMPRESSD` / `VPCOMPRESSQ`); with AVX2 8 or 4 at a time through a permutation table (Polychroniou, Raghavan and Ross's selective store: one shuffle per vector, chosen by the vector's bits of the mask); with 128-bit vectors (NEON's `TBL` on ARM64, SSSE3's `PSHUFB`) a lane of 4 bytes moves 4 at a time through a byte shuffle table; otherwise, and for other sizes, one at a time without a branch per element.

## Methods

### `Compact` [#compact]

```csharp
public static int Compact<T>(ReadOnlySpan<T> source, ulong mask, Span<T> destination) where T : unmanaged;
```

Write the elements of `source` whose bit is set in `mask` (bit `i` selects `source[i]`, so at most 64 elements) to the start of `destination`, in order, and return how many: `PopCount(mask)`. Nothing past the end of `source` is read and only that many elements are written. O(64 / lanes per vector) for elements of 4 or 8 bytes with AVX-512 or AVX2 and of 4 bytes with SSSE3 or ARM64's NEON, else O(selected); allocation-free.

**Parameters**

- `source`: The elements to choose from: a run of a batch method's span or of its `EntitySpan.Ids`.
- `mask`: The selected elements; no bit at or past `source.Length` may be set.
- `destination`: Where the selected elements go; at least `PopCount(mask)` long.

**Returns** The number of elements written.

**Exceptions**

- `ArgumentException`: A bit of `mask` selects no element of `source`, or `destination` is too short.

**Complexity** ([API table](/en/docs/api)): O(1): at most 64 elements; for elements of 8 or 4 bytes 8 or 4 vector steps with AVX-512, skipping steps that select nothing; without AVX-512, one step per selected element when 12 or fewer are, else 16 or 8 steps with AVX2, 16 steps for 4-byte elements with 128-bit vectors (ARM64's NEON, SSSE3), otherwise one step per element up to the last selected one

### `Rows` [#rows]

```csharp
public static int Rows(ulong mask, int first, Span<int> destination);
```

Write the numbers of the rows `mask` selects, `first` + the index of each set bit, to the start of `destination` in order, and return how many: the row list of a word of rows a vector condition passed, which generated loops and the core write with this one call whatever the machine ([`Lanes.Compact`](/en/docs/reference/lanes#compact) over the numbers 0 to 63, then `first` added in vectors). O(64 / lanes per vector); allocation-free.

**Parameters**

- `mask`: The selected rows of the word: bit `i` is row `first` + i.
- `first`: The word's first row.
- `destination`: Where the rows go; at least `PopCount(mask)` long.

**Returns** The number of rows written.

**Exceptions**

- `ArgumentException`: `destination` is too short.

**Complexity** ([API table](/en/docs/api)): O(1): `Compact` over the numbers 0 to 63, then `first` added a vector at a time
