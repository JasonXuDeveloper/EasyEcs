[`ForEachAttribute`](/zh/docs/reference/foreachattribute) 方法只访问在系统上次运行之后（[`SystemHandle.LastRunTick`](/zh/docs/reference/systemhandle#lastruntick)）失去 `T`、而且没有再拿回来的实体：同步时把移除发出去，清理时释放组件代表的资源。移除组件后实体的行还在，所以方法能读实体的其他组件；已经销毁的实体不会访问到。`T` 要追踪变更（[`ITracked`](/zh/docs/reference/itracked)），而且不能作为参数（实体已经没有它了，EECS016）。
