public sealed class UpdateIntervalAttribute : Attribute

系统只在所属分组每第 `interval` 次更新时运行：更新计数（[`World.DefaultUpdateCount`](/zh/docs/reference/world#defaultupdatecount)、[`World.UpdateCount`](/zh/docs/reference/world#updatecount)）对间隔取模等于 [`UpdateIntervalAttribute.Phase`](/zh/docs/reference/updateintervalattribute#phase) 的那几次。间隔相同、相位不同的系统把工作分散到不同的更新里，不会全挤在同一次。生成器把这两个值写进系统的代码；间隔至少为 1，相位在 0 到 interval - 1 之间（EECS083）。

```csharp
[EcsSystem, UpdateInterval(4, Phase = 1)]   // updates 1, 5, 9, ...
ref struct Regrowth { ... }
```
