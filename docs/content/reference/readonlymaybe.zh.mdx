public readonly ref struct ReadOnlyMaybe<T> where T : struct, IComponent

`[ForEach]` 方法访问的实体上一个可选、只读的组件：[`ReadOnlyMaybe.Value`](/zh/docs/reference/readonlymaybe#value) 是 `ref readonly`，所以方法按 `T` 的读者调度，被追踪的组件永远不打 tick；带索引的组件（[`IIndexed`](/zh/docs/reference/iindexed)）也能这样接收，[`Maybe`](/zh/docs/reference/maybe) 不行（EECS015：它的 ref 可能背着索引改掉键）。查找方式和 [`Maybe`](/zh/docs/reference/maybe) 一样：不做结构变更的方法每段行查一次列，否则通过实体查找。只在传给它的那次调用里有效（ref struct）。
