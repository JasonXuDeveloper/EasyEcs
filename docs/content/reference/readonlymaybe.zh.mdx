```csharp
public readonly ref struct ReadOnlyMaybe<T> where T : struct, IComponent
```

An optional component of the entity a `[ForEach]` method visits, read-only (as `in` beside `ref`): [`ReadOnlyMaybe.Value`](/zh/docs/reference/readonlymaybe#value) is a `ref readonly`, so the method is scheduled as a reader of `T`, a tracked component is never stamped, and an indexed one ([`IIndexed`](/zh/docs/reference/iindexed)) may be taken, which a [`Maybe`](/zh/docs/reference/maybe) may not (EECS015: its ref could change the key behind the index's back). The same lookups as a [`Maybe`](/zh/docs/reference/maybe): the column once per run of rows in a method that changes no structure, the entity otherwise. Valid for the call it is passed to (a ref struct).
