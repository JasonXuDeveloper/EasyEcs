分块周围哪些分块算作邻居，按偏移沿几条轴移动来分（[`ITileShape.Neighbourhood`](/zh/docs/reference/itileshape#neighbourhood)）：隔着面的分块（von Neumann），加上隔着棱的，或再加上隔着角的（Moore）。2D 分块分别有 4、8、8 个；3D 分别有 6、18、26 个。只算 [`ITileShape.Faces`](/zh/docs/reference/itileshape#faces) 中的轴：只有侧面有邻居的体素列分别有 4、8、8 个。

## 字段 [#fields]

### `All` [#all]

```csharp
All = 2;
```

周围的每个分块（偏移沿最多三条轴）：2D 九点或 3D 27 点模板。

### `Faces` [#faces]

```csharp
Faces = 0;
```

隔着面的分块（偏移沿一条轴）：五点或七点模板只读这些。

### `FacesAndEdges` [#facesandedges]

```csharp
FacesAndEdges = 1;
```

再加上隔着棱的分块（偏移沿两条轴）：2D 网格的角，19 点模板。
