`[ForEach]` 方法（包括并行方法）用的确定性随机数（cuRAND 的 Philox，一种基于计数器的生成器）：每个数都是种子、实体、tick 和流的纯函数，没有要推进的状态，所以每次运行、任何线程数、行以任何顺序运行，结果都一样。它是存放种子和 tick 的单例：`static void Wander(ref Velocity v, Entity entity, in EntityRandom random) => v.X = random.Range(entity.Id, 0,
-1f, 1f);`，推进模拟时钟的系统同时推进 [`EntityRandom.Tick`](/zh/docs/reference/entityrandom#tick)。静态成员显式接收这四个输入（自己的种子、自己时钟的 tick）。

`stream` 区分同一个实体在同一个 tick 里的多次抽取：方法里每个调用点用自己的流（0、1、2……）。同样的四个输入得到同样的数，所以两个调用点用同一个流会抽到同一个数。

这些位是 SplitMix64 终结函数的四轮，每个输入一轮：每一轮都是 64 位上的双射，所以只差一位的两个输入，输出大约有一半的位不同。它是哈希，不是密码学生成器。

#### 参数 [#parameters]

- `Seed`：World 的种子：换一个种子，每个实体的序列都不同。
- `Tick`：这些数所属的模拟步：每一步推进一次。
