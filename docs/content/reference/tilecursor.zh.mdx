带边分块在一行第一个格子处的位置（[`PaddedTile.At`](/zh/docs/reference/paddedtile#at)）：它周围的格子，一次一个或一个向量。偏移以格子计：dx 从 −r（行前第一个 halo 格子）到 Width + r − 1（行后最后一个），dy 和 dz 从 −r 到 r（2D 分块 dy 为 0），r 是形状的 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo)；一个向量的格子必须在行后最后一个 halo 格子处或之前结束。常量偏移由 JIT 检查，其他偏移用一次比较。

#### 类型参数 [#type-parameters]

- `TCell`：格子。
- `TTile`：分块的组件和形状。
