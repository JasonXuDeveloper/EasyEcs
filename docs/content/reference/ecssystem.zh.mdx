```csharp
public abstract class EcsSystem
```

在 World 上运行的逻辑。生命周期：添加时调用 [`EcsSystem.OnCreate`](/zh/docs/reference/ecssystem#oncreate)；之后每次更新先调用 [`EcsSystem.OnUpdate`](/zh/docs/reference/ecssystem#onupdate)，再执行 [[ForEach]](/zh/docs/reference/foreachattribute) 方法；移除时或 World 释放时调用 [`EcsSystem.OnDestroy`](/zh/docs/reference/ecssystem#ondestroy)。这些都在 [`World.Update`](/zh/docs/reference/world#update) 里同步执行（[分组](/zh/docs/reference/updateingroupattribute)里的系统是 [`World.Update`](/zh/docs/reference/world#update-2)）：在调用线程上执行；打开 [`WorldOptions.ParallelSystems`](/zh/docs/reference/worldoptions#parallelsystems) 后，也可能和 [读写](/zh/docs/reference/systemaccess)不冲突的系统一起，在线程池线程上执行。

### `LastRunTick` [#lastruntick]

```csharp
public ulong LastRunTick { get; }
```

这个系统上次运行时 World 的 [`World.ChangeTick`](/zh/docs/reference/world#changetick)（第一次运行前为 0）：它的 `[Changed<T>]` 方法选出这个 tick 之后写入的行，所以不包括它们自己在那一轮的写入。

### `RunCount` [#runcount]

```csharp
public long RunCount { get; }
```

当前这次运行之前，系统已经运行过多少次（第一次运行时为 0；被 [[UpdateInterval]](/zh/docs/reference/updateintervalattribute) 跳过的、禁用期间的运行不算，抛出异常的运行算）。`[ForEach(Slices = N)]` 方法访问它的第 `RunCount % N` 片行，所以 [`EcsSystem.OnUpdate`](/zh/docs/reference/ecssystem#onupdate) 能知道这次运行访问哪一片。
