```csharp
public interface IIndexed<TKey> where TKey : IEquatable<TKey>
```

World 按 [`IIndexed.Key`](/zh/docs/reference/iindexed#key) 建索引的组件：`world.Index<T, TKey>().Find(key)` 枚举 `TKey` 等于某个值的实体（物品的主人、玩家的名字、网格的一个格子）。键是 [`EntityId`](/zh/docs/reference/entityid) 时，这个组件就是关系：按父实体建索引的 `ChildOf(EntityId Parent)` 能找到一个实体的子实体。索引在用 `Set` 和 `CreateEntity` 写入值的同时跟着更新，所以带索引的组件从不通过 `ref` 写入（`Get`、`ref` 参数、查询的元素）：分析器会报告这种写入（EECS015）。
