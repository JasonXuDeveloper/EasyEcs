```csharp
public readonly ref struct Emit<T> where T : struct
```

一次 `[ForEach]` 遍历追加记录的目标（Unity 的 `NativeStream`，GPU 的流压缩），按值传入：`static void Strike(in Attack attack, in Target target, Emit<Hit> hits) => hits.Add(new Hit(target.Id,
attack.Power));`。并行遍历的每个块（单线程时是整次遍历）追加到自己的列表，每条记录不加锁，也没有原子操作；遍历结束时，这些列表按块的顺序（也就是行的顺序）追加到 World 的 [`Emitted`](/zh/docs/reference/emitted) 单例（没有就先添加）：每次运行、任何线程数下记录的顺序都一样，就是同一个方法 `Parallel = false` 时的顺序。

遍历是追加，不是替换：一次更新里可以有几个系统依次产出 `T`（近战和法术都产出伤害），由应用这些记录的系统清空它们（`world.GetSingleton<Emitted<Hit>>().Items.Clear()`），所以没有记录会被应用两次。产出记录的方法不能同时接收 [`Emitted`](/zh/docs/reference/emitted)（EECS070）：并行遍历的记录要到遍历结束才进入它。

系统写 [`Emitted`](/zh/docs/reference/emitted)（每次遍历一次，和 [`Reduce`](/zh/docs/reference/reduce) 写它的单例一样）。各块的列表来自它们自己的池，保持在一个块用过的最大长度，所以稳定的遍历零分配。只在传入它的这次调用里有效（ref struct）。

#### 类型参数 [#type-parameters]

- `T`：记录：普通数据，比如一次命中的目标和伤害。
