```csharp
public readonly ref struct Reduce<T> where T : struct, ISingletonComponent, IReduction<T>
```

把一次 `[ForEach]` 遍历归约到单例 `T`（OpenMP 的 `reduction`，MPI 的 `Allreduce`）：`static void Count(in Health h, Reduce<Census> census) => census.Value.Alive++;`。并行遍历的每个块（单线程时是整次遍历）累加到自己的副本里，副本从 [`IReduction.Identity`](/zh/docs/reference/ireduction#identity) 开始：每行不加锁，也没有原子操作。遍历结束时，副本按块的顺序（也就是行的顺序）合并，结果替换 World 里的 `T`（没有就先添加）。

整数结果是精确的，和线程无关。浮点结果取决于块从哪里开始，因为每个块的和各自舍入：[`ForEachAttribute.ChunkRows`](/zh/docs/reference/foreachattribute#chunkrows) 固定时，每次运行、任何线程数下结果都一样，但和同一个方法 `Parallel = false` 的结果（只有一个部分结果）不一定逐位相同。默认的块大小随线程数变化。

系统写 `T`（每次遍历一次）；[`Reduce.Value`](/zh/docs/reference/reduce#value) 是这个块的部分结果，不是总数。只在传入它的那次调用内有效（ref struct）。

#### 类型参数 [#type-parameters]

- `T`：存放结果的单例，它和自身合并。
