跨遍历保存累计值的归约单例（[`IReduction`](/zh/docs/reference/ireduction)）：带 [`Reduce`](/zh/docs/reference/reduce) 参数的遍历把结果合并进 World 里的值（`Combine(World 里的值, 这次遍历的结果)`：先到的行在前），而不是替换它。不标它时，每次遍历的结果替换这个值。`[Accumulate, Sum] public partial record struct Stats(long Kills, long Hits) : ISingletonComponent;`，再写 `static void Die(in Health h, ref Reduce<Stats> stats) { if (h.Value <= 0) stats.Value.Kills++; }`，就把这次遍历的击杀数加到整局的总数上，单线程或多线程都一样，不用给遍历单独建单例，也不用再写一个系统把它加到总数里。World 里还没有这个单例时，从 `Identity` 开始。
