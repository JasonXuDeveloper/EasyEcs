Logic that runs on a world. Lifecycle: [`EcsSystem.OnCreate`](/en/docs/reference/ecssystem#oncreate) when added, then every update [`EcsSystem.OnUpdate`](/en/docs/reference/ecssystem#onupdate) followed by the [[ForEach]](/en/docs/reference/foreachattribute) methods, and [`EcsSystem.OnDestroy`](/en/docs/reference/ecssystem#ondestroy) when removed or when the world is disposed. Everything runs synchronously within [`World.Update`](/en/docs/reference/world#update) (or [`World.Update`](/en/docs/reference/world#update-2) for systems in a [group](/en/docs/reference/updateingroupattribute)): on the calling thread, or with [`WorldOptions.ParallelSystems`](/en/docs/reference/worldoptions#parallelsystems) on a thread-pool thread next to systems whose [access](/en/docs/reference/systemaccess) does not conflict.

### `LastRunTick` [#lastruntick]

```csharp
public ulong LastRunTick { get; }
```

The world's [`World.ChangeTick`](/en/docs/reference/world#changetick) when this system last ran (0 before its first run): its `[Changed<T>]` methods select rows written after that tick, so not their own writes of that run.

### `RunCount` [#runcount]

```csharp
public long RunCount { get; }
```

How many times the system has run before the current run (0 during its first run; runs skipped by [[UpdateInterval]](/en/docs/reference/updateintervalattribute) or while disabled do not count, a run that throws does). A `[ForEach(Slices = N)]` method visits slice `RunCount % N` of its rows, so [`EcsSystem.OnUpdate`](/en/docs/reference/ecssystem#onupdate) can tell which slice this run visits.
