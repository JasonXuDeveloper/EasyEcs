How a world runs its systems ([`World.DescribeSchedule`](/en/docs/reference/world#describeschedule)): every group's stages, what each system reads and writes, why a system waits for an earlier stage, and which conflicting systems are ordered by nothing but their registration order. A description in names, for reading ([`ScheduleInfo.ToString`](/en/docs/reference/scheduleinfo#tostring)) or drawing ([`ScheduleInfo.ToMermaid`](/en/docs/reference/scheduleinfo#tomermaid)); the scheduler does not read it back.

#### Parameters

- `Groups`: The groups that hold systems, the default group first.
