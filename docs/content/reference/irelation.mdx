An element of a [`DynamicBuffer`](/en/docs/reference/dynamicbuffer) that links its entity to [`IRelation.Target`](/en/docs/reference/irelation#target): an entity holds any number of links of one kind (the members of a party, the items a merchant offers, the units a buff applies to), and [`World.Relations`](/en/docs/reference/world#relations) finds the entities linking to a target. Links are written with [`Entity.AddRelation`](/en/docs/reference/entity#addrelation) / [`Entity.RemoveRelation`](/en/docs/reference/entity#removerelation) (or `Set` of a whole buffer), so the index follows; read them with `Read<DynamicBuffer<T>>()` or an `in` parameter. The analyzer reports writes through a `ref` (EECS015), as for any indexed component.
