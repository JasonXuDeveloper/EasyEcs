A reduction of a `[ForEach]` pass into singleton `T` (OpenMP's `reduction`, MPI's `Allreduce`): `static void Count(in Health h, Reduce<Census> census) => census.Value.Alive++;`. Each chunk of a parallel pass (or the whole pass on one thread) accumulates into its own copy, which starts at [`IReduction.Identity`](/en/docs/reference/ireduction#identity): no lock and no atomic per row. When the pass ends, the copies are combined in chunk order, which is row order, and the result replaces the world's `T` (added when missing).

Integer results are exact and do not depend on the threads. A floating-point result depends on where chunks begin, since each chunk's sum is rounded on its own: with a fixed [`ForEachAttribute.ChunkRows`](/en/docs/reference/foreachattribute#chunkrows) it is the same on every run and for any thread count, but not bit for bit the result of the same method with `Parallel = false` (one partial result). The default chunk size follows the thread count.

The system writes `T` (once per pass); [`Reduce.Value`](/en/docs/reference/reduce#value) holds this chunk's partial result, not the total. Valid for the call it is passed to (a ref struct).

#### Type parameters

- `T`: The singleton holding the result, which combines with itself.
