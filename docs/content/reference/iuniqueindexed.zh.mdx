```csharp
public interface IUniqueIndexed<TKey> : IIndexed<TKey> where TKey : IEquatable<TKey>
```

键只对应一个实体的 [`IIndexed`](/zh/docs/reference/iindexed) 组件：玩家的账号 id、会话令牌、网格格子里的占用者。一次写入如果会让第二个实体拿到另一个实体已有的键，就在改动任何东西之前抛出 `InvalidOperationException`（Set、CreateEntity / CreateEntities、GetOrAdd、Instantiate、Clone、SetAll、Enable / EnableAll、LoadEntities / LoadEntitiesInto、MoveEntities）；[`World.Load`](/zh/docs/reference/world#load) 一个同一个键出现两次的存档时抛出 `InvalidDataException`。之后 World 保持原样。给实体重新写入它自己的键没问题；要把一个键从一个实体挪到另一个实体，先改第一个，再改第二个。null 键（引用类型键的默认值）不算键：任意多个实体都可以有，查找也找不到它们。[`EntityId`](/zh/docs/reference/entityid) 键（关系）不能唯一。

唯一组件的索引是立即建立的：每个 World 在第一张含这个组件的表出现时就建立它，所以从第一次写入起每次写入都会检查（[`IIndexed`](/zh/docs/reference/iindexed) 的索引在第一次查找时才建立）。用 `world.Index<T, TKey>().Get(key)` / `TryGet`（生成的 `world.XIndex`）查找实体；`Find`、`Count` 和有序遍历和其他索引一样。
