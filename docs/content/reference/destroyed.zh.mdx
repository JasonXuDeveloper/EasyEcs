实体持有 [`ICleanupComponent`](/zh/docs/reference/icleanupcomponent) 时销毁，就会带上这个标签：其他组件已经去掉，实体一直存活到最后一个清理组件移除为止。清理系统用 `With<Destroyed>` 选出这些实体，获取资源的系统用 `Without<Destroyed>` 只选新实体。
