`[ForEach]` 方法在运行它的线程上的工作内存（OpenMP 的 `threadprivate`）：邻居列表、寻路的开放集、要填充的缓冲区。`static void Plan(ref Path path, in Goal goal, Scratch<Frontier> frontier)`：[`Scratch.Value`](/zh/docs/reference/scratch#value) 是每个方法、每个线程一个的 `T`，开始是 `default`，在线程的整个生命周期内保留，所以一行往里分配的东西（`value.Ids ??= new int[256]`）每个线程只在第一次运行该方法时分配一次，稳定状态不分配。值本身的空间，只要有一个线程运行了该方法，就在每个辅助线程（[`WorldOptions.MaxDegreeOfParallelism`](/zh/docs/reference/worldoptions#maxdegreeofparallelism)）上建好。两个线程从不共享同一个；并行遍历中在同一线程上运行的块一个接一个地运行，所以一行在它的调用期间独占它。

它从不重置：一行看到的是同一线程上一行留下的内容，可能来自本次遍历或更早的遍历，来自这个 World 或另一个 World。在行的开头清空你要用的东西（`list.Clear()`）；属于 World 的数据不能在行与行之间留在这里。把它按引用持有的东西存进组件或单例（EECS058），等于把一个线程的内存交给下一个复用它的行。它的内存属于线程：线程结束时释放，而不是 World 释放时。

只在传入它的那次调用内有效（ref struct）。

#### 类型参数 [#type-parameters]

- `T`：工作值：持有缓冲区的结构体，或 `List<int>` 这样的类（首次使用时创建：`scratch.Value ??= new()`）。
