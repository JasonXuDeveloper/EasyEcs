```csharp
public interface ITile<TKey> : ITileShape, IIndexed<TKey> where TKey : IEquatable<TKey>
```

让实体成为网格中一个瓦片的组件，按键查找（带索引的组件，[`IIndexed`](/zh/docs/reference/iindexed)）：`record struct Chunk(ChunkPos Pos) : IComponent, ITile<ChunkPos>`，带着形状（[`ITileShape`](/zh/docs/reference/itileshape)）和每个邻居的键（[`ITile.Beside`](/zh/docs/reference/itile#beside)）。接收它的 [`Tile`](/zh/docs/reference/tile) 的 `[ForEach]` 方法拿到实体的格子和通过索引找到的邻居的格子。

#### 类型参数 [#type-parameters]

- `TKey`：键：瓦片在网格中的位置。

## 方法 [#methods]

### `Beside` [#beside]

```csharp
static abstract TKey Beside(TKey key, TileFaces face);
```

位于 `key` 的瓦片在 `face`（[`ITileShape.Faces`](/zh/docs/reference/itileshape#faces) 中的一个面）对面的瓦片的键。隔着一条棱或一个角的瓦片，一次跨一个面找到：先 x，再 z，最后 y。周期网格在这里回绕（最后一个瓦片的东边是第一个）。
