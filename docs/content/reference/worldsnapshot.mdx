```csharp
public sealed class WorldSnapshot
```

A copy of a world's entities, components and singletons, taken by [`World.Capture`](/en/docs/reference/world#capture) and put back by [`World.Restore`](/en/docs/reference/world#restore) (systems and options are not part of it). Holds the copies only; it can be restored any number of times, into the world it was taken from. [`World.Capture`](/en/docs/reference/world#capture-2) overwrites it, reusing its arrays (no allocation once they are large enough).
