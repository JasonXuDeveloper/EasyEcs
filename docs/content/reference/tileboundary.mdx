What the halo holds where a tile has no neighbor ([`ITileShape.Boundary`](/en/docs/reference/itileshape#boundary)), the boundary condition of the grid. A periodic grid needs none: its [`ITile.Beside`](/en/docs/reference/itile#beside) wraps, so every tile has neighbors.

## Fields

### `Clamp` [#clamp]

```csharp
Clamp = 1;
```

The tile's own edge cell, repeated: the halo cell at −k is cell 0.

### `Fill` [#fill]

```csharp
Fill = 0;
```

The fill value of [`Tile.Pad`](/en/docs/reference/tile#pad-2) (default zero): a Dirichlet boundary.

### `Mirror` [#mirror]

```csharp
Mirror = 2;
```

The tile's own cells, mirrored at its edge: the halo cell at −k is cell k − 1 (a zero-flux, Neumann boundary).
