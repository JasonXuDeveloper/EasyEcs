public interface IOrderKey<TKey> : IComponent where TKey : unmanaged

A component whose tables keep their rows in the order of [`IOrderKey.OrderKey`](/en/docs/reference/iorderkey#orderkey), with a box per cluster of rows (8, or 4 on ARM64) over [`IOrderKey.BoxPoint`](/en/docs/reference/iorderkey#boxpoint) ([`RowClusters`](/en/docs/reference/rowclusters)). Declared with [[OrderBy]](/en/docs/reference/orderbyattribute) on the key member, which makes the generator write both members explicitly and register the order for every world: the interface alone orders nothing.

#### Type parameters

- `TKey`: The key: an integer type, `char`, `bool`, `float`, `double` or an enum (a radix sort orders its bits). A spatial order is a Morton or Hilbert code of a quantized position, computed by the component.

## Properties

### `BoxPoint` [#boxpoint]

```csharp
Vector3 BoxPoint { get; }
```

The point the box of a cluster covers: up to three axes (the declaration's), the others 0.

### `OrderKey` [#orderkey]

```csharp
TKey OrderKey { get; }
```

The key rows are ordered by, ascending (rows with equal keys keep their order).
