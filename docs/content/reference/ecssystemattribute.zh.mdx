声明一个系统：一个 `ref struct`，它的静态方法就是在 World 上运行的逻辑。系统永远不是对象（ref struct 不能装箱、存储或捕获）；World 把它的簿记作为数据保存（[`SystemHandle`](/zh/docs/reference/systemhandle)），生成器写出运行它的代码，由 World 直接调用。

生命周期：钩子就是按名字命名的静态方法，不需要特性。添加时（[`World.AddSystem`](/zh/docs/reference/world#addsystem)）调用 `OnCreate`；之后每次更新先调用 `OnUpdate`，再按声明顺序执行 [[ForEach]](/zh/docs/reference/foreachattribute) 方法；移除时或 World 释放时调用 `OnDestroy`。钩子接收 [`World`](/zh/docs/reference/world)、[`SystemHandle`](/zh/docs/reference/systemhandle)、两者都要或都不要，返回 void（EECS076）；`OnUpdate` 什么都能碰，所以它的系统从不和别的系统共享并行阶段（[`SystemAccess.RunAlone`](/zh/docs/reference/systemaccess#runalone)）。这些都在 [`World.Update`](/zh/docs/reference/world#update) 里同步执行（[分组](/zh/docs/reference/updateingroupattribute)里的系统是 [`World.Update`](/zh/docs/reference/world#update-2)）：在调用线程上执行；打开 [`WorldOptions.ParallelSystems`](/zh/docs/reference/worldoptions#parallelsystems) 后，也可能和 [读写](/zh/docs/reference/systemaccess)不冲突的系统一起，在进程的辅助线程上执行。

```csharp
[EcsSystem, UpdateAfter<Input>]
ref struct Movement
{
    [ForEach] static void Move(ref Position p, in Velocity v) { p.X += v.X; p.Y += v.Y; }
}

world.AddSystem<Movement>();
```

系统只声明静态成员（状态属于组件和单例）；几个系统共享的东西写成泛型系统（`[EcsSystem] ref struct Regen<T>`）或静态辅助函数，构造函数参数配置的东西改成单例。
