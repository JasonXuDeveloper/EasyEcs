高瓦片里一个格子方法的遍历覆盖的层，来自方法所取的、瓦片实体上的一个组件（`in TLayers`）：遍历只交换 [`ITileLayers.From`](/zh/docs/reference/itilelayers#from) 到 [`ITileLayers.To`](/zh/docs/reference/itilelayers#to) 这些层的光环（连同它们的光环层，和 [`Tile.ExchangeHalo`](/zh/docs/reference/tile#exchangehalo-2) 一样），也只走这些层，适合数据只在少数几层、而用户自己的统计知道是哪几层的模板（一片地形的水能到的层）：

```csharp
public record struct FlowLayers(int From, int To) : IComponent, ITileLayers;

[ForEach(Parallel = true)]
static void Flow(Cell<Fluid, Chunk> w, Cell<Block, Chunk> g, in FlowLayers layers, out NextFluid next) => ...
```

范围外的行得到方法在空白格子上算出的值，和遍历跳过的行一样：所以这些层必须包含每一个模板读到非零格子的行（瓦片自己的、旁边邻居的，以及模板向上向下够到的层）。层会被夹到瓦片之内（0 到 Height - 1）；[`ITileLayers.From`](/zh/docs/reference/itilelayers#from) 大于 [`ITileLayers.To`](/zh/docs/reference/itilelayers#to) 时什么都不交换，所有行都填上。生成器只在证明了方法在空白行上算出什么的地方才限定遍历（调度行写 "layers of '...'"）；其他地方每一层都运行（EECS123）。
