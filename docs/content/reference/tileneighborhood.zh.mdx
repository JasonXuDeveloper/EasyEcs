瓦片周围哪些瓦片算作邻居，按偏移沿几条轴移动来分（[`ITileShape.Neighborhood`](/zh/docs/reference/itileshape#neighborhood)）：隔着面的瓦片（von Neumann），加上隔着棱的，或再加上隔着角的（Moore）。2D 瓦片分别有 4、8、8 个；3D 分别有 6、18、26 个。只算 [`ITileShape.Faces`](/zh/docs/reference/itileshape#faces) 中的轴：只有侧面有邻居的体素列分别有 4、8、8 个。

## 字段 [#fields]

### `All` [#all]

```csharp
All = 2;
```

周围的每个瓦片（偏移沿最多三条轴）：2D 九点或 3D 27 点模板。

### `Faces` [#faces]

```csharp
Faces = 0;
```

隔着面的瓦片（偏移沿一条轴）：五点或七点模板只读这些。

### `FacesAndEdges` [#facesandedges]

```csharp
FacesAndEdges = 1;
```

再加上隔着棱的瓦片（偏移沿两条轴）：2D 网格的角，19 点模板。
