实体的身份：下标，加上这个下标的版本号（8 字节，非托管）。凡是从数据里引用实体的地方（关系、目标、主人、消息）都存它：只含非托管值的组件保持非托管列，这种列固定在内存里、整块复制、GC 从不扫描，序列化时直接写原始字节。用 [`World.TryGetEntity`](/zh/docs/reference/world#trygetentity) 换回句柄；句柄可以隐式转换成 id。`default` 就是 [`EntityId.Null`](/zh/docs/reference/entityid#null)，没有哪个实体用这个 id。
