嵌套在 [`TileColumnWalk`](/zh/docs/reference/tilecolumnwalk) 里。

遍历停在行中某一列：它周围的格子，一次一个或一个向量，偏移从这一列算起；还能把一个向量从这一列存进步进写的那一行。偏移以格子计：dx 从 −r 起，到从遍历的最后一列加载仍在行后最后一个 halo 格子（Width + r − 1）处或之前结束为止；dy 和 dz 从 −r 到 r（2D 瓦片 dy 为 0），r 是形状的 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo)。遍历的每一列都通过同一个检查，所以步长是常量时，常量偏移由 JIT 检查，其他偏移用一次比较。
