Marker of a system group: systems marked [`UpdateInGroupAttribute`](/en/docs/reference/updateingroupattribute) run together when [`World.Update`](/en/docs/reference/world#update-2) is called, independently of the default group run by [`World.Update`](/en/docs/reference/world#update). Use groups for different cadences (a fixed-rate simulation tick vs. work that runs whenever input arrives).

```csharp
public struct NetworkGroup : ISystemGroup;

[UpdateInGroup<NetworkGroup>]
public class ReceiveSystem : EcsSystem { ... }

world.Update<NetworkGroup>();   // whenever packets arrive
world.Update();                     // fixed tick: default group
```

A group may carry [`WithAttribute`](/en/docs/reference/withattribute), [`WithoutAttribute`](/en/docs/reference/withoutattribute) and [`WithAnyAttribute`](/en/docs/reference/withanyattribute) filters: the generator adds them to every [ForEach] method of its systems (`[Without<Inactive>] public struct Gameplay : ISystemGroup;` keeps inactive entities out of the whole group). Queries a system makes in OnUpdate are its own.
