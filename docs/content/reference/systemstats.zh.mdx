系统运行了多少次、花了多长时间（[`WorldOptions.MeasureSystems`](/zh/docs/reference/worldoptions#measuresystems)）：每次运行包括 `OnUpdate` 方法和它的 `[ForEach]` 方法，并记下分配的字节数和 `[ForEach]` 方法访问的实体数。在两次更新之间读取；打开 [`WorldOptions.ParallelSystems`](/zh/docs/reference/worldoptions#parallelsystems) 时，每个系统各自记录自己的运行。

每次运行的平均耗时（第一次运行前为零）。

### `LastAllocated` [#lastallocated]

```csharp
public long LastAllocated { get; }
```

最近一次运行在托管堆上分配的字节数：运行系统的线程上的，加上运行它的并行 `[ForEach]` 方法各个块的线程上的（每段前后各取一次 `GC.GetAllocatedBytesForCurrentThread`）。

### `LastEntities` [#lastentities]

```csharp
public long LastEntities { get; }
```

最近一次运行的 `[ForEach]` 方法访问的实体数：每个方法的遍历开始时它的查询匹配的实体（通过过滤条件的行；`[Changed<T>]` / `[Removed<T>]` 还要求在系统上次运行之后写过或移除过），各方法相加；`[ForEach(Slices = N)]` 方法只算它这次访问的那一片的行。OnUpdate 方法里做的查询不算。
