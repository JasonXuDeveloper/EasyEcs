```csharp
public readonly struct SystemStats
```

How often and how long a system ran ([`WorldOptions.MeasureSystems`](/zh/docs/reference/worldoptions#measuresystems)): its `OnUpdate` method plus its `[ForEach]` methods, per run, with the bytes it allocated and the entities its `[ForEach]` methods visited. Read it between updates; with [`WorldOptions.ParallelSystems`](/zh/docs/reference/worldoptions#parallelsystems) each system records its own runs.

最近一次运行在托管堆上分配的字节数：运行系统的线程上的，加上运行它的并行 `[ForEach]` 方法各个块的线程上的（每段前后各取一次 `GC.GetAllocatedBytesForCurrentThread`）。

### `LastEntities` [#lastentities]

```csharp
public long LastEntities { get; }
```

Entities the latest run's `[ForEach]` methods visited: the entities each method's query matched when its pass started (rows passing its filters and, for `[Changed<T>]` / `[Removed<T>]`, written or removed since the system last ran), summed over the methods; a `[ForEach(Slices = N)]` method counts the rows of the slice it visited. Queries made in its OnUpdate method are not counted.
