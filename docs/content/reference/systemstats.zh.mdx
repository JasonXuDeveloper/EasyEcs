系统运行了多少次、花了多长时间（[`WorldOptions.MeasureSystems`](/zh/docs/reference/worldoptions#measuresystems)）：每次运行包括 [`EcsSystem.OnUpdate`](/zh/docs/reference/ecssystem#onupdate) 和它的 `[ForEach]` 方法。在两次更新之间读取；打开 [`WorldOptions.ParallelSystems`](/zh/docs/reference/worldoptions#parallelsystems) 时，每个系统各自记录自己的运行。
