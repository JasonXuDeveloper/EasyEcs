[[Group]](/en/docs/reference/groupattribute), and every world groups the component's tables by this member ([`World.GroupBy`](/en/docs/reference/world#groupby)) from its first table holding it: a group filter ([`QueryFilter.InGroup`](/en/docs/reference/queryfilter#ingroup)) then visits that group's tables only, in every world, with no setup call to forget. `public partial record struct Zone([GroupBy] int Id) : IComponent;` On the `Group` property of a hand-written [`IGroup`](/en/docs/reference/igroup), it only makes every world group by it.
