A reduction singleton ([`IReduction`](/en/docs/reference/ireduction)) that holds a total across passes: a pass with a [`Reduce`](/en/docs/reference/reduce) parameter combines its result into the world's value (`Combine(world's value, pass's
result)`: the earlier rows first) instead of replacing it. Without it, each pass's result replaces the value. `[Accumulate, Sum] public partial record struct Stats(long Kills, long Hits) : ISingletonComponent;`, then `static void Die(in Health h, ref Reduce<Stats> stats) { if (h.Value <= 0) stats.Value.Kills++; }` adds the pass's kills to the run's total, on one thread or several, with no singleton of the pass's own and no system that adds it to the total. A world without the singleton starts it at `Identity`.
