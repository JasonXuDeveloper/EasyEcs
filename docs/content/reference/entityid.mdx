The identity of an entity: its index and the incarnation of that index (8 bytes, unmanaged). Store it wherever an entity is referred to from data (a relation, a target, an owner, a message): a component holding only unmanaged values keeps an unmanaged column, which is pinned, copied as a block and never scanned by the GC, and serializes as raw bytes. Turn it back into a handle with [`World.TryGetEntity`](/en/docs/reference/world#trygetentity); a handle converts to its id implicitly. `default` is [`EntityId.Null`](/en/docs/reference/entityid#null), which no entity has.
