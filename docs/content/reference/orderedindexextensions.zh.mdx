键可比较（分数、截止时间、等级）的值索引的有序遍历：按区间或按顺序遍历，用于排行榜、计时器和匹配分段。第一次遍历时把键排一次序；之后键出现和消失，索引都保持有序（每次 O(log 键数)，外加一次块移动）。
