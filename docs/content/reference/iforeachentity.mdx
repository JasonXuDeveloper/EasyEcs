Like [`IForEach`](/en/docs/reference/iforeach) but also receives the [`Entity`](/en/docs/reference/entity) handle, built from the archetype's entity rows (id and version side by side) without a per-entity lookup. `[ForEach]` methods taking an [`Entity`](/en/docs/reference/entity) compile to this.

## Properties

### `Writes` [#writes]

```csharp
static virtual int Writes { get; }
```

Components the job writes through its refs: bit k - 1 for component k (default: all). When the job changes the archetype of the entity it visits, ForEach carries those components over from the row the refs point into to the entity's new row after the job returns. Generated jobs set only their `ref` parameters.
