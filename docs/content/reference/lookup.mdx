```csharp
public readonly ref struct Lookup<T> where T : struct, IComponent
```

Read-only access to component `T` of any entity, from a `[ForEach]` method (MPI's one-sided `Get`, Unity's `ComponentLookup`): `static void Chase(ref Velocity v, in Target target,
Lookup<Position> positions)` reads the target's position with `positions[target.Id]`. The method stays free of the World, so it may run in parallel ([`ForEachAttribute.Parallel`](/en/docs/reference/foreachattribute#parallel)) and share a parallel stage with systems that do not write `T`.

The contract: no one writes `T` while the pass runs, so every read sees the value from before the pass. The system is scheduled as a reader of `T`, so no system writing it shares its stage; a method that writes `T` itself (a `ref`, `Mut`, writable `Maybe` or span parameter) may not look it up (EECS059: rows written during the pass would be read before or after their write, or torn on another thread); and the pass makes no structural change, so ids keep their rows.

An indexed `T` ([`IIndexed`](/en/docs/reference/iindexed)) is also found by key ([`LookupExtensions`](/en/docs/reference/lookupextensions): `TryFind`, `Find`, `Count`, called on the parameter itself): its index is created and built before the pass, and before the parallel stage of its system, so a lookup during a pass never changes it. (A value index otherwise builds on its first lookup; reached any other way during a parallel stage or pass, an index not built yet throws instead of building.)

Each lookup is one entity lookup ([`World.TryGetEntity`](/en/docs/reference/world#trygetentity), then the row's column). Valid for the call it is passed to (a ref struct).

#### Type parameters

- `T`: The component read.
