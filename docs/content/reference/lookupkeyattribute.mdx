The key entities are looked up by: a world indexes the component by it ([`IIndexed`](/en/docs/reference/iindexed)), several entities per key ([`UniqueKeyAttribute`](/en/docs/reference/uniquekeyattribute) for one). On a field, a property or a record's positional parameter, the key is that member (`public partial struct Owner : IComponent { [LookupKey] public EntityId Of; }`); on the struct itself, the key is the whole value. The generator adds `IIndexed<TKey>` to the partial struct (unless an interface the struct declares brings it) with an explicit `Key` returning the member. One key per component; a key computed from several members is written by hand (`public (int, int) Key => (X, Y);`).
