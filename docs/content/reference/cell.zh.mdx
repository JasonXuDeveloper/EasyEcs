瓦片的一个格子和它的邻居，是计算一个格子的 [ForEach] 方法的参数：模板的着色器写法。方法读这个格子（[`Cell.Value`](/zh/docs/reference/cell#value)）和常量偏移处的邻居（`w[-1, 0, 0]`，在形状的 [`ITileShape.Halo`](/zh/docs/reference/itileshape#halo) 之内），给 `out` 参数赋值，也就是实体同类型 `DynamicBuffer` 里同一位置的格子：

```csharp
[ForEach(Parallel = true)]
static void Blur(Cell<Warmth, Plate> w, out NextWarmth next) =>
    next = new((w[-1, 0, 0].T + w.Value.T + w[1, 0, 0].T) * (1f / 3));
```

遍历由生成器写：每个瓦片交换一次光环，只走偏移读到的行（安静的行得到方法在全零上算出的值），每行是一个遍历格子的向量循环，邻居是带光环纹理上的非对齐加载；向量循环处理不了的格子按方法原样运行。把它当作瓦片参数（[`Tile`](/zh/docs/reference/tile)）看：行需要瓦片组件和格子的 buffer，邻居来自网格的索引。

#### 类型参数 [#type-parameters]

- `TCell`：格子。
- `TTile`：瓦片的组件和形状。

### `this[]` [#indexer]

```csharp

```

从这个格子偏移 (`dx`, `dy`, `dz`) 处的格子，每个偏移都在形状的光环之内（只有一层的瓦片 dy 为 0）：瓦片里的邻居，或邻居（或边界）给出的光环格子。偏移是常量，所以生成器把它们读作固定偏移的加载。O(1)；超出光环时抛出异常。
