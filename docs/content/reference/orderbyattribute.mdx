The key every world keeps the component's tables ordered by, and the point the boxes of their blocks cover. A table needs no declaration to be ordered for a pair method: the generator infers the order from the method's distance test (the Morton code of the position by the cutoff, `World.OrderRows`). `[OrderBy]` overrides that order for every world: another key, a non-spatial order. On a member of a partial component (a field, a property or a record's positional parameter) whose type is an integer, `char`, `bool`, `float`, `double` or an enum. A spatial order is a Morton code of a quantized position the component computes, and the box axes name its coordinates: `public partial record struct Position(float X, float Y) : IComponent { [OrderBy(nameof(X), nameof(Y))] public readonly uint Cell => Map.Morton(X, Y); }` (`Map.Morton` standing for the game's own quantization). The generator adds [`IOrderKey`](/en/docs/reference/iorderkey) with an explicit `OrderKey` returning the member and `BoxPoint` returning the axes, and registers the order: every world re-sorts each table holding the component every [`OrderByAttribute.Interval`](/en/docs/reference/orderbyattribute#interval) updates (from the first update after the table appears), keeping the rows of the table in key order and a box per block of rows (8, or 4 on ARM64) over the axes ([`RowBlocks`](/en/docs/reference/rowblocks)). Rows that join between sorts wait at the end of their table; a row that moves into a block widens its box. A table that holds two ordered components is ordered by the one with the lower bit.

#### Parameters

- `box`: The members the blocks' boxes cover, up to three: `float` fields or properties of the component, or one `Vector2` or `Vector3`. None: rows are ordered, the blocks have no box.

### `Interval` [#interval]

```csharp
public int Interval { get; set; }
```

[`World.Update`](/en/docs/reference/world#update) calls between sorts (default 10, at least 1): GROMACS rebuilds its pair lists every 10 steps, and a sort's cost spread over 10 updates is a small share of a tick (decision D137).

### `Margin` [#margin]

```csharp
public float Margin { get; set; }
```

How far a row may move between sorts and stay inside its block's box: every box is widened by it on each side (the buffer of GROMACS's pair lists). 0 by default: a search that must find every row within a range adds the distance rows move per update times [`OrderByAttribute.Interval`](/en/docs/reference/orderbyattribute#interval).
