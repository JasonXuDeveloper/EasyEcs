系统分组的标记：标了 [`UpdateInGroupAttribute`](/zh/docs/reference/updateingroupattribute) 的系统在调用 [`World.Update`](/zh/docs/reference/world#update-2) 时一起运行，和 [`World.Update`](/zh/docs/reference/world#update) 运行的默认分组互不相干。节奏不同的工作放进不同的分组（固定频率的模拟 tick，和有输入到达就运行的工作）。

```csharp
public struct NetworkGroup : ISystemGroup;

[UpdateInGroup<NetworkGroup>]
public class ReceiveSystem : EcsSystem { ... }

world.Update<NetworkGroup>();   // whenever packets arrive
world.Update();                     // fixed tick: default group
```

分组上可以加 [`WithAttribute`](/zh/docs/reference/withattribute)、[`WithoutAttribute`](/zh/docs/reference/withoutattribute) 和 [`WithAnyAttribute`](/zh/docs/reference/withanyattribute) 过滤条件：生成器把它们加到分组里所有系统的每个 [ForEach] 方法上（`[Without<Inactive>] public struct Gameplay : ISystemGroup;` 让整个分组都不处理不活跃的实体）；它实现的接口也可以带过滤条件：[`ISystemGroupWith`](/zh/docs/reference/isystemgroupwith)、[`ISystemGroupWithout`](/zh/docs/reference/isystemgroupwithout)。系统在 OnUpdate 里自己发起的查询不受影响。
