Marker of a system group: systems marked [`UpdateInGroupAttribute`](/zh/docs/reference/updateingroupattribute) run together when [`World.Update`](/zh/docs/reference/world#update-2) is called, independently of the default group run by [`World.Update`](/zh/docs/reference/world#update). Use groups for different cadences (a fixed-rate simulation tick vs. work that runs whenever input arrives).

```csharp
public struct NetworkGroup : ISystemGroup;

[EcsSystem, UpdateInGroup<NetworkGroup>]
ref struct Receive { ... }

world.Update<NetworkGroup>();   // whenever packets arrive
world.Update();                     // fixed tick: default group
```

A group may carry [`WithAttribute`](/zh/docs/reference/withattribute), [`WithoutAttribute`](/zh/docs/reference/withoutattribute) and `[WithAny<T1, T2>]` filters: the generator adds them to every [ForEach] method of its systems (`[Without<Inactive>] public struct Gameplay : ISystemGroup;` keeps inactive entities out of the whole group), and so may the interfaces it implements: [`ISystemGroupWith`](/zh/docs/reference/isystemgroupwith), [`ISystemGroupWithout`](/zh/docs/reference/isystemgroupwithout). Queries a system makes in its `OnUpdate` method are its own.
