和 [`IForEach`](/zh/docs/reference/iforeach) 一样，但还接收 [`Entity`](/zh/docs/reference/entity) 句柄。句柄直接用原型的实体行（id 和版本号挨着存）构造，不用逐个实体查找。带 [`Entity`](/zh/docs/reference/entity) 参数的 `[ForEach]` 方法编译成它。

组件数量从 1 到 9，每个数量一个类型，都由同一个模板生成；下面的成员每个类型都有，以 `IForEachEntity<T1>` 为例。

## 属性 [#properties]

### `Merges` [#merges]

```csharp
static virtual bool Merges { get; }
```

job 在字段里保存部分结果（[`Reduce`](/zh/docs/reference/reduce)；默认 false）：并行遍历保留每个块的 job 副本，按块的顺序把它们合并进调用方的 job（[`IForEachEntity.Merge`](/zh/docs/reference/iforeachentity#merge)）。

### `OptionalWrites` [#optionalwrites]

```csharp
static virtual ComponentSet OptionalWrites { get; }
```

job 在自身组件之外写入的被追踪的组件（通过 [`Maybe`](/zh/docs/reference/maybe)；默认没有）：并行遍历打开它们的变更 tick 区块时，与 [`IForEachEntity.WriteMask`](/zh/docs/reference/iforeachentity#writemask) 的组件一起打开，让切开同一区块的块共用它。生成的并行 job 标出它们通过 [`Maybe`](/zh/docs/reference/maybe) 的写入。

### `SelfStamped` [#selfstamped]

```csharp
static virtual int SelfStamped { get; }
```

[`IForEachEntity.WriteMask`](/zh/docs/reference/iforeachentity#writemask) 里由 job 自己打 tick、而且只在它写的行上打 tick 的组件（位的含义同 [`IForEachEntity.WriteMask`](/zh/docs/reference/iforeachentity#writemask)；默认没有）：循环不给这些组件的行打 tick。生成的 job 标出它们的 [`Mut`](/zh/docs/reference/mut) 参数。

### `WriteMask` [#writemask]

```csharp
static virtual int WriteMask { get; }
```

job 通过 ref 写入的组件：第 k 个组件对应第 k - 1 位（默认：全部）。job 改变了当前实体的原型时，ForEach 在 job 返回后，把这些组件从 ref 指向的那一行带到实体的新行。生成的 job 只标出它们的 `ref` 参数。
