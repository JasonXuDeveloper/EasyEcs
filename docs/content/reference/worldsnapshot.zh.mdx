World 的实体、组件和单例的一份拷贝：[`World.Capture`](/zh/docs/reference/world#capture) 拍下，[`World.Restore`](/zh/docs/reference/world#restore) 放回（系统和选项不在里面）。它只保存这些拷贝；可以恢复任意多次，但只能恢复到拍它的那个 World。[`World.Capture`](/zh/docs/reference/world#capture-2) 会覆盖它，并复用它的数组（数组够大之后不分配内存）。
