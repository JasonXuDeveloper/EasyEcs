在单个实体上运行的静态方法：生成器写一个入口，它是方法所在类型的静态成员，和方法同名，接收实体（带 `[Changed<T>]` / `[Removed<T>]` 时接着是 tick，然后是方法的其他值），返回方法有没有运行。方法能接收的，就是系统之外的 [`ForEachAttribute`](/zh/docs/reference/foreachattribute) 方法对单个实体能接收的：组件（`ref` / `in`、[`Mut`](/zh/docs/reference/mut)、[`Maybe`](/zh/docs/reference/maybe)）、单例、[`Lookup`](/zh/docs/reference/lookup)、[`Entity`](/zh/docs/reference/entity)、[`World`](/zh/docs/reference/world) 和任意其他类型的值，以及过滤特性（[`WithAttribute`](/zh/docs/reference/withattribute)、[`WithoutAttribute`](/zh/docs/reference/withoutattribute)、`[WithAny<T1, T2>]`、`[Changed<T>]`、`[Removed<T>]`）。它编译成 `entity.Run` 运行的 job（一个 [`IForEachEntity`](/zh/docs/reference/iforeachentity) 结构体，带它的 `WriteMask`；方法不做结构变更时实现 [`INoStructuralChanges`](/zh/docs/reference/inostructuralchanges)）：所有组件只查一次表，零分配。

```csharp
public static class Orders
{
    [EntityMethod, Without<Closed>]
    static void Buy(ref Stock stock, ref Sales sales, int quantity) { stock.Items -= quantity; sales.Count += quantity; }
}

bool sold = Orders.Buy(shop, 3);   // false: closed, no Stock or Sales, or not alive
```
