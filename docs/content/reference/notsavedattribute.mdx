A component or singleton no save holds: runtime state (a connection, a cache, a handle to a service) that a restart rebuilds. Every save leaves it out ([`World.Save`](/en/docs/reference/world#save), [`World.SaveWithout`](/en/docs/reference/world#savewithout), the saves of entities, even a set that names it), so it needs no Nino formatter, and a load keeps the world's own value of a singleton (as [`World.LoadKeeping`](/en/docs/reference/world#loadkeeping) does). Snapshots ([`World.Capture`](/en/docs/reference/world#capture)) and moves between worlds ([`World.MoveEntities`](/en/docs/reference/world#moveentities)) copy it as any other.
