The [`ForEachAttribute`](/en/docs/reference/foreachattribute) method consumes the rows it visits: when its pass ends, the entities it visited are destroyed, for event and command entities that are handled once. Exactly the pass's rows go, never an entity that matches later: a method that makes no structural change has every row it visited destroyed at once after the pass (one `DestroyAll` with the method's filter, a table whose rows all go emptied in one step); a method that may change structure has each entity destroyed right after its row. Destroying follows the rules of [`Entity.Destroy`](/en/docs/reference/entity#destroy): an entity holding cleanup components is retired, the destroy log records each id. A pass that throws destroys nothing it has not finished: a method without structural changes destroys none of its rows, which it visits again on the next run. Not with [`ForEachAttribute.Slices`](/en/docs/reference/foreachattribute#slices) (EECS085).

```csharp
[ForEach, Consume]
static void Count(in Damage hit, ref DamageDealt dealt) => dealt.Total += hit.Amount;   // each Damage event, once
```
