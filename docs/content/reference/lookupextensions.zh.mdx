通过 [`Lookup`](/zh/docs/reference/lookup) 按键查找带索引的组件（[`IIndexed`](/zh/docs/reference/iindexed)）。

## 扩展成员 [#extension-members]

### `Count` [#count]

```csharp
extension<T, TKey>(Lookup<T> lookup) public int Count(TKey key);
```

`T` 的键为 `key` 的实体数量。O(1)：一次哈希探测。

### `Find` [#find]

```csharp
extension<T, TKey>(Lookup<T> lookup) public ValueIndex<T, TKey>.Matches Find(TKey key);
```

`T` 的键为 `key` 的实体（`foreach`）。O(1)，然后每个实体 O(1)。遍历期间没有人写 `T`，所以遍历这个列表时它保持不变。

### `TryFind` [#tryfind]

```csharp
extension<T, TKey>(Lookup<T> lookup) public bool TryFind(TKey key, out Entity entity);
```

一个 `T` 的键为 `key` 的实体：唯一索引（[`IUniqueIndexed`](/zh/docs/reference/iuniqueindexed)）时就是那一个，否则是其中任意一个。O(1)：一次哈希探测。
