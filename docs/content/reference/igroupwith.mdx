A system group whose [ForEach] methods visit only entities with `T`, as [`WithAttribute`](/en/docs/reference/withattribute) on the group would. An interface can name its own type parameter where an attribute cannot, so a framework's generic group interface carries the filter for every group that implements it: `interface IActor<TSelf> : IGroupWith<In<TSelf>>`, then `struct Map : IActor<Map>` filters its systems to `In<Map>`.
