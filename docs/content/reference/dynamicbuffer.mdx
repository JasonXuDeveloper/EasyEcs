public struct DynamicBuffer<T> : IComponent, ITracked

A list of `T` per entity, held as a component: an inventory, a path, the hits of this tick. Writes go through a `ref` to the component (`ref` parameters of `[ForEach]` methods and jobs, [`Entity.Get`](/en/docs/reference/entity#get)), so they are tracked like any write of an [`ITracked`](/en/docs/reference/itracked) component and `[Changed<DynamicBuffer<T>>]` selects the entities whose list changed. Through `in` or [`Entity.Read`](/en/docs/reference/entity#read) the list is read-only: the mutating methods ([`DynamicBufferExtensions`](/en/docs/reference/dynamicbufferextensions)) take `ref this`, so a write through a read-only reference does not compile. Snapshots copy the elements ([`World.Capture`](/en/docs/reference/world#capture)); a moved row keeps its list. Adding within the capacity allocates nothing.

#### Remarks

A `new DynamicBuffer<T>()` holds no list: each entity's list is made by its first write (reserve room with [`DynamicBufferExtensions.EnsureCapacity`](/en/docs/reference/dynamicbufferextensions#ensurecapacity)), so one value can create many entities. The list lives in an object the component refers to, and a copy of the component would refer to the same list: the analyzer rejects copies (EECS012), reach the list through the entity.
