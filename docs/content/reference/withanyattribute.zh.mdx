[`ForEachAttribute`](/zh/docs/reference/foreachattribute) 方法要求实体至少拥有它的 `[WithAny<T>]` 特性列出的组件之一（不传入方法）：`[ForEach, WithAny<Burning>, WithAny<Poisoned>]`。加在系统分组上时，分组里所有系统的每个 [ForEach] 方法都要求拥有分组列出的组件之一。
