### `DestroyLogCapacity` [#destroylogcapacity]

```csharp
public int DestroyLogCapacity { get; init; }
```

销毁日志的容量（默认 0：关闭）：最近销毁的这么多个实体的 id（不再存活的：退休的实体在被释放时才记录），每个带着它被销毁时的变更 tick，[`World.DestroyedSince`](/zh/docs/reference/world#destroyedsince) 把它们报告给各自保留自己 tick 的读者（每个客户端一个同步标记）。预先分配（每条记录 16 字节）；之后一次销毁写一条记录，日志关闭时没有任何开销。容量按读者两次读取之间可能留下的最长间隔里的销毁数来定：更旧的读者会被告知要重新同步（[`World.DestroyLogOldestTick`](/zh/docs/reference/world#destroylogoldesttick)）。

### `MaxDegreeOfParallelism` [#maxdegreeofparallelism]

```csharp
public int MaxDegreeOfParallelism { get; init; }
```

一次并行执行最多用多少个线程（默认：处理器数）。管的是 [`WorldOptions.ParallelSystems`](/zh/docs/reference/worldoptions#parallelsystems) 并行执行的系统，以及并行 `[ForEach]` 方法、`ForEachParallel` 和 `ForEachEntityParallel` 的行分块（不管 [`WorldOptions.ParallelSystems`](/zh/docs/reference/worldoptions#parallelsystems) 开没开，它们都分块执行）。

### `MeasureSystems` [#measuresystems]

```csharp
public bool MeasureSystems { get; init; }
```

把每个系统每次运行的数据记进 [`SystemHandle.Stats`](/zh/docs/reference/systemhandle#stats)：耗时和分配的字节数（每次运行读两次时间戳、两次分配计数，并行 `[ForEach]` 的每个辅助块也一样），以及它的 `[ForEach]` 方法访问过的实体数（每次遍历开始时数一次）。默认 false。

### `ParallelSystems` [#parallelsystems]
