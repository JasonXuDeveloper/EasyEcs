A tile of a grid ([`ITile`](/en/docs/reference/itile)) declared by its shape: the generator adds `ITile<TKey>` to the partial component, its key the type of the member marked [[LookupKey]](/en/docs/reference/lookupkeyattribute) or [[UniqueKey]](/en/docs/reference/uniquekeyattribute), with the shape's static members ([`ITileShape`](/en/docs/reference/itileshape)) from the properties set here and `Beside` from the key: `[Tile(Width = 16, Depth = 16)] public partial record struct HeatPlate([LookupKey] PlatePos Pos) : IComponent;`. `Beside` steps an `int` key by one along x (west −1, east +1), and a key with integer members `X` and `Z` (and `Y`, the layers) along the axis of the face, as [`TileFaces`](/en/docs/reference/tilefaces) names them: north −z, south +z, west −x, east +x, below −y, above +y. A key of another shape, or a grid whose `Beside` wraps (a torus), writes `Beside` by hand; the generator then writes the rest. A type that declares `ITile<TKey>` itself gets the same inferred `Beside` when it writes none.
