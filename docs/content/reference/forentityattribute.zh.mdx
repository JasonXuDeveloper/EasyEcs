A static method that runs on one entity: the generator writes an entry point, a static member of the method's type named like the method, which takes the entity (then the tick with `[Changed<T>]` / `[Removed<T>]`, then the method's other values) and returns whether the method ran. The method takes what a [`ForEachAttribute`](/zh/docs/reference/foreachattribute) method outside a system takes for one entity: components (`ref` / `in`, [`Mut`](/zh/docs/reference/mut), [`Maybe`](/zh/docs/reference/maybe)), singletons, [`Lookup`](/zh/docs/reference/lookup), the [`Entity`](/zh/docs/reference/entity), the [`World`](/zh/docs/reference/world) and values of any other type, and filters ([`WithAttribute`](/zh/docs/reference/withattribute), [`WithoutAttribute`](/zh/docs/reference/withoutattribute), `[WithAny<T1, T2>]`, `[Changed<T>]`, `[Removed<T>]`). It compiles to the job `entity.Run` runs (an [`IForEachEntity`](/zh/docs/reference/iforeachentity) struct with its `WriteMask`, [`INoStructuralChanges`](/zh/docs/reference/inostructuralchanges) when the method makes no structural change): one table lookup for all its components, no allocation.

```csharp
public static class Orders
{
    [ForEntity, Without<Closed>]
    static void Buy(ref Stock stock, ref Sales sales, int quantity) { stock.Items -= quantity; sales.Count += quantity; }
}

bool sold = Orders.Buy(shop, 3);   // false: closed, no Stock or Sales, or not alive
```
