```csharp
public sealed class RemovedAttribute<T> : Attribute where T : struct, IComponent, ITracked
```

The [`ForEachAttribute`](/en/docs/reference/foreachattribute) method visits only entities that lost `T` since its system last ran ([`SystemHandle.LastRunTick`](/en/docs/reference/systemhandle#lastruntick)) and have not got it back: replication sends the removal, a cleanup releases what the component stood for. Removing a component keeps the entity's row, so the method can read the entity's other components; destroyed entities are not visited. `T` tracks changes ([`ITracked`](/en/docs/reference/itracked)) and is not a parameter (the entity no longer has it, EECS016).
