The faces of a tile ([`ITileShape`](/en/docs/reference/itileshape)): north is −z, south +z, west −x, east +x, below −y, above +y. One face names a neighbour ([`ITile.Beside`](/en/docs/reference/itile#beside), [`Tile.Beside`](/en/docs/reference/tile#beside)); a set of them is [`ITileShape.Faces`](/en/docs/reference/itileshape#faces), the faces that have neighbours.
