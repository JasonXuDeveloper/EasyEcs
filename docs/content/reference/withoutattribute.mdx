```csharp
public sealed class WithoutAttribute<T> : Attribute where T : struct, IComponent
```

The [`ForEachAttribute`](/en/docs/reference/foreachattribute) method skips entities having component `T`. On a system group (an [`ISystemGroup`](/en/docs/reference/isystemgroup) struct), every [ForEach] method of the group's systems does:

```csharp
[Without<Inactive>] public struct Gameplay : ISystemGroup;
```
