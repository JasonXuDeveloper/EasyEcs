A [`Prefab`](/en/docs/reference/prefab) declared as the components its entities start with: a partial struct with one field per component, each field's initializer its default value: `[Prefab] public partial struct Goblin { public Health Health = new(30); public Position Position; }`. The generator writes `Goblin.Prefab`, a static [`Prefab`](/en/docs/reference/prefab) built once from the defaults, and the parameterless constructor field initializers need. `world.Instantiate(Goblin.Prefab)` creates a goblin (values given to `Instantiate` replace the defaults, a span gets many), `new Prefab(Goblin.Prefab)` is a variant to change (a buffer, a member). The declaration names no kind a query could find: give it a tag component to filter on.
