船上装着炮塔，炮塔上装着炮管，队长带着队员。`ChildOf(parent)` 把实体挂到父实体下：`world.Children(parent)` 列出子实体，
销毁父实体时后代一并销毁。船沉了，炮塔跟着没了，一行清理代码都不用写。`ChildOf` 和其他
[带索引的 `EntityId` 链接](/zh/docs/guide/indexes-and-relations#entityid-keys)没有区别，只是默认打开了级联销毁。

## 什么时候用 [#when-to-use-it]

<Callout type="idea" title="适合">
  和另一个实体同生共死的实体：船上的炮塔、玩家身上的物品、小队成员、载具的部件。把玩家和他拥有的一切迁移到另一个
  World 或另一台服务器。
</Callout>

<Callout type="warn" title="不适合">
  不该连带杀死对方的链接（攻击目标、跟随者）：用自己的 `EntityId` 键，配 `Keep` 或 `Remove`。一个实体有多个“父亲”
  （同时属于多支队伍）：用[关系](/zh/docs/guide/indexes-and-relations#relations)。变换传播不是内置功能，
  [下面的示例](#transform-propagation)是你自己写的系统。
</Callout>

## 怎么用 [#how-to-use-it]

<Steps>
<Step>

### 挂上子实体 [#attach]

给子实体加一个 `ChildOf`，参数是父实体的 id（句柄可以直接转换）。

```csharp
public record struct Name(string Value) : IComponent;
```

```csharp
var ship = world.CreateEntity(new Name("ship"));
var turret = world.CreateEntity(new Name("turret"), new ChildOf(ship));
var gun = world.CreateEntity(new Name("gun"), new ChildOf(turret));
```

</Step>
<Step>

### 列出子实体 [#children]

`world.Children(parent)` 返回 `ChildOf` 指向这个父实体的实体：O(1)，之后每个子实体 O(1)。第一次调用会把所有 `ChildOf`
索引一遍。

```csharp
foreach (var child in world.Children(ship)) { /* 炮塔 */ }
```

</Step>
<Step>

### 换父实体、解除挂接 [#reparent]

`ChildOf` 就是一个普通的值：设一个新值就是换父实体，移除它，实体就成了根。

```csharp
gun.Set(new ChildOf(ship));                // 炮管改挂到船上
turret.Remove<ChildOf>();                  // 炮塔成了根
```

</Step>
<Step>

### 销毁父实体 [#cascade]

销毁父实体时，它的子实体、子实体的子实体都会在同一次调用里销毁。

```csharp
ship.Destroy();                            // 炮管跟着没了；已经解除挂接的炮塔还在
bool gunAlive = gun.IsAlive;               // false
```

</Step>
</Steps>

### 改变销毁的行为 [#cascade-policy]

`ChildOf` 的初始策略是 `TargetPolicy.Destroy`。和其他[目标策略](/zh/docs/guide/indexes-and-relations#target-policies)一样，
可以按 World 修改：`Remove` 让被销毁父实体的子实体变成根，`Keep` 让它们的 `ChildOf` 继续指向那个死去的 id。

```csharp
world.Index<ChildOf, EntityId>().WhenTargetDestroyed(TargetPolicy.Remove);   // 孤儿变成根
```

- 持有[清理组件](/zh/docs/guide/cleanup-and-disable#cleanup-components)的子实体不会被直接释放，而是“退休”：带着
  `Destroyed` 标签保留清理组件，它自己的子实体照样随它而去。
- 环（实体是自己的祖先）会正常结束：销毁其中任何一个，整个环都会被销毁。
- `ChildOf` 不能被禁用（`Disable<ChildOf>()` 会抛异常）：父实体销毁时必须找得到子实体。

### 变换传播 [#transform-propagation]

EasyEcs 没有内置变换组件。传播就是一个系统：从根（`Without<ChildOf>`）开始，用 `Children` 往下走，每个世界坐标都由父实体
刚算好的坐标得出。

```csharp
public record struct LocalPosition(float X, float Y) : IComponent;
public record struct WorldPosition(float X, float Y) : IComponent;
```

```csharp title="PropagateTransforms.cs"
public class PropagateTransforms : EcsSystem
{
    // 根：世界坐标就是本地坐标；然后每棵子树跟随它的父实体
    [ForEach, Without<ChildOf>]
    static void FromRoot(Entity root, in LocalPosition local, ref WorldPosition position)
    {
        position = new WorldPosition(local.X, local.Y);
        Follow(root, position);
    }

    static void Follow(Entity parent, WorldPosition at)
    {
        foreach (var child in parent.World.Children(parent)) // [!code highlight]
        {
            ref readonly var local = ref child.LocalPosition;
            var position = new WorldPosition(at.X + local.X, at.Y + local.Y);
            child.WorldPosition = position;
            Follow(child, position);
        }
    }
}
```

```csharp
world.AddSystem<PropagateTransforms>();
var hull = world.CreateEntity(new LocalPosition(10, 0), new WorldPosition());
var mount = world.CreateEntity(new LocalPosition(0, 2), new WorldPosition(), new ChildOf(hull));
var barrel = world.CreateEntity(new LocalPosition(1, 0), new WorldPosition(), new ChildOf(mount));
world.Update();                            // barrel：WorldPosition(11, 2)
```

方法接收了 `Entity`，所以这个系统单独运行（它要读写别的实体的组件）。子实体带着 `ChildOf`，和根不在同一张表里，写它们
不会挪动当前遍历所在的行。整个过程没有任何分配。

### 迁移层级 [#moving]

`MoveEntities` 和 `SaveEntities` 只处理你列出的实体，不会顺带它们的子实体。用 `Children` 收集整棵层级再一起迁移：父实体
没跟过去的子实体，到了那边会去掉 `ChildOf`（成为根）；而 `MoveEntities` 销毁原实体时会连同子实体一起销毁，没列出的子实体
就丢了。详见[迁移](/zh/docs/guide/migration-and-unload#move-entities)。

```csharp
var player = world.CreateEntity(new Name("bob"));
world.CreateEntity(new Name("sword"), new ChildOf(player));

var group = new List<EntityId> { player.Id };
foreach (var child in world.Children(player)) group.Add(child.Id);
using var other = new World();
world.MoveEntities(other, group.ToArray());   // bob 和他的剑，链接保持不变
```

## 完整例子 [#full-example]

一艘船，上面有炮塔，炮塔上有炮：世界坐标跟着父实体走；然后把炮挂到别的父实体上，把炮塔摘下来，最后销毁船和还挂在它上面的
东西。把这几个文件放进一个引用了 EasyEcs 的控制台项目（`dotnet add package EasyEcs`），用 `dotnet run` 运行。

<Accordions>
<Accordion title="Components.cs">

```csharp title="Components.cs" doccheck=example
using EasyEcs;

public record struct Name(string Value) : IComponent;

// 相对父实体的位置（根实体就是相对世界）。
public record struct LocalPosition(float X, float Y) : IComponent;

// 世界坐标，由 PropagateTransforms 计算。
public record struct WorldPosition(float X, float Y) : IComponent;
```

</Accordion>
<Accordion title="Systems.cs">

```csharp title="Systems.cs" doccheck=example
using EasyEcs;

// 从根往下计算每个世界坐标，
// 每个子实体都跟着父实体的新位置走。
public class PropagateTransforms : EcsSystem
{
    // 根实体没有 ChildOf：世界坐标就是本地坐标。
    [ForEach, Without<ChildOf>]
    static void FromRoot(Entity root, in LocalPosition local, ref WorldPosition position)
    {
        position = new WorldPosition(local.X, local.Y);
        Follow(root, position);
    }

    static void Follow(Entity parent, WorldPosition parentPosition)
    {
        foreach (var child in parent.World.Children(parent))
        {
            LocalPosition local = child.LocalPosition;
            float x = parentPosition.X + local.X;
            float y = parentPosition.Y + local.Y;
            var position = new WorldPosition(x, y);
            child.WorldPosition = position;
            Follow(child, position);
        }
    }
}
```

</Accordion>
<Accordion title="Program.cs">

```csharp title="Program.cs" doccheck=example
using EasyEcs;

using var world = new World();
world.AddSystem<PropagateTransforms>();

// 子实体用 ChildOf 指向父实体。
Entity ship = world.CreateEntity(new Name("ship"), new LocalPosition(10, 0), new WorldPosition());
Entity turret = world.CreateEntity(
    new Name("turret"), new LocalPosition(0, 2), new WorldPosition(), new ChildOf(ship));
Entity gun = world.CreateEntity(
    new Name("gun"), new LocalPosition(1, 0), new WorldPosition(), new ChildOf(turret));

world.Update();
Console.WriteLine($"gun at {gun.WorldPosition}");

foreach (var child in world.Children(ship))
{
    Console.WriteLine($"ship > {child.Name.Value}");
}

// 换父实体：设一个新的 ChildOf。摘下来：移除它，实体就成了根。
gun.Set(new ChildOf(ship));
turret.Remove<ChildOf>();

// ChildOf 是带索引的组件：用它的索引数一个父实体有几个子实体。
var children = world.Index<ChildOf, EntityId>();
Console.WriteLine($"ship: {children.Count(ship)} child, turret: {children.Count(turret)} children");

// 销毁父实体会连带销毁子实体：炮跟着船一起没了。
ship.Destroy();
Console.WriteLine($"turret alive: {turret.IsAlive}, gun alive: {gun.IsAlive}");
Console.WriteLine($"{world.EntityCount} entity left");
```

</Accordion>
</Accordions>

输出：

```text
gun at WorldPosition { X = 11, Y = 2 }
ship > turret
ship: 1 child, turret: 0 children
turret alive: True, gun alive: False
1 entity left
```

炮的世界坐标是它和各级父实体偏移的和：10 + 0 + 1 和 0 + 2 + 0。炮塔被摘下来以后，船销毁了它还在；炮被挂到了船上，就跟着船
一起销毁了。

## 怎么用得快 [#how-to-use-it-fast]

- **销毁根。** 一次 `Destroy` 在结构闸门内顺着整棵子树走完，不递归（用一个目标栈）。先一个个销毁子实体再销毁父实体，
  做的事一样，只是调用更多。
- **做传播时层级尽量浅。** 上面的遍历每个实体查一次 `Children`；扁平的层级（船和它的炮塔）走得最快。
- **`DestroyEntities<T>()`** 一次销毁整张表，级联照样生效。

## 开销 [#what-it-costs]

- **出现第一个 `ChildOf` 之前零开销。** 没有任何表包含 `ChildOf` 的 World，销毁实体时根本不去找子实体。
- **内存：** `ChildOf` 列（每行 8 字节），外加 `EntityId` 键的索引（每个子实体一个节点）。
- **`Children`：** O(1)，之后每个子实体 O(1)；第一次调用会索引所有 `ChildOf`。
- **一次级联：** 每个被销毁的实体 O(1)，再加上它的每个子实体 O(1)。

## 常见陷阱 [#pitfalls]

| 错误 | 后果 | 谁能发现 |
| --- | --- | --- |
| 通过 `ref` 写 `ChildOf` | 索引还记着旧的父实体 | [EECS015](/zh/docs/guide/analyzer#eecs015) |
| 自己用 `Entity` 字段存父指针 | 托管列，存不了盘，也没有级联 | [EECS017](/zh/docs/guide/analyzer#eecs017) |
| 只迁移父实体，不带子实体 | 子实体留在原地，随原实体一起被销毁 | 用 `Children` 收集整组 |
| `Disable<ChildOf>()` | 抛 `InvalidOperationException` | 运行时 |
| 没写系统却指望有世界坐标 | 没有内置变换 | 写一个[传播系统](#transform-propagation) |
