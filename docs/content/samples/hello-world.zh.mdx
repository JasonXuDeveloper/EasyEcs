最小的完整 EasyEcs 程序，也是入门的起点：两个会动的实体，一个把其中之一标成玩家的标签，一个计 tick 的时钟，三个各管一件事的系统。
本页的代码块全部引自 [`samples/HelloWorld`](https://github.com/JasonXuDeveloper/EasyEcs/tree/master/samples/HelloWorld)，
CI 会构建并运行它，把输出和下面列出的比对。

## 运行 [#run-it]

```bash
dotnet run --project samples/HelloWorld
```

## 数据 [#data]

组件是普通数据：只有字段，没有逻辑。两个实体都有 `Position` 和 `Velocity`；`Player` 没有字段，是系统用来过滤的
[标签](/zh/docs/guide/entities-and-components#tags)；`Clock` 是[单例](/zh/docs/guide/singletons)，每个 World 只有一份。

<include lang="csharp" meta='title="Components.cs"'>../../../samples/HelloWorld/Components.cs</include>

## 系统 [#systems]

[系统](/zh/docs/guide/systems)各管一件事，自己不存状态。`[ForEach]` 方法对每个具备其组件参数的实体跑一次：`ref` 表示要写，
`in` 表示只读。`MoveSystem` 移动所有有位置和速度的实体，`ReportSystem` 只打印玩家（`[With<Player>]` 是一个
[过滤条件](/zh/docs/guide/queries#filters)），`ClockSystem` 在 `OnUpdate` 里每次更新推进一次时钟，而不是每个实体一次。

<include lang="csharp" meta='title="Systems.cs"'>../../../samples/HelloWorld/Systems.cs</include>

## 程序 [#program]

创建 World，加入单例和系统，创建两个实体，跑三次更新。`world.Update()` 按添加顺序把每个系统跑一遍。

<include lang="csharp" meta='title="Program.cs"'>../../../samples/HelloWorld/Program.cs</include>

## 输出 [#output]

```text
tick 0: player at (1, 2)
tick 1: player at (2, 4)
tick 2: player at (3, 6)
2 entities after 3 ticks
```

`ReportSystem` 在 `ClockSystem` 之前运行，所以第一次更新打印的是 tick 0。第二个实体也在动，但它没有 `Player` 标签，所以从不打印。
