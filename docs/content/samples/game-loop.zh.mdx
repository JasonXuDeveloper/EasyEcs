一个小型游戏服务器：客户端在另一个线程，模拟按固定 30 Hz 跑 tick，只同步变化的数据。十六个假客户端在三秒的游戏时间里加入、移动、开火、离开。
本页的代码块全部引自 [`samples/GameLoop`](https://github.com/JasonXuDeveloper/EasyEcs/tree/master/samples/GameLoop)，
CI 会构建并运行它。建议先读 [HelloWorld](/zh/docs/samples/hello-world)。

## 你会学到 [#what-you-learn]

- **输入就是数据**：网络线程把消息投进邮箱，`ReceiveInputSystem` 把每条消息变成一个请求实体（`JoinRequest`、`MoveRequest` 等）。
  每种请求由一个系统处理，并在同一 tick 内销毁（[来自其他线程的输入](/zh/docs/guide/threading#input-from-other-threads)）。
- **[系统分组](/zh/docs/guide/systems#system-groups)**（`ISystemGroup`、`[UpdateInGroup<T>]`）让系统各有节奏：输入每次唤醒都跑，
  模拟跟着固定 tick，同步每三个 tick 一次。
- **[值索引](/zh/docs/guide/indexes-and-relations#value-indexes)**（`Client` 上的 `IIndexed<int>`）按客户端 id 找玩家：
  `world.ClientIndex.TryFind(...)`。
- **单例里的[预制体](/zh/docs/guide/prefabs)**：系统用每个实例各自的值实例化 `prefabs.Player` 和 `prefabs.Bullet`，每个只拷贝一行。
- **[变更追踪](/zh/docs/guide/change-tracking)**（`Position` 上的 `ITracked`、`[Changed<Position>]`）：同步只访问上次运行以来移动过的实体。
- **运维**：`--ticks N`、每秒一行状态、Ctrl+C 干净退出、[`WorldOptions.MeasureSystems`](/zh/docs/guide/diagnostics#timing)
  给出每个系统的运行次数和耗时。

## 运行 [#run-it]

```bash
dotnet run --project samples/GameLoop                   # 3 秒（90 个 tick）
dotnet run --project samples/GameLoop -- --ticks 30     # 1 秒
```

## 输出 [#output]

用 `-c Release -- --ticks 30` 运行。假客户端用固定种子，除时序带来的差异外，每次的计数都相同；耗时随机器而变。
所有检查通过时进程返回 0，否则返回 1。

```text
t=1s players=16 bullets=59 entities=75
30 ticks in 1.0 s
  220 messages (0 refused)
  34 joins, 18 leaves
  59 bullets fired
  455 position updates replicated (5.3 KB)
  LeaveSystem             30 runs,      4.7 us last run
  JoinSystem              30 runs,      2.2 us last run
  MoveSystem              30 runs,      6.9 us last run
  FireSystem              30 runs,     71.0 us last run
  MovementSystem          30 runs,      4.7 us last run
  LifetimeSystem          30 runs,      4.7 us last run
  ClockSystem             30 runs,      0.8 us last run
  ReceiveInputSystem     252 runs,      0.4 us last run
  ReplicationSystem       10 runs,     15.1 us last run
  ok   players have the prefab's components and their client id
  ok   bullets have the prefab's components and their lifetime
  ok   no client has two players
  ok   the mailbox refused no message
stopped
```

`ReceiveInputSystem` 跑的次数远多于 tick：等下一个 tick 时，循环每次醒来都会清空邮箱；`ReplicationSystem` 则每三个 tick 跑一次。
