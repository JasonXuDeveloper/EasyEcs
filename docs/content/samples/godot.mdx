EasyEcs inside a Godot 4 .NET project: the scene's root node owns a world, steps it once per physics tick and draws
the entities with one multimesh. A thousand dots move and bounce off the edges of the arena. Every code block on this
page is included from [`samples/Godot`](https://github.com/JasonXuDeveloper/EasyEcs/tree/master/samples/Godot),
which CI builds and runs headless with Godot 4.7.2, comparing its output with the one shown below. Read the
[HelloWorld](/en/docs/samples/hello-world) sample first.

## What you learn [#what-you-learn]

- **The project targets net10.0**: Godot loads a C# project's assembly into the .NET runtime the project targets.
  A project made by an older editor says `net8.0`; change it to `net10.0` and install the .NET 10 SDK
  ([getting started](/en/docs/getting-started#create-a-project), [Unity and Godot](/en/docs/faq#unity-godot)).
- **The node is the host, the systems are the game**: `Main` creates the world in `_Ready`, calls
  `world.Update()` in `_PhysicsProcess` (Godot's fixed tick) and disposes it in `_ExitTree`
  ([hosting a world](/en/docs/guide/hosting#owner)).
- **Godot types are component fields**: `Position` and `Velocity` hold a `Vector2`; the arena and the tick length
  are [singletons](/en/docs/guide/singletons).
- **Draw from the data in one call**: after the update the node copies every position into one float buffer and
  hands it to `RenderingServer.MultimeshSetBuffer`: one draw for every entity, no node per entity.

## Run it [#run-it]

Open the folder in the Godot 4 editor (the .NET build) and press Play, or run it without a window:

```bash
dotnet build samples/Godot
godot --headless --path samples/Godot -- --ticks 120
```

## The node [#node]

`Main` moves data between Godot and the world: it creates the entities, steps the world once per physics tick,
writes the positions into the multimesh, and frees what it made when it leaves the tree. The `--ticks` option and
the report CI checks are in
[`Support.cs`](https://github.com/JasonXuDeveloper/EasyEcs/blob/master/samples/Godot/Support.cs): plumbing, not the
lesson.

## Output [#output]

```text
120 ticks, 1000 entities, 1000 inside the arena
updates after the first allocated 0 B
```

The first update builds the queries' caches; from then on the world allocates nothing per tick, inside Godot as in a
server. CI runs this sample on Linux; Godot's .NET exports to other platforms (Android, iOS) use the runtime Godot
ships for them and are not tested here.
