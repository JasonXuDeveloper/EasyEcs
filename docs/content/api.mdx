Every public type and call of EasyEcs, grouped by what you do with it, with the cost of each. Everything is in
`namespace EasyEcs`. T1..T9 overloads come from one template each
([Architecture](/en/docs/architecture#source-generators-and-analyzer-easyecsgenerator)). For signatures, parameters
and the XML documentation of each member, see the generated [API reference](/en/docs/reference); its pages quote
the complexities below.

Notation:

- *n*: components in the call (1 to 9).
- *c*: components of the entity.
- *M*: tables (archetypes) matching a query.
- *S*: rows of those tables: living entities, plus tombstones while a pass that makes structural changes runs.
- *k*: entities of one key of an index; *L*: links of one entity.
- "Amortized": tables and the entity array occasionally double.

Unless a row says otherwise, a call allocates nothing once the world is warmed up, and only the world's owner thread
may make it ([Threading](/en/docs/guide/threading)).

## Types [#types]

| Type | Kind | Purpose |
| --- | --- | --- |
| `World` | sealed class, `IDisposable` | Owns entities, components, singletons, indexes and systems. |
| `WorldOptions` | sealed class | `ParallelSystems`, `MaxDegreeOfParallelism`, `InitialEntityCapacity`, `MeasureSystems`, `SystemErrors`, `DestroyLogCapacity` (init-only). |
| `Entity` | readonly struct | Handle: `Id`, `World`, `IsAlive`. A destroyed or default handle answers questions (`IsAlive`, `Has`, `TryGet`, `TryGetRef`) with false, throws on accesses and changes, and ignores `Destroy`. Converts to its `EntityId`. |
| `EntityId` | readonly struct, unmanaged | `Index` and `Version`, 8 bytes: what a component stores to refer to an entity. `EntityId.Null` names none. |
| `IComponent`, `ISingletonComponent` | marker interfaces | Component and singleton structs. An empty component is a tag. |
| `ITracked` | marker interface | Rows record the change tick of their last write or removal ([change tracking](/en/docs/guide/change-tracking)). |
| `IIndexed<TKey>` | interface | A component the world indexes by its `Key`; written with `Set` (EECS015). An `EntityId` key makes it a link to an entity. |
| `IUniqueIndexed<TKey>`, `UniqueIndexExtensions` | interface, extensions | An indexed component whose key names one entity: a write giving a second entity a taken key throws; `index.Get(key)`, `TryGet` ([indexes and relations](/en/docs/guide/indexes-and-relations)). |
| `IRelation` | interface | An element of a `DynamicBuffer<T>` that links its entity to `Target` ([indexes and relations](/en/docs/guide/indexes-and-relations)). |
| `ChildOf` | record struct | `ChildOf(EntityId Parent)`: the hierarchy; destroying a parent destroys its children ([hierarchy](/en/docs/guide/hierarchy)). |
| `IGroup` | interface | A component whose `Group` value splits tables (`world.GroupBy<T>()`, [groups](/en/docs/guide/groups)). |
| `ICleanupComponent`, `Retired` | marker interface, tag | `Destroy` on an entity that holds a cleanup component retires it: it stays alive with the cleanup components, tagged `Retired`, until the last one is removed ([cleanup and disable](/en/docs/guide/cleanup-and-disable)). |
| `Disabled<T>` | tag | Present while `T` is disabled: the value kept, the component hidden. |
| `Prefab` | sealed class | A recipe of component values that belongs to no world ([prefabs](/en/docs/guide/prefabs)). |
| `DynamicBuffer<T>` | struct, `IComponent, ITracked` | A list per entity; writes through `DynamicBufferExtensions` on a `ref` ([dynamic buffers](/en/docs/guide/dynamic-buffers)). |
| `ValueIndex<T, TKey>` | sealed class | `world.Index<T, TKey>()`: `Find`, `TryFind`, `Count`; ordered walks for a comparable key (`OrderedIndexExtensions`). |
| `RelationIndex<T>` | sealed class | `world.Relations<T>()`: the entities linking to a target. |
| `TargetPolicy`, `TargetPolicyExtensions` | enum, extensions | What destroying a target does to the links to it: `Keep`, `Remove`, `Destroy`. |
| `EcsSystem` | abstract class | `World`, `UpdateInterval`, `UpdatePhase`, `Enabled`, `Error`, `Stats`, `LastRunTick`, `RunCount`; `OnCreate` / `OnUpdate` / `OnDestroy` ([systems](/en/docs/guide/systems)). |
| `ForEachAttribute` and its filters | attributes | `[ForEach]` (`Parallel = true`, `Slices = N`), `[With<T>]`, `[Without<T>]`, `[WithAny<T>]`, `[Changed<T>]`, `[Removed<T>]`, `[ChangedAny<T1..Tn>]`, `[RemovedAny<T1..Tn>]`. |
| `Maybe<T>` | ref struct | An optional component parameter of a `[ForEach]` method: `HasValue`, `Value`. |
| `Mut<T>` | ref struct | A component parameter of a `[ForEach]` method that counts as written only on the rows the method writes: `Value`, `Write()`, `SetIfChanged(value)` ([change tracking](/en/docs/guide/change-tracking)). |
| `ISystemGroup`, `ISystemGroupWith<T>`, `ISystemGroupWithout<T>`, `[UpdateInGroup<T>]`, `[UpdateBefore<T>]`, `[UpdateAfter<T>]` | interfaces, attributes | System groups (with filters through interfaces) and ordering. |
| `SystemErrorPolicy` | enum | `Throw` (default) or `Disable`: what an exception in a system does. |
| `SystemStats`, `SystemList` | readonly structs | A system's run count, times, allocated bytes and visited entities; `world.Systems`, allocation-free. |
| `ScheduleInfo`, `GroupInfo`, `StageInfo`, `SystemInfo`, `StageWait`, `SystemPair` | sealed records | What `world.DescribeSchedule()` returns: stages, reads and writes, waits, registration-only pairs; `ToString()`, `ToMermaid()`. |
| `SystemAccess` | struct | What a system reads and writes; filled only by generated code. |
| `QueryFilter` | readonly struct | `With`, `Without`, `WithAny`, `Changed`, `Removed`, `ChangedAny`, `RemovedAny`, `InGroup`, `Since`, `Slice`; holds no object reference. |
| `QueryEnumerator<T1..Tn>`, `QueryItem<T1..Tn>` | ref structs | The result of `Query`: `item.Entity` and refs into the row (`item.Position`). |
| `IForEach<…>`, `IForEachEntity<…>`, `IForEachBatch<…>`, `INoStructuralChanges` | interfaces | Struct jobs for ad-hoc passes; `EntitySpan` holds a batch run's entities. |
| `SingletonRef<T>` | readonly struct | A stable singleton handle; `.Value` is `ref T`. |
| `WorldSnapshot` | sealed class | A copy of a world in memory (`world.Capture()`). |
| `ComponentSet` | readonly struct | Component and singleton types, built once: what `SaveEntitiesWith` writes, what `SaveWithout` leaves out, which singletons `LoadKeeping` keeps. |
| `TableInfo`, `ColumnInfo`, `ComponentValue` | record structs | What `world.DescribeTables()` and `entity.Describe()` return. |

| `world.DestroyAll<T1..Tn>(filter)` | O(M + S) | destroys every match in one gate pass and returns how many; safe during a pass |
| `world.DestroyEntities(ids)` | O(ids × c) | destroys a list of ids in one gate pass and one cascade and returns how many; stale ids and repeats are skipped; safe during a pass |
| `entity.IsAlive` / `world.IsAlive(id)` | O(1) | |
| `world.TryGetEntity(id, out e)` / `GetEntity(id)` | O(1) | false (or a throw) when that incarnation is not alive |
| `world.EntityCount` | O(1) | |
| `world.Entities` | O(capacity) | living entities in id order, for diagnostics |
| `world.EnsureEntityCapacity(capacity)` | O(capacity) | pre-size the entity array; a no-op when large enough |

## Components [#components]

| API | Complexity | Notes |
| --- | --- | --- |
| `entity.Get<T>()` | O(1) | `ref T`: a version check, a column lookup, one presence-bit test, one load; throws if missing or not alive; a write of a tracked component |
| `entity.Read<T>()` | O(1) | `ref readonly T`; never a write |
| `entity.TryGetRef<T>(out bool found)` | O(1) | `ref T`, a null ref when missing; a write of a tracked component when found |
| `entity.Has<T>()` / `TryGet<T>(out T)` | O(1) | false when missing or not alive; `TryGet` returns a copy (not a write) |
| `entity.Has<T1..Tn>()` | O(n) | all of them, one record lookup |
| `entity.Set(in T1 … in Tn)` | O(n), or O(c) amortized when it moves | adds or overwrites, at most one row copy, returns the entity; a component the table has a column for only sets its bit; re-indexes a changed key (O(1)); a unique key another entity holds throws before anything changes |
| `entity.SetIfChanged(in T value)` | O(1) plus a comparison (O(size of `T`)); as `Set` when the value differs | false, and nothing written, stamped or re-indexed, when the entity already has this value; adds `T` when missing; equality is `IEquatable<T>`, else the bytes of an unmanaged `T` |
| `entity.GetOrAdd<T>()` | O(1); when missing, O(1) if the table has a column for `T`, else O(c) amortized | `ref T`; adds a default value only when missing; a write of a tracked component; an indexed `T` it adds is indexed by its default key (a unique one claims it) |
| `entity.Remove<T1..Tn>()` | O(n) | clears presence bits, the row stays; missing components are ignored; a tracked component's removal is stamped (`[Removed<T>]`); returns the entity |
| `entity.Disable<T>()` / `Enable<T>()` | O(1); the first disable in a table moves the row once | keeps the value while queries, `Has` and `Get` see it as gone; a disable counts as a removal, an enable as a write; returns false when there was nothing to do |
| `entity.IsDisabled<T>()` | O(1) | |
| generated: `entity.X`, `HasX`, `TryGetX`, `GetOrAddX()`, `SetX(…)`, `SetXIfChanged(…)`, `RemoveX()`, `WriteX()`, `DisableX()`, `EnableX()`, `IsXDisabled`; tags `IsX`, `SetX()`; `world.XIndex` | as the generic call | C# 14 extension members per component ([generated members](/en/docs/guide/entities-and-components)); `entity.X` is `Get`, or `Read` for a tracked or indexed component, whose writes use `WriteX()` or `SetX(…)`; `SetXIfChanged(…)` for a tracked, indexed or grouped component that can be compared; EasyEcs's own `ChildOf` has them too (no `DisableChildOf` / `EnableChildOf`: it cannot be disabled), and `Retired` has `entity.IsRetired` |

## Prefabs and cloning [#prefabs-and-cloning]

A copy gets its own list for each `DynamicBuffer<T>`, is indexed at once, and counts as a write of every tracked
component it has; components the source lacks stay absent and are not removals.

| API | Complexity | Notes |
| --- | --- | --- |
| `new Prefab()` | O(1) | an empty recipe; allocates its private store once |
| `new Prefab(basePrefab)` | O(c) | a variant: a copy of every value (and member), changed on its own afterwards |
| `prefab.Set(in T1 … in Tn)` | O(n), or O(c) amortized when it gains a component | adds or replaces values; returns the prefab |
| `prefab.Remove<T1..Tn>()` | O(n) | missing ones are ignored; returns the prefab |
| `prefab.Has<T>()` / `Read<T>()` | O(1) | `Read` throws if the prefab has no `T` |
| `prefab.SetBuffer<T>(params ReadOnlySpan<T>)` | O(n) | a `DynamicBuffer<T>` of these elements; every instance gets a list of its own |
| `prefab.AddMember()` | O(1) | a member of the prefab's group: instantiating one creates all; `EntityId` fields naming members are rewritten per instance |
| generated: `prefab.X`, `HasX`, `SetX(…)`, `RemoveX()`; tags `IsX`, `SetX()`; buffers `SetLoot(items…)` | as the generic call | writers return the prefab; the property is read-only; not structural changes of any world |
| `world.Instantiate(prefab)` | O(c) | one row copy; the target table is found once per prefab table and cached; safe during a pass (which does not visit the new entity); O(members × c) for a group |
| `world.Instantiate(prefab, Span<Entity> entities)` | O(count × c) | one gate pass and at most one table growth for the wave |
| `world.Instantiate(prefab, in T1 … in Tn)` | O(c + n) amortized | the prefab's values plus the given ones (replacing the prefab's, or added; a disabled one given is enabled), in one row copy into the final table, no intermediate table; a given `ChildOf` links the hierarchy, a unique key is checked first; O(members × c) plus one move for a group, whose entity of the prefab passed gets the components |
| `world.Instantiate(prefab, Span<Entity> entities, in T1 … in Tn)` | O(count × (c + n)) | the same values for every instance; one gate pass, at most one table growth, each given column filled at once |
| `world.Reserve(prefab, count)` | O(c), plus one growth | pre-sizes the tables the next `count` instances go to, so a spawn wave never grows them during a tick |
| `entity.Clone()` | O(c) | a new entity of the same world and table with a copy of every component; throws if not alive or retired (kept for its cleanup components) |

## Dynamic buffers [#dynamic-buffers]

`new DynamicBuffer<T>()` holds no list until its first write. Reads work on any reference (`in`, `Read<T>()`); writes
need a `ref` and are tracked writes.

| API | Complexity | Notes |
| --- | --- | --- |
| `bag.Count`, `bag.Capacity`, `bag[i]`, `AsReadOnlySpan()`, `GetEnumerator()` | O(1) | read-only; out-of-range indexes throw |
| `bag.Add(item)` / `AddRange(items)` | O(1) amortized / O(items) | `items`: a span, several values (`params`) or `CollectionsMarshal.AsSpan(list)`; allocates only when the buffer grows |
| `bag.Insert(i, item)` / `RemoveAt(i)` | O(count) | keep the order |
| `bag.RemoveAtSwapBack(i)` | O(1) | the last element moves into `i` |
| `bag.Clear()` | O(1), O(count) for elements with references | keeps the capacity |
| `bag.EnsureCapacity(n)` / `AsSpan()` | O(count) when it grows / O(1) | `AsSpan()` is writable |
| `bag.TrimExcess()` | O(count) | reallocates to the count; an empty list holds no array |

A snapshot, a save or a clone of a buffer column copies the elements: O(elements), a new list per entity.

## Queries [#queries]

| API | Complexity | Notes |
| --- | --- | --- |
| `[ForEach]` method / `world.ForEach<T1..Tn, TJob>(ref job, filter)` | O(M + S) | fastest: a struct job, no delegate |
| `world.ForEachEntity<T1..Tn, TJob>(ref job, filter)` | O(M + S) | the job also receives the `Entity` |
| `entity.Run<T1..Tn, TJob>(ref job)` / `Run(ref job, filter)` | O(n), plus O(1) per filter component | one entity; false when stale, missing a component or rejected by the filter; refs survive the job's structural changes |
| `world.ForEachBatch<T1..Tn, TJob>(ref job, filter)` | O(M + S / 64 + runs) | spans of consecutive rows; no structural changes |
| `world.ForEachParallel<T1..Tn, TJob>(ref job, filter)` / `ForEachEntityParallel` | O(M + S), divided over up to `MaxDegreeOfParallelism` threads | `INoStructuralChanges` jobs; chunks of 1,024 to `World.ParallelChunkRows` rows (multiples of 4,096 when the job writes a tracked component), one job copy per chunk; helpers are woken only when they pay |
| `foreach (var item in world.Query<T1..Tn>(filter))` | O(M + S) | refs into the row: every visited row of a tracked component counts as written; no `await` in the loop |
| `foreach (var item in world.Read<T1..Tn>(filter))` | O(M + S) | `ref readonly` into the row: nothing is stamped; otherwise as `Query` |
| `world.Count<T1..Tn>(filter)` | O(M), + S / 64 for tables whose rows must be tested | sums table counts, or counts presence bits (and ticks), 8 words per step with AVX-512 |
| `world.Any<T1..Tn>(filter)` | O(M + S / 64) worst | stops at the first match |
| `QueryFilter.Create().With<T>().Without<U>().WithAny<V>()` | O(1) | build once, keep in a `static readonly` field; `WithAny` calls form one "at least one of" set |
| `filter.Changed<T>(since)` / `[Changed<T>]` | O(1); a pass skips tables, 4,096-row blocks and 64-row words written before `since` | rows whose tracked `T` was written at or after `since` ([change tracking](/en/docs/guide/change-tracking)); one tick per filter |
| `filter.Removed<T>(since)` / `[Removed<T>]` | as `Changed` | entities that lost a tracked `T` at or after `since` and still lack it; destroyed entities are not reported (the destroy log reports them) |
| `filter.ChangedAny<T1..Tn>(since)` / `[ChangedAny<T1..Tn>]` | O(n) to build; a pass skips tables none of whose columns of the set was written since `since`, and blocks and words no column wrote | rows where at least one of 2 to 9 tracked components was written at or after `since`; all `ChangedAny` calls of a filter form one set, combined with the other filters by AND; one tick per filter |
| `filter.RemovedAny<T1..Tn>(since)` / `[RemovedAny<T1..Tn>]` | as `ChangedAny` | entities that lost at least one of them at or after `since` and still lack it |
| `filter.Slice(index, of)` / `[ForEach(Slices = N)]` | O(1); a pass visits about S / N rows, cut at 64-row words | the `ForEach` calls only (`Query`, `Read`, `Count`, `Any`, `DestroyAll`, `entity.Run(ref job, filter)` and the bulk calls throw `ArgumentException`); a sliced method visits slice `RunCount % N`; not with `[Changed<T>]` / `[Removed<T>]` (EECS035) |
| `filter.InGroup<T>(group)` | O(1); a pass walks only that group's tables | [groups](/en/docs/guide/groups) |
| `filter.Since(since)` | O(1) | the filter with its `Changed`, `Removed`, `ChangedAny` and `RemovedAny` ticks moved, without rebuilding it: one filter, run with each client's tick |

The first use of a query shape builds its cache entry, O(all tables), under the shared gate. Later lookups are a memo
hit or one hash probe. Creating a new table (the first entity with a new component set) costs O(tables + cached
query shapes), as it joins every cached query it matches. Both are cold paths.

`Mut<T>`, the `[ForEach]` parameter of a component written on some rows only:

| API | Complexity | Notes |
| --- | --- | --- |
| `mut.Value` | O(1) | `ref readonly T`; stamps nothing |
| `mut.Write()` | O(1): one stamp (plus one entity lookup in a method that changes structure or runs in parallel) | `ref T`, the row stamped as written (a tracked `T`); call it once per write |
| `mut.SetIfChanged(in T value)` | O(size of `T`), plus a `Write()` when it differs | true when it stored the value; equality is `IEquatable<T>`, else the bytes of an unmanaged `T`; a managed `T` without `IEquatable<T>` throws `NotSupportedException` |

## Indexes [#indexes]

| API | Complexity | Notes |
| --- | --- | --- |
| `world.Index<T, TKey>()` | O(1); the first call creates it | one per world and indexed component; a second key type throws |
| `index.Count(key)` / `TryFind(key, out Entity)` | O(1) | a hash probe (an array access for a key that is an entity); the first lookup indexes every row once |
| `index.KeyCount` | O(1) | distinct keys some entity has (how many guilds have a member), kept as entities join and leave keys |
| `index.Find(key)` | O(1), then O(1) per entity | a `ref struct` for `foreach`; destroying entities during the loop is allowed, changing `T` is not |
| `index.Find(key).Count` / `world.Children(parent).Count` | O(1) | how many entities had the key when found (size a buffer without walking twice); entities destroyed during the loop are skipped by it but still counted |
| `index.Ascending()` / `Descending()` | O(keys log keys) for the first walk, then O(1) per entity | ordered walks for a comparable key (leaderboards, timers); after the first walk the index keeps its keys sorted: O(log keys) plus a block move per key that appears or disappears |
| `index.Range(min, max)` / `RangeDescending(min, max)` | O(keys log keys) for the first walk, then O(log keys) to find `min` and O(1) per entity | inclusive bounds |
| `index.WhenTargetDestroyed(policy)` | O(1); then O(1) per destroyed entity | an `EntityId` key: `Keep` (default), `Remove` or `Destroy` the components pointing at a destroyed entity |
| `index.Get(key)` / `TryGet(key, out Entity)` | O(1): a hash probe | a unique component (`IUniqueIndexed<TKey>`): the one entity of the key; `Get` throws `InvalidOperationException` when none has it |

A unique component's index exists from the first table holding it, so every write is checked before it changes
anything: `Set` and `CreateEntity` add one hash probe per changed key; `SetAll` and `EnableAll` an extra pass over the
matching rows; `Clone`, `Instantiate`, `LoadEntities`, `LoadEntitiesInto` and `MoveEntities` O(rows × unique
columns); `Load` O(rows). A taken key throws `InvalidOperationException` (a save holding a key twice:
`InvalidDataException`) and leaves the world as it was.

## Hierarchy and relations [#relations]

| API | Complexity | Notes |
| --- | --- | --- |
| `world.Children(parent)` | O(1), then O(1) per child | the entities whose `ChildOf` points at `parent`; destroying a parent destroys them, and theirs |
| `world.Descendants(root)` | O(1) per entity of the subtree | depth first, every level below `root`; 0 B once warm |
| `world.Descendants(root).AddTo(ids, includeRoot)` | O(1) per entity of the subtree | appends the subtree to a `List<EntityId>`, the root first when asked, each parent before its children (the group `MoveEntities` / `SaveEntities` take as `CollectionsMarshal.AsSpan(ids)`); returns how many were added; allocates only when the list grows |
| `entity.Link(in T relation)` | O(1) amortized | appends to the entity's `DynamicBuffer<T>` (added first if missing) and to the relation index |
| `entity.Unlink<T>(target)` / `Links<T>(target)` | O(L) | `Unlink` returns how many links went; generated as `e.UnlinkX(target)` / `e.LinksX(target)` for a relation `X` |
| `world.Relations<T>()` | O(1); the first call creates it | the relation index; generated as `world.XIndex` for a relation `X` |
| `relations.Count(target)` | O(1) | links to `target` |
| `relations.TargetCount` | O(1) | distinct entities some link points at (how many guilds have a member), kept as links come and go |
| `relations.Find(target)` | O(1), then O(1) per link | the entities linking to `target` |
| `relations.Find(target).Count` | O(1) | how many links pointed at `target` when found; links dropped during the loop are skipped by it but still counted |
| `relations.WhenTargetDestroyed(policy)` | O(1); then O(1) per destroyed entity and O(L) per link | `Remove` drops the links, `Destroy` destroys the linking entities |

## Snapshots, saves and moves [#saves]

| API | Complexity | Notes |
| --- | --- | --- |
| `world.Capture()` / `Capture(into)` | O(entities × components + tables + singletons) | copies by value; `Capture(into)` reuses an earlier snapshot's arrays and allocates nothing once they are large enough; not while a pass iterates |
| `world.Restore(snapshot)` | O(entities × components + tables + singletons) | snapshot handles are valid again, later ones stale; every restored row counts as written (or removed) |
| `world.Save(output)` | O(entities × components) | the world as bytes: unmanaged rows raw, managed values through Nino; allocates nothing once its buffers are large enough |
| `world.SaveWithout(output, in ComponentSet exclude)` | O(entities × components) | without the components and singletons of `exclude` (a `Disabled<T>` goes with its `T`), which need no formatter; allocates nothing once its buffers are large enough |
| `world.Load(input, markWritten)` | O(entities × components) | entities keep their ids; a changed component layout throws `InvalidDataException` and leaves the world as it was; `markWritten: false`: the loaded rows count as never written |
| `world.LoadKeeping(input, in ComponentSet keep, markWritten)` | O(entities × components) | the singletons of `keep` stay exactly as the world has them (the save's values are skipped); a component in `keep` throws `ArgumentException`; `markWritten` applies to the loaded rows |
| `world.SaveEntities(output, ids)` | O(entities given × components) | a group of entities, for another world or process |
| `world.SaveEntitiesWith(output, ids, set)` | O(entities given × components) | only the components of a `ComponentSet` (built once: `ComponentSet.Create().With<T>()`, O(1) per type); a set naming a singleton throws `ArgumentException` |
| `ComponentSet.Create().With<T>()` / `WithSingleton<T>()` / `With(type)` | O(1) each; `With(type)` one lookup (cold) | `With(type)` takes a component or a singleton type; `Contains<T>()` / `ContainsSingleton<T>()` O(1) |
| `world.LoadEntities(input, entities)` | O(entities × components) | new ids; `EntityId` fields naming the group are rewritten, others become `EntityId.Null` |
| `world.LoadEntitiesInto(input, targets, markWritten)` | O(entities × components) | onto entities that exist: each moves table at most once, the components the save lacks stay; `markWritten: false`: the loaded components count as never written |
| `world.MoveEntities(target, ids, moved)` | O(entities × components) | to another world of this thread, without encoding; the originals are destroyed (retired, when they hold cleanup components, which stay with them); retired entities are skipped |
| the `ids` / `entities` of these calls | O(1) to pass | spans: an array, `[a.Id, b.Id]` or `SaveEntities(output, a.Id, b.Id)` (built on the stack), a list as `CollectionsMarshal.AsSpan(list)`: no copy, no allocation |

Details: [snapshots](/en/docs/guide/snapshots), [saves](/en/docs/guide/saves),
[migration and unloading](/en/docs/guide/migration-and-unload).

## Systems, singletons, maintenance [#systems-singletons-maintenance]

| API | Complexity | Notes |
| --- | --- | --- |
| `world.AddSystem<T>(changesFromNow)` / `AddSystem(system, changesFromNow)` | O(s²), s = systems of its group | calls `OnCreate`; rebuilds the order and stages (cold); throws if the system already belongs to a world, or on an ordering cycle; `changesFromNow: true`: its first run sees only what is written after the call |
| `world.RemoveSystem<T>()` | O(s²) | calls `OnDestroy`; returns whether a system was removed |
| `world.TryGetSystem<T>(out system)` | O(systems) | false (and null) when absent |
| `world.Update()` / `world.Update<TGroup>()` | Σ systems of the group | synchronous, allocation-free; throws `ObjectDisposedException` after `Dispose` |
| `world.ChangeTick` | O(1) | grows by one per stage of systems and once after each update |
| `world.AddSingleton<T>()` / `GetSingleton<T>()` / `GetOrAddSingleton<T>()` | O(1) | `ref T`; `AddSingleton` throws when the singleton exists; `GetSingleton` throws when missing |
| `world.SingletonRef<T>()` | O(1) | a stable handle; throws when the singleton was not added; `.Value` is one load |
| `world.TryGetSingleton<T>(out T)` / `HasSingleton<T>()` / `RemoveSingleton<T>()` | O(1) | `RemoveSingleton` returns false when it was not added |
| generated: `world.X`, `HasX`, `GetOrAddX()`, `SetX(…)`, `RemoveX()` for a singleton `X` | as the generic call | |
| `world.Systems` | O(systems) to walk, `Count` O(groups) | every group's systems in execution order, allocation-free |
| `world.DefaultUpdateCount` | O(1) | default-group updates so far |
| `world.RemoveTypes(assembly)` / `RemoveTypes(context)` | O(entities with such components + tables + cached queries) | takes a plugin's systems, singletons, indexes and components out of the world so its `AssemblyLoadContext` can unload; allocates (cold) |
| `world.DescribeTables()` | O(tables + columns) | every table with its columns, rows, capacity and bytes; allocates (cold) |
| `world.DescribeSchedule()` | O(groups × systems³) | every group's stages, each system's reads and writes, its waits and the registration-only pairs; allocates (cold); any thread |
| `schedule.ToString()` / `ToMermaid()` | O(systems + waits + pairs) | the description as indented text, or as a mermaid flowchart; allocates |
| `world.TrimExcess()` | O(tables × (cached queries + snapshots) + rows of the shrunk tables × columns) | drops empty tables (except those a snapshot holds rows of), shrinks the others to their rows rounded up to a power of two (64 at least), releases the buffers of saves, loads and migrations; allocates (cold); owner thread, not during a pass; dropped tables and edges are created again on demand |
| `world.DestroyedSince(since, Span<EntityId> into, out int count)` | O(count) | the entities destroyed at or after `since`, oldest first; false (nothing written) when `since` is older than `DestroyLogOldestTick`: resynchronize; throws when `WorldOptions.DestroyLogCapacity` is 0; allocation-free; owner thread or a thread of a parallel stage |
| `world.DestroyLogOldestTick` | O(1) | the oldest tick `DestroyedSince` answers for; `ulong.MaxValue` when the log is off |
| `entity.Describe()` | O(c) | boxed copies of the entity's components, disabled ones marked; allocates (cold) |
| `world.Dispose()` | O(systems + entities + tables) | `OnDestroy` on every system in reverse order, then releases storage |

`WorldOptions.SystemErrors`: `SystemErrorPolicy.Throw` (default: the exception propagates out of `Update()`, and of
`Dispose` for `OnDestroy`) or `Disable` (the system is switched off and keeps the exception in `system.Error` until it
is enabled again; a failed run still moves `LastRunTick` on). `WorldOptions.MeasureSystems` records every run into
`system.Stats` (`Runs`, `LastTime`, `TotalTime`, `AverageTime`, `LastAllocated`, `TotalAllocated`, `LastEntities`,
`TotalEntities`, all O(1) to read) for two timestamp reads and two allocation-counter reads per run (and per helper
chunk of a parallel `[ForEach]`), plus one count of each `[ForEach]` pass's matches. `WorldOptions.DestroyLogCapacity` (default
0, off) preallocates that many 16-byte records for `DestroyedSince`: O(capacity) once, at `new World`.

Values and handles, all O(1): `entity.Id` / `World`, `id.Index` / `Version`, `==` / `Equals` / `GetHashCode` (id and
version) / `ToString`; `snapshot.EntityCount`; `system.LastRunTick`, `RunCount`, `UpdateInterval`, `UpdatePhase`,
`Enabled`, `Error`, `Stats`, `World`.
