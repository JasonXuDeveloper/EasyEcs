Every public type and call of EasyEcs, grouped by what you do with it, with the cost of each. Everything is in
`namespace EasyEcs`. T1..T9 overloads come from one template each
([Architecture](/en/docs/architecture#source-generators-and-analyzer-easyecsgenerator)). For signatures, parameters
and the XML documentation of each member, see the generated [API reference](/en/docs/reference); its pages quote
the complexities below.

Notation:

- *n*: components in the call (1 to 9).
- *c*: components of the entity.
- *M*: tables (archetypes) matching a query.
- *S*: rows of those tables: living entities, plus tombstones while a pass that makes structural changes runs.
- *k*: entities of one key of an index; *L*: links of one entity.
- "Amortized": tables and the entity array occasionally double.

Unless a row says otherwise, a call allocates nothing once the world is warmed up, and only the world's owner thread
may make it ([Threading](/en/docs/guide/threading)).

| `World` | sealed class, `IDisposable` | Owns entities, components, singletons, indexes and systems. |

| `IUniqueIndexed<TKey>`, `UniqueIndexExtensions` | interface, extensions | An indexed component whose key names one entity: a write giving a second entity a taken key throws; `index.Get(key)`, `TryGet` ([indexes and relations](/en/docs/guide/indexes-and-relations)). |
| `IDirectMapped<TKey>` | interface | A unique component whose keys map to a bounded range of slots (`static Slots`, `static SlotOf(key)`): its index keeps a slot array beside the hash, so `Get` / `TryGet` and the uniqueness check of a write read one entry ([indexes and relations](/en/docs/guide/indexes-and-relations)). |

| `ChildOf` | record struct | `ChildOf(EntityId Parent)`: the hierarchy; destroying a parent destroys its children ([hierarchy](/en/docs/guide/hierarchy)). |

| `ICleanupComponent`, `Retired` | marker interface, tag | `Destroy` on an entity that holds a cleanup component retires it: it stays alive with the cleanup components, tagged `Retired`, until the last one is removed ([cleanup and disable](/en/docs/guide/cleanup-and-disable)). |
| `Disabled<T>` | tag | Present while `T` is disabled: the value kept, the component hidden. |
| `Prefab` | sealed class | A recipe of component values that belongs to no world ([prefabs](/en/docs/guide/prefabs)). |
| `DynamicBuffer<T>` | struct, `IComponent, ITracked` | A list per entity; writes through `DynamicBufferExtensions` on a `ref` ([dynamic buffers](/en/docs/guide/dynamic-buffers)). |
| `ValueIndex<T, TKey>` | sealed class | `world.Index<T, TKey>()`: `Find`, `TryFind`, `Count`; ordered walks for a comparable key (`OrderedIndexExtensions`). |
| `RelationIndex<T>` | sealed class | `world.Relations<T>()`: the entities linking to a target. |
| `TargetPolicy`, `TargetPolicyExtensions` | enum, extensions | What destroying a target does to the links to it: `Keep`, `Remove`, `Destroy`. |
| `[EcsSystem]` | attribute | On a `ref struct` of static members: a system. Its hooks are static methods marked `[OnCreate]`, `[OnUpdate]`, `[OnDestroy]`, each taking the `World`, the `SystemHandle`, both or neither ([systems](/en/docs/guide/systems)). |
| `SystemHandle` | readonly struct | A system added to a world: `Enabled`, `Error`, `Stats`, `LastRunTick`, `RunCount`, `Name`, `Type`, `World`, `IsAlive`; stale (its members throw) once the system is removed. |
| `ForEachAttribute` and its filters | attributes | `[ForEach]` (`Parallel = true`, `ChunkSize = n`, `Slices = N`, `SimdMode = SimdMode.Auto` / `Require` / `Off`, `FloatMode = FloatMode.Exact` / `Fast`), `[With<T>]`, `[Without<T>]`, `[WithAny<T>]`, `[Changed<T>]`, `[Removed<T>]`, `[ChangedAny<T1..Tn>]`, `[RemovedAny<T1..Tn>]`; `[Consume]` (the visited rows destroyed after the pass); `[ForEntity]` (a static method run on one entity through its generated entry point). |
| `Maybe<T>` | ref struct | An optional component parameter of a `[ForEach]` method: `HasValue`, `Value`. |
| `ReadOnlyMaybe<T>` | ref struct | The same, read-only: `Value` is `ref readonly`, never stamped, allowed for indexed components; a `Maybe<T>` converts to it. |
| `[View]` | attribute | On a `ref struct` of `ref` (written), `ref readonly` (read) and `Mut<T>` (written on some rows) component fields with business methods: one entity's components, taken by `[ForEach]` and `[ForEntity]` methods and reached by `entity.AsX()` / `TryGetX(out X)`. |
| `[Prefab]` | attribute | On a partial struct with one field per component, its initializer the default: the generator writes `X.Prefab`, a `static readonly Prefab` of those defaults, for `world.Instantiate(X.Prefab)`. |
| `Mut<T>` | ref struct | A component parameter of a `[ForEach]` method that counts as written only on the rows the method writes: `Value`, `Write()`, `SetIfChanged(value)` ([change tracking](/en/docs/guide/change-tracking)). |

| `[Sum]`, `[Product]`, `[Min]`, `[Max]`, `[All]`, `[Any]` | attributes | On every instance field of a partial struct (on the struct: for the fields without one): the generator writes its `IReduction<T>` (`Identity` and a field-wise `Combine`). |

| `[LookupKey]`, `[UniqueKey]`, `[Group]` | attributes | On a member of a partial component (`[LookupKey]` on the type: the value itself): the generator writes the explicit `IIndexed<TKey>.Key` (`IUniqueIndexed<TKey>`) or `IGroup.Group`. |
| `[GroupBy]`, `[WhenTargetDestroyed(policy)]`, `[NotSaved]` | attributes | Setup every world applies from its first table holding the type: its grouping, the policy of links to a destroyed target; `[NotSaved]`: no save writes the type, a load keeps the world's own singleton. |
| `[OrderBy(box...)]`, `IOrderKey<TKey>` | attribute, interface | On a member of a partial component: every world keeps the tables holding it in the order of that key (`Interval`, `Margin`), overriding an order a pair method's setup requested; the generator writes the explicit `OrderKey` and `BoxPoint`. |
| `[Neighbor]` | attribute | On a parameter of a `[ForEach]` method: a component of the other entity of a pair taken by `in`, or its `Entity`; the method runs for every pair within the cutoff its first test names (a pair method). |
| `RowBlocks`, `BlockPair` | ref struct, record struct | One ordered table's rows in blocks of `Size` rows (8, or 4 on ARM64) with a box each (`world.Blocks<T>()`, `entities.Blocks`): `Count`, `SortedRows`, `Start`, `End`, `Min(axis)`, `Max(axis)`, `Read<T>()`, `Ids`, `Has(row)`, `Pairs(reach, into)`. |
| `IRowOrder<T>`, `RowKeys` | interface, static class | For generated code: how an order reads a row (`Key`, `Point`, static), the Morton code of a point by a cell (`RowKeys.Morton`). |
| `Scratch<T>` | ref struct | A `[ForEach]` parameter: working memory of the method on the running thread, kept between rows, passes and worlds: `Value`. |
| `Emit<T>`, `Emitted<T>` | ref struct, struct | A `[ForEach]` parameter, taken by value, appending records (`Add`, `AddRange`) joined in chunk order into singleton `Emitted<T>` (`Items`, a `DynamicBuffer<T>`) when the pass ends. |
| `[ForEachRecord]`, `IForEachRecord<T>` | attribute, interface | On a static method taking `in T` first: the generator runs it on each record of `Emitted<T>` in order, then clears them (`Emitted<T>.Consume` runs its job). |
| `EntityRandom` | record struct | A singleton (`Seed`, `Tick`) and pure static functions: deterministic random numbers per (seed, entity, tick, stream): `Bits`, `Float`, `Range`, `Chance`. |
| `IForRange`, `IForSpan<T>` | interfaces | Jobs of `world.ForParallel`: `Execute(start, end)` over a range of indexes, `Execute(start, span)` over the elements of a list. |
| `Lookup<T>`, `LookupExtensions` | ref struct, static class | A `[ForEach]` parameter reading component `T` of any entity, scheduled as a read of `T`: `this[id]`, `Read(id)`, `Has(id)`; by key for an indexed `T`: `TryFind(key, out entity)`, `Find(key)`, `Count(key)`. |

## Entities [#entities]

| API | Complexity | Notes |
| --- | --- | --- |
| `new World(options)` | O(`InitialEntityCapacity`) | `options` may be null (defaults); allocates the entity array and the empty table |
| `world.CreateEntity()` | O(1) amortized | reuses recycled ids |
| `world.CreateEntity(in T1 … in Tn)` | O(n) amortized | placed directly in its final table |
| `world.CreateEntities(Span<Entity> entities, in T1 … in Tn)` | O(count × n) amortized | one gate pass and at most one table growth for the wave; writes the handles |
| `entity.Destroy()` | O(c) | the table's last row fills the hole (a tombstone during a pass); recycles the id; a stale handle is ignored; unlinks indexed components; cascades to `ChildOf` children and applies target policies; with `WorldOptions.DestroyLogCapacity`, one 16-byte record |
| `world.DestroyAll<T1..Tn>(filter)` | O(M + S) | destroys every match in one gate pass and returns how many; safe during a pass |
| `world.CollectIds<T1..Tn>(into, filter)` | O(M), + the rows read until `into` is full | writes the ids of the matches into a span in query order until it is full and returns how many: a bounded batch for `DestroyEntities`, `SaveEntities` or structural changes; a table whose rows all match is one copy, a 64-row word with room for its rows one `Lanes.Compact`; allocation-free |
| `world.DestroyEntities(ids)` | O(ids × c) | destroys a list of ids in one gate pass and one cascade and returns how many; stale ids and repeats are skipped; safe during a pass |
| `entity.IsAlive` / `world.IsAlive(id)` | O(1) | |
| `world.TryGetEntity(id, out e)` / `GetEntity(id)` | O(1) | false (or a throw) when that incarnation is not alive |
| `world.EntityCount` | O(1) | |
| `world.Entities` | O(capacity) | living entities in id order, for diagnostics |
| `world.EnsureEntityCapacity(capacity)` | O(capacity) | pre-size the entity array; a no-op when large enough |
| `world.Reserve<T1..Tn>(count)` | O(n), plus one growth | pre-sizes the table of exactly `T1..Tn` and the entity array, so the next `count` creations with those components never grow them; also the keys of their indexed components, the table they retire into when they hold cleanup components, and the free-id list ([reserve](/en/docs/guide/prefabs#reserve)) |

## Components [#components]

| API | Complexity | Notes |
| --- | --- | --- |
| `entity.Get<T>()` | O(1) | `ref T`: a version check, a column lookup, one presence-bit test, one load; throws if missing or not alive; a write of a tracked component |
| `entity.Read<T>()` | O(1) | `ref readonly T`; never a write |
| `entity.TryGetRef<T>(out bool found)` | O(1) | `ref T`, a null ref when missing; a write of a tracked component when found |
| `entity.Has<T>()` / `TryGet<T>(out T)` | O(1) | false when missing or not alive; `TryGet` returns a copy (not a write) |
| `entity.Has<T1..Tn>()` | O(n) | all of them, one record lookup |
| `entity.Set(in T1 … in Tn)` | O(n), or O(c) amortized when it moves | adds or overwrites, at most one row copy, returns the entity; a component the table has a column for only sets its bit; re-indexes a changed key (O(1)); a unique key another entity holds throws before anything changes |
| `entity.SetIfChanged(in T value)` | O(1) plus a comparison (O(size of `T`)); as `Set` when the value differs | false, and nothing written, stamped or re-indexed, when the entity already has this value; adds `T` when missing; equality is `IEquatable<T>`, else the bytes of an unmanaged `T` |
| `entity.GetOrAdd<T>()` | O(1); when missing, O(1) if the table has a column for `T`, else O(c) amortized | `ref T`; adds a default value only when missing; a write of a tracked component; an indexed `T` it adds is indexed by its default key (a unique one claims it) |
| `entity.GetOrAdd<T>(in T value)` / generated `GetOrAddX(…)` | as `GetOrAdd<T>()` | `ref T`; adds `value` only when missing (indexed, grouped, a unique key claimed, as `Set`); an entity that has `T` keeps its own value |
| `entity.Remove<T1..Tn>()` | O(n) | clears presence bits, the row stays; missing components are ignored; a tracked component's removal is stamped (`[Removed<T>]`); returns the entity |
| `entity.Disable<T>()` / `Enable<T>()` | O(1); the first disable in a table moves the row once | keeps the value while queries, `Has` and `Get` see it as gone; a disable counts as a removal, an enable as a write; returns false when there was nothing to do |
| `entity.IsDisabled<T>()` | O(1) | |
| generated: `entity.X`, `HasX`, `TryGetX`, `GetOrAddX()`, `SetX(…)`, `SetXIfChanged(…)`, `RemoveX()`, `WriteX()`, `DisableX()`, `EnableX()`, `IsXDisabled`; tags `IsX`, `SetX()`; `world.XIndex` | as the generic call | C# 14 extension members per component ([generated members](/en/docs/guide/entities-and-components)); `entity.X` is `Get`, or `Read` for a tracked or indexed component, whose writes use `WriteX()` or `SetX(…)`; `SetXIfChanged(…)` for a tracked, indexed or grouped component that can be compared; EasyEcs's own `ChildOf` has them too (no `DisableChildOf` / `EnableChildOf`: it cannot be disabled), and `Retired` has `entity.IsRetired` |

## Prefabs and cloning [#prefabs-and-cloning]

A copy gets its own list for each `DynamicBuffer<T>`, is indexed at once, and counts as a write of every tracked
component it has; components the source lacks stay absent and are not removals.

| API | Complexity | Notes |
| --- | --- | --- |
| `new Prefab()` | O(1) | an empty recipe; allocates its private store once |
| `new Prefab(basePrefab)` | O(c) | a variant: a copy of every value (and member), changed on its own afterwards |
| `prefab.Set(in T1 … in Tn)` | O(n), or O(c) amortized when it gains a component | adds or replaces values; returns the prefab |
| `prefab.Remove<T1..Tn>()` | O(n) | missing ones are ignored; returns the prefab |
| `prefab.Has<T>()` / `Read<T>()` | O(1) | `Read` throws if the prefab has no `T` |
| `prefab.SetBuffer<T>(params ReadOnlySpan<T>)` | O(n) | a `DynamicBuffer<T>` of these elements; every instance gets a list of its own |
| `prefab.SetAbsent<T>()` | O(1) | a column for `T` without the component: instances lack it, and adding it later flips a presence bit in their table instead of moving the row |
| `prefab.AddMember()` | O(1) | a member of the prefab's group: instantiating one creates all; `EntityId` fields naming members are rewritten per instance |
| generated: `prefab.X`, `HasX`, `SetX(…)`, `RemoveX()`; tags `IsX`, `SetX()`; buffers `SetLoot(items…)` | as the generic call | writers return the prefab; the property is read-only; not structural changes of any world |
| generated `X.Prefab` of a `[Prefab]` struct | O(c) once, at the type's first use | a prefab of the field initializers' values (`default` for a field without one), shared by every world: instantiate it, or change a variant (`new Prefab(X.Prefab)`) |
| `world.Instantiate(prefab)` | O(c) | one row copy; the target table is found once per prefab table and cached; safe during a pass (which does not visit the new entity); O(members × c) for a group |
| `world.Instantiate(prefab, Span<Entity> entities)` | O(count × c) | one gate pass and at most one table growth for the wave |
| `world.Instantiate(prefab, in T1 … in Tn)` | O(c + n) amortized | the prefab's values plus the given ones (replacing the prefab's, or added; a disabled one given is enabled), in one row copy into the final table, no intermediate table; a given `ChildOf` links the hierarchy, a unique key is checked first; O(members × c) plus one move for a group, whose entity of the prefab passed gets the components |
| `world.Instantiate(prefab, Span<Entity> entities, in T1 … in Tn)` | O(count × (c + n)) | the same values for every instance; one gate pass, at most one table growth, each given column filled at once |
| `world.Reserve(prefab, count)` | O(c), plus one growth | pre-sizes the tables the next `count` instances go to, so a spawn wave never grows them during a tick; also the instances' index keys, retired table and free ids (not their buffer lists: `ReserveBuffers`) |
| `world.ReserveBuffers(prefab, count)` | O(c + rows), plus O(lists) allocations once | fills the pool of each `DynamicBuffer<T>` the prefab holds (`FillPool`) until it holds a list per instance and member holding it; process-wide, not cumulative across prefabs |
| `entity.Clone()` | O(c) | a new entity of the same world and table with a copy of every component; throws if not alive or retired (kept for its cleanup components) |

## Dynamic buffers [#dynamic-buffers]

`new DynamicBuffer<T>()` holds no list until its first write. Reads work on any reference (`in`, `Read<T>()`); writes
need a `ref` and are tracked writes.

| API | Complexity | Notes |
| --- | --- | --- |
| `bag.Count`, `bag.Capacity`, `bag[i]`, `AsReadOnlySpan()`, `GetEnumerator()` | O(1) | read-only; out-of-range indexes throw |
| `bag.Add(item)` / `AddRange(items)` | O(1) amortized / O(items) | `items`: a span, several values (`params`) or `CollectionsMarshal.AsSpan(list)`; allocates only when the buffer grows |
| `bag.Insert(i, item)` / `RemoveAt(i)` | O(count) | keep the order |
| `bag.RemoveAtSwapBack(i)` | O(1) | the last element moves into `i` |
| `bag.Clear()` | O(1), O(count) for elements with references | keeps the capacity |
| `bag.EnsureCapacity(n)` / `AsSpan()` | O(count) when it grows / O(1) | `AsSpan()` is writable |
| `bag.SetCount(n)` | O(elements added or removed) | returns the span to write (`AsSpan()`); added elements are `default`; allocates only when the buffer grows |
| `bag.TrimExcess()` | O(count) | reallocates to the count; an empty buffer gives its list back to the pool and holds none |
| `DynamicBuffer<T>.MaxPooledLength` | O(1) | the longest list a dead buffer of `T` gives back to the [buffer pool](/en/docs/guide/dynamic-buffers#pool) (default 4 KB of elements); per element type, process-wide, set at startup |
| `DynamicBuffer<T>.FillPool(lists)` | O(lists) allocations once; O(1) when the pool holds enough | fills the pool with empty lists of `MaxPooledLength` elements until it holds `lists`; per element type, process-wide, after `MaxPooledLength` |

A snapshot, a save or a clone of a buffer column copies the elements: O(elements), a new list per entity.

## Queries [#queries]

| API | Complexity | Notes |
| --- | --- | --- |
| `[ForEach]` method / `world.ForEach<T1..Tn, TJob>(ref job, filter)` | O(M + S) | fastest: a struct job, no delegate |
| `world.ForEach(values…, static (ref P p, …) => …)` / `ForEachParallel(…)` | O(M + S) | a lambda pass: the generator compiles each call into the job a `[ForEach]` method with its parameters and body gets (vector loop included); up to 4 values before the lambda become job fields (a change filter takes its tick first); 0 B; throws when the call was not compiled (EECS095) |
| `world.ForEachEntity<T1..Tn, TJob>(ref job, filter)` | O(M + S) | the job also receives the `Entity` |
| `entity.Run<T1..Tn, TJob>(ref job)` / `Run(ref job, filter)` | O(n), plus O(1) per filter component | one entity; false when stale, missing a component or rejected by the filter; refs survive the job's structural changes |
| `entity.Run<T1..Tn, TJob>(ref job, in filter, since)` | O(n), plus O(components the filter names) | as `Run(ref job, filter)` with `since` as the filter's tick: the test of `filter.Since(since)` without copying the filter (a `static readonly` filter, as a `[ForEntity, Changed<T>]` entry point passes it) |
| `[ForEntity]` method: generated `Owner.Method(entity, values…)` | as `entity.Run` | `entity.Run` of the generated job (its `ref` parameters the `WriteMask`, its filter attributes a `static readonly` filter); false as `Run`; a method with `[Changed<T>]` takes `since` second; one that takes singletons or the `World` is false for an entity of no world |
| `[View]` parameter of a `[ForEach]` / `[ForEntity]` method or a lambda pass | as the same components taken as parameters | the job builds the view over the row (one ref per field, no copy); its `ref` fields are the system's writes (tracked ones stamped on every visited row), its `Mut<T>` fields writes stamped on the rows written (no vector loop), its `ref readonly` fields its reads; a method calling the view's members gets the vector loop the same code written over the parameters would (the members inlined); a lambda pass taking a view keeps the scalar loop; a component reached twice is EECS099 |
| generated `entity.AsX()` / `TryGetX(out X)` of a `[View]` | O(fields) | a ref per field (`Get` for `ref`, `Read` for `ref readonly` and `Mut<T>`, whose writes stamp); `AsX` throws when a component is missing or the entity is not alive, `TryGetX` returns false; never a structural change |
| `[ForEach, Consume]` | the pass, then O(M + S): a `DestroyAll` (whole tables freed at once) or one destroy per row | destroys the rows the pass visited when it ends: a `DestroyAll` of the method's filter after a method without structural changes, one destroy per row after the method otherwise; rows that start to match during the pass stay; a bulk pass that throws destroys nothing; the system runs alone; not with `Slices` (EECS085) |

## Ordered tables [#ordered-tables]

A table ordered by a component keeps its rows in key order (a Morton code of a position for a pair method's distance
test, or the key `[OrderBy]` declares), re-sorted on a cadence, with a box per block of `Size` rows (8, or 4 on ARM64). N = rows of the table,
C = its columns, K = the key's bytes that differ, B = blocks.

| API | Complexity | Notes |
| --- | --- | --- |
| `world.OrderRows<T, TOrder>(axes, cell, interval, margin)` | O(tables), once | for generated setup: orders the tables holding `T` now and later by `TOrder`'s key, the first sort at the next update, then every `interval` updates; the first request for a component stands, `[OrderBy]` overrides it; throws during a pass |
| sort (an update on the cadence, `world.SortRows<T>()`) | O(N × (K + C)) when rows move, O(N) when they are in order already | an LSD radix sort of (key, row) skipping bytes every row shares, one permutation of every column, presence bit, change tick and slot under the structural gate (refs and handles' rows end, as at any structural change); rows lacking `T` sort last; boxes drawn again; 0 B in steady state (pooled buffers); `SortRows` throws during a pass |
| a table no order covers | 0 | no sort, no box, one null check where rows move |
| `world.Blocks<T>()` | O(1), O(tables) to walk | the `RowBlocks` of each table ordered by `T`; none for an unordered component |
| `blocks.Min(axis)` / `Max(axis)` / `Start(b)` / `End(b)` / `Read<T>()` / `Ids` / `Has(row)` | O(1) | the box sides of every block, a block's rows (`[b * Size, min((b + 1) * Size, SortedRows))`), the table's columns read-only; rows past `SortedRows` joined since the sort and are in no block; a row moved into a block widened its box |
| `blocks.Pairs(reach, into)` / `Pairs(other, reach, into)` | O(B log B + pairs) | the block pairs whose boxes come within `reach` on every axis (each block with itself, the others once), as far as `into` holds; returns how many there are; 0 B in steady state |

| `world.TrimExcess()` | O(tables × (cached queries + snapshots) + rows of the shrunk tables × columns) | drops empty tables (except those a snapshot holds rows of), shrinks the others to their rows rounded up to a power of two (64 at least), releases the buffers of saves, loads and migrations; allocates (cold); owner thread, not during a pass; dropped tables and edges are created again on demand |
| `world.DestroyedSince(since, Span<EntityId> into, out int count)` | O(count) | the entities destroyed at or after `since`, oldest first; false (nothing written) when `since` is older than `DestroyLogOldestTick`: resynchronize; throws when `WorldOptions.DestroyLogCapacity` is 0; allocation-free; owner thread or a thread of a parallel stage |
| `world.DestroyLogOldestTick` | O(1) | the oldest tick `DestroyedSince` answers for; `ulong.MaxValue` when the log is off |
| `entity.Describe()` | O(c) | boxed copies of the entity's components, disabled ones marked; allocates (cold) |
| `world.Dispose()` | O(systems + entities + tables) | the `[OnDestroy]` method of every system in reverse order, then releases storage; every system handle turns stale |

`WorldOptions.SystemErrors`: `SystemErrorPolicy.Throw` (default: the exception propagates out of `Update()`, and of
`Dispose` for `[OnDestroy]`) or `Disable` (the system is switched off and keeps the exception in `system.Error` until it
is enabled again; a failed run still moves `LastRunTick` on). `WorldOptions.MeasureSystems` records every run into
`system.Stats` (`Runs`, `LastTime`, `TotalTime`, `AverageTime`, `LastAllocated`, `TotalAllocated`, `LastEntities`,
`TotalEntities`, all O(1) to read) for two timestamp reads and two allocation-counter reads per run (and per helper
chunk of a parallel `[ForEach]`), plus one count of each `[ForEach]` pass's matches. `WorldOptions.DestroyLogCapacity` (default
0, off) preallocates that many 16-byte records for `DestroyedSince`: O(capacity) once, at `new World`.

Values and handles, all O(1): `entity.Id` / `World`, `id.Index` / `Version`, `==` / `Equals` / `GetHashCode` (id and
version) / `ToString`; `snapshot.EntityCount`; `system.LastRunTick`, `RunCount`,
`Enabled`, `Error`, `Stats`, `World`.
