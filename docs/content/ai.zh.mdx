EasyEcs 比大多数模型的训练数据都新，它的规则（无状态系统、状态变化即数据、`in` 和 `ref` 参数、所有者线程）恰恰是 AI 助手最先写错的地方。在项目里工作的编码智能体从 EasyEcs 技能获得这些规则；聊天助手则直接读文档：`llms.txt`，或任意页面的 Markdown 版本。

## EasyEcs 技能 [#agent-skill]

技能收录了编写 EasyEcs 代码时最要紧的规则：组件和系统、方法过滤条件和组过滤条件、结构性变更、用 `entity.Run` 处理单个实体的请求、线程与引用、性能、持久化（快照、存档、用 `LoadEntitiesInto` 写入记录）、EasyEcs 不做的事（包括留给你实现的 actor 模式）、项目结构与调试，以及一个示例。它们来自 [ECS 原则](/zh/docs/ecs-principles)、[分析器规则](/zh/docs/guide/analyzer)、[性能指南](/zh/docs/performance)、[项目结构](/zh/docs/guide/project-structure)和[诊断](/zh/docs/guide/diagnostics)。

智能体平时只读技能的描述，任务编写、审查或迁移 EasyEcs 代码时才加载规则，其他对话不占上下文。Claude Code、Cursor、Codex、GitHub Copilot、Gemini CLI 以及其他支持 [Agent Skills](https://agentskills.io) 的智能体都能加载它。

<Tabs items={['skills CLI', '手动安装']}>
<Tab value="skills CLI">

```bash
npx skills add JasonXuDeveloper/EasyEcs
```

[skills CLI](https://github.com/vercel-labs/skills) 会询问要装给哪些智能体：`-a claude-code` 指定一个，`-g` 装到用户目录而不是项目里。仓库只发布一个技能 `easyecs`。新版本发布后运行 `npx skills update` 即可更新。

</Tab>
<Tab value="手动安装">

技能就是一个包含 `SKILL.md` 的文件夹。把它下载到智能体读取技能的目录（Claude Code 用 `.claude/skills`，Codex、Cursor 等用 `.agents/skills`）：

```bash
curl -fsSL --create-dirs -o .claude/skills/easyecs/SKILL.md \
  https://raw.githubusercontent.com/JasonXuDeveloper/EasyEcs/master/skills/easyecs/SKILL.md
```

新版本发布后重新下载一次。

</Tab>
</Tabs>

分析器仍会检查每次构建，所以智能体漏掉的规则会变成编译错误或警告，而不是 bug。

## 纯文本形式的文档 [#docs-as-text]

| 文件 | 内容 |
| --- | --- |
| [`/llms.zh.txt`](https://ecs.xgamedev.net/llms.zh.txt) | EasyEcs 简介、关键事实，以及每个中文页面 Markdown 版本的链接（[llmstxt.org](https://llmstxt.org) 格式；也可访问 `/zh/llms.txt`） |
| [`/llms-full.zh.txt`](https://ecs.xgamedev.net/llms-full.zh.txt) | 所有中文页面的全文，合成一个文件（也可访问 `/zh/llms-full.txt`） |
| [`/llms.txt`](https://ecs.xgamedev.net/llms.txt)、[`/llms-full.txt`](https://ecs.xgamedev.net/llms-full.txt) | 英文页面的同类文件 |

助手能跟随链接时给它 `llms.txt`，不能时给 `llms-full.txt`。全文文件包含[战斗服示例](/zh/docs/example)的代码，模型能看到所有功能放在一起的用法。

## 每页的 Markdown 版本 [#markdown-copies]

在页面地址后加 `.md` 就是它的 Markdown：`https://ecs.xgamedev.net/zh/docs/guide/queries.md`，文档首页是 `/zh/docs.md`。
请求页面本身时带上 `Accept: text/markdown`，得到的也是同一份 Markdown，优先请求 Markdown 的工具不需要特殊地址：

```bash
curl -H "Accept: text/markdown" https://ecs.xgamedev.net/zh/docs/guide/systems
```

每页顶部的菜单可以复制本页 Markdown，或者带着本页在 ChatGPT、Claude、T3 Chat、Scira 中打开。

## 其他工具 [#other-tools]

[Context7](https://context7.com)、[DeepWiki](https://deepwiki.com) 这类为 AI 助手索引 GitHub 仓库和文档的服务，可以在它们自己的网站上指向
[EasyEcs 仓库](https://github.com/JasonXuDeveloper/EasyEcs)。这些服务由第三方运营，返回的内容请以本文档为准核对。
